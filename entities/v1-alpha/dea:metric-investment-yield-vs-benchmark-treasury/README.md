## 2. Definition

Investment Yield vs Benchmark (Treasury) (IYBT) captures the economic value created or preserved for organizations tracking corporate treasury (deep dive). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Portfolio Yield - Benchmark Yield; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Portfolio Yield - Benchmark Yield
```
