## 2. Definition

Agent Licensing Compliance Rate (ALCR) addresses conformance to standards, plans, or obligations and is a fixture of insurance distribution & agency management reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Agents with Valid Licenses / Appointed Agents; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Insurance, it is a recognized element of the standard performance toolkit.

## Formula

```
ALCR = Agents with Valid Licenses / Appointed Agents
```
