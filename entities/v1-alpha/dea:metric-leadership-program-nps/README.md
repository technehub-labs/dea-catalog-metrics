## 2. Definition

A Learning & Development Effectiveness (Deep Dive) indicator, Leadership Program NPS (LPNPS) quantifies the engagement or satisfaction of the people involved. It is computed as Net Promoter Score for Leadership Curricula, expressed in score (points). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.
