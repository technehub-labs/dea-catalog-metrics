## 2. Definition

A Retail Banking Branch Network (Deep Dive) indicator, Appointment Conversion Rate (Branch Advisory) (ACR-BD) quantifies how effectively a process or entity achieves its intended outcome. The formula is Appointments Held / Booked - reported in percent (%). It is a standard measure in the Banking sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.
