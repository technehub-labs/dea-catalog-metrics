## 2. Definition

Within Pulp, Paper & Forest Products, Pulp Yield per Ton of Wood (PYT) is used to gauge how efficiently resources are converted into outputs. It is defined as Pulp Produced / Wood Consumed; the result is stated in ratio (x:1 or x). In Manufacturing, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Pulp Produced / Wood Consumed
```
