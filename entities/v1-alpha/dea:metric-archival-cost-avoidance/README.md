## 2. Definition

A Database & Data Platform Operations indicator, Archival Cost Avoidance (ACA-DB) quantifies the economic value created or preserved. The formula is Storage Cost Avoided through Archival vs Baseline - reported in currency value. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Software sector.
