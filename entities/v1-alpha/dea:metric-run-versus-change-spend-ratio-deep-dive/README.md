## 2. Definition

Within IT Financial Management & Technology Budgeting, Run versus Change Spend Ratio (Deep Dive) (RVCS-D) is used to gauge how efficiently resources are converted into outputs. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Run-the-Business Spend / Total IT Spend - reported in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the balance of spend keeping the lights on versus building new capability. A rising run share quietly strangles transformation. Reclassification games (calling maintenance 'change') are the classic distortion. Read with IT spend as percent of revenue and application rationalization progress rate.

## Formula

```
Run-the-Business Spend / Total IT Spend
```
