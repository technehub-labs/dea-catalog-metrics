## 2. Definition

Purple Team Exercise Closure Rate (PTECR) captures conformance to standards, plans, or obligations for organizations tracking threat intelligence & red team. It is computed as Exercise Findings Remediated / Findings, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Exercise Findings Remediated / Findings
```
