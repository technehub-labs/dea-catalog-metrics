## 2. Definition

Static Analysis Violation Density (SAVD) captures the quality of outputs and outcomes for organizations tracking software development - coding & engineering practices. The formula is Static Analysis Violations per 1,000 Lines of Code - reported in events per thousand or million (scaled). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Static Analysis Violations per 1,000 Lines of Code
```
