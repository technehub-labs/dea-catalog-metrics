## 2. Definition

Localization and Internationalization Test Coverage (LITC-QA) addresses the quality of outputs and outcomes and is a fixture of software testing & quality engineering reporting. It is defined as Locales Tested / Supported Locales; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Locales Tested / Supported Locales
```
