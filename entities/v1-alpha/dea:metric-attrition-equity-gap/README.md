## 2. Definition

Within Diversity, Equity & Inclusion (Deep Dive), Attrition Equity Gap (AEG-DEI) is used to gauge the retention of customers, users, or assets over time. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Attrition Rate Difference between Groups - reported in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures whether voluntary attrition differs systematically across demographic groups. Differential attrition is the quiet undoing of diverse hiring. Exit-survey honesty about reasons for leaving is partial. Read with regretted attrition ratio and belonging index.

## Formula

```
AEG-DEI = Attrition Rate Difference between Groups
```
