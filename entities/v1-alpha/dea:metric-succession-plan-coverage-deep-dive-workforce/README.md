## 2. Definition

Within Workforce Planning & Productivity, Succession Plan Coverage (Deep Dive - Workforce) (SPCD) is used to gauge exposure to adverse outcomes. It is computed as Critical Roles with Ready Successor / Critical Roles, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of critical roles with identified, developing successors. Succession coverage is the antidote to key-person fragility. Coverage counting any name rather than a developing successor is a list, not a plan. Read with succession plan coverage (Deep Dive) and succession ready-now ratio (Deep Dive).

## Formula

```
Critical Roles with Ready Successor / Critical Roles
```
