## 2. Definition

New Hire Ramp Time (Contact Center) (NHRT-CC) captures capability maturity or development for organizations tracking contact center standard measures (deep dive). It provides the day-to-day signal that a process is running as designed. Its calculation is Weeks to Reach Target Proficiency, measured in weeks. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

Weeks to Reach Target Proficiency
