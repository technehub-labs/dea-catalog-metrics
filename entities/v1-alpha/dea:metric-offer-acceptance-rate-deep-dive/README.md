## 2. Definition

Offer Acceptance Rate (Deep Dive) (OARDD) addresses the quality of outputs and outcomes and is a fixture of talent acquisition deep dive reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Offers Accepted / Offers Extended, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Offers Accepted / Offers Extended
```
