## 2. Definition

Program Milestone Cascade Accuracy (PMCA-PPM) addresses the quality of outputs and outcomes and is a fixture of program & portfolio management reporting. Its calculation is Program Milestones Aligned to Project Deliverables / Milestones, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Program Milestones Aligned to Project Deliverables / Milestones
```
