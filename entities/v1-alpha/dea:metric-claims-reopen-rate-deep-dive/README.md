## 2. Definition

A Insurance Claims Deep Dive indicator, Claims Reopen Rate (Deep Dive) (COR) quantifies the quality of outputs and outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Claims Reopened after Closure / Claims Closed - reported in percent (%). It should be driven down, since lower readings signal healthier performance. It is a standard measure in the Insurance sector.

## Formula

```
Claims Reopened after Closure / Claims Closed
```
