## 2. Definition

Master Data Onboarding Cycle Time (MDOCT) measures how efficiently resources are converted into outputs in the Master Data Management domain. It is defined as Days to Add New Master Record with Full Governance; the result is stated in days. It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.
