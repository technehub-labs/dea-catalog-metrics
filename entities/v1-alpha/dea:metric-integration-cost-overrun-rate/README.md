## 2. Definition

A Mergers & Acquisitions indicator, Integration Cost Overrun Rate (ICOR) quantifies exposure to adverse outcomes. It is defined as Integration Cost Overrun / Planned Integration Cost; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures actual integration costs against planned, and against deal-model assumptions. Overruns both destroy value directly and signal weaker integration management, which predicts synergy misses. Some overrun is normal (one-time costs are lumpy), but repeated overruns across deals indicate systematically under-scoped plans. Read with PMI milestone attainment rate and synergy realization timing.

## Formula

```
Integration Cost Overrun / Planned Integration Cost
```
