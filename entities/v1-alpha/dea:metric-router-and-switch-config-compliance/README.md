## 2. Definition

Router and Switch Config Compliance (RSCC) addresses conformance to standards, plans, or obligations and is a fixture of telecom network operations (deep dive) reporting. Its calculation is Devices with Approved Config / Devices, measured in percent (%). It originates from and is most used in Telecommunications practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Devices with Approved Config / Devices
```
