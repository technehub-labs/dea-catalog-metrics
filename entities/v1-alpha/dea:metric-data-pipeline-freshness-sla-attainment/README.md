## 2. Definition

A MLOps & Model Lifecycle Operations indicator, Data Pipeline Freshness SLA Attainment (DPFSLA) quantifies conformance to standards, plans, or obligations. It is computed as Pipelines Meeting Freshness SLA / Pipelines, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Pipelines Meeting Freshness SLA / Pipelines
```
