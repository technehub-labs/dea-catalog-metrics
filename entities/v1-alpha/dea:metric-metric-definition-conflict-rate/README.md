## 2. Definition

A Data Science & Analytics Operations indicator, Metric Definition Conflict Rate (MDCR-DS) quantifies the quality of outputs and outcomes. Its calculation is Metrics with Conflicting Definitions Found / Metrics Audited, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Metrics with Conflicting Definitions Found / Metrics Audited
```
