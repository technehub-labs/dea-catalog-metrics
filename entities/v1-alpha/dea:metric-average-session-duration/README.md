## 2. Definition

Average Session Duration (ASD) measures the engagement or satisfaction of the people involved in the Marketing domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Total Session Time / Sessions, measured in minutes. Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Total Session Time / Sessions
```
