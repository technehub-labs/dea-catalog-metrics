## 2. Definition

A Enterprise Fraud & Financial Crime Management indicator, Fraud Loss per Investigation FTE (FLPIF) quantifies the economic value created or preserved. Its calculation is Annual Fraud Losses Prevented / Investigation FTE, measured in currency per unit. Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Annual Fraud Losses Prevented / Investigation FTE
```
