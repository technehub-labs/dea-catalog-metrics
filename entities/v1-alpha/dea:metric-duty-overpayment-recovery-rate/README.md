## 2. Definition

A International Trade & Customs indicator, Duty Overpayment Recovery Rate (DORR) quantifies the economic value created or preserved. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Duty Refunds Recovered / Recoverable Overpayments - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Logistics & Trade sector.

## Formula

```
Duty Refunds Recovered / Recoverable Overpayments
```
