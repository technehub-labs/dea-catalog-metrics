## 2. Definition

Outsourced versus In-House Cost Delta (OVIHC) captures the economic value created or preserved for organizations tracking operating model monitoring & design effectiveness. It is defined as Outsourced Unit Cost - In-House Unit Cost / In-House; the result is stated in percent (%). It is applied across virtually every sector. Its trend is watched by senior leadership as an early signal of structural performance shifts. Values outside the intended band, on either side, warrant investigation.

## 3. Context

Measures the cost difference between externally and internally delivered equivalents. The delta should inform sourcing decisions alongside quality, risk, and strategic control. Deltas excluding transition and contract-management overhead flatter outsourcing. Read with vendor spend concentration and shared service adoption ratio.

## Formula

```
OVIHC = Outsourced Unit Cost - In-House Unit Cost / In-House
```
