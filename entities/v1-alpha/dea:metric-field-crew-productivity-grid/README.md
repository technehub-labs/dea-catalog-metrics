## 2. Definition

Field Crew Productivity (Grid) (FCP-G) measures how efficiently resources are converted into outputs in the Utilities Field Operations & Grid domain. It is defined as Completed Work Orders / Crew Day; the result is stated in count (items per period). In Utilities, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Completed Work Orders / Crew Day
```
