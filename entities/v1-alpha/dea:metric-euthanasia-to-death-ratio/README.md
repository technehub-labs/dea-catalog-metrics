## 2. Definition

Euthanasia to Death Ratio (EDR) measures exposure to adverse outcomes in the Veterinary & Animal Health domain. The formula is Planned Euthanasia / Total Deaths Recorded - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. It is a standard measure in the Healthcare sector.

## Formula

```
Planned Euthanasia / Total Deaths Recorded
```
