## 2. Definition

Prototype Validation Cycle Time (PVCT-RE) addresses how efficiently resources are converted into outputs and is a fixture of requirements engineering & product discovery reporting. It is defined as Days from Prototype Build to Validated Learning; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
