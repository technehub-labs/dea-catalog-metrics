## 2. Definition

A Process Excellence (Lean Six Sigma) indicator, Cost Savings from Improvement Projects (CSIP) quantifies the economic value created or preserved. It is defined as Validated Annualized Savings per Period; the result is stated in currency value. Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Cost savings from improvement projects measures the financial benefit captured by process-improvement programs (Lean, Six Sigma, operational excellence), and it is the credibility metric of the entire improvement function - improvement programs survive only while savings are real, and the failure mode of the industry is soft savings: estimates, avoided costs, and hard-to-attribute gains that never appear in the P&L. The measurement honesty issue is baseline methodology: savings measured against an inflated or hypothetical baseline (the projected cost rather than the actual prior cost) manufacture value that finance never sees. The finance-validation discipline is the fix: savings only count when signed off by the controller against real budget lines. Read with the savings-to-P&L traceability ratio (validated versus claimed), sustainment of savings after the project team leaves, and project pipeline velocity.
