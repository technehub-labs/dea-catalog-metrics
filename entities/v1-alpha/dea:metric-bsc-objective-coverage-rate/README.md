## 2. Definition

BSC Objective Coverage Rate (BSOC) addresses strategy and is a fixture of balanced scorecard implementation & review reporting. The formula is Strategy Map Objectives with Linked Measures / Objectives - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures how completely the scorecard's strategic objectives have assigned measures and owners. Unmeasured objectives are aspirations. Coverage with any available metric attached (rather than a fitting one) is metric stuffing. Read with operating model KPI coverage ratio and OKR coverage - cascading ratio.

## Formula

```
Strategy Map Objectives with Linked Measures / Objectives
```
