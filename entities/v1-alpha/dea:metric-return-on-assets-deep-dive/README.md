## 2. Definition

Return on Assets (Deep Dive) (ROADD) measures the economic value created or preserved in the Financial Statement Analysis Ratios (Deep Dive) domain. Its calculation is Net Income / Total Assets, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures profit generated per unit of total assets. ROA tests whether the asset base, financed however, is productive. Asset-light models inflate ROA in ways that limit comparison. Read with return on equity (Deep Dive) and fixed asset turnover (Statement Analysis).

## Formula

```
Net Income / Total Assets
```
