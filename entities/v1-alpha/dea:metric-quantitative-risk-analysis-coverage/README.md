## 2. Definition

A Project Risk & Issue Management indicator, Quantitative Risk Analysis Coverage (QRAC) quantifies capability maturity or development. It is defined as High-Criticality Projects with Quantified Risk / High-Criticality Projects; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
High-Criticality Projects with Quantified Risk / High-Criticality Projects
```
