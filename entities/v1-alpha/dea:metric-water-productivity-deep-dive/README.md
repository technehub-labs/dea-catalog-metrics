## 2. Definition

Water Productivity (Deep Dive) (WP-D) addresses how efficiently resources are converted into outputs and is a fixture of agriculture & agronomy (deep dive) reporting. It is defined as Crop Yield per mm Irrigation Water; the result is stated in ratio (x:1 or x). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Agriculture, it is a recognized element of the standard performance toolkit.

## Formula

```
WP-D = Crop Yield per mm Irrigation Water
```
