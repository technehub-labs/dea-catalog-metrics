## 2. Definition

Exit Interview Completion Rate (Deep Dive) (EICR-EE) addresses the quality of outputs and outcomes and is a fixture of employee engagement & culture (deep dive) reporting. It is defined as Leavers Completing Exit Interview / Leavers; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Leavers Completing Exit Interview / Leavers
```
