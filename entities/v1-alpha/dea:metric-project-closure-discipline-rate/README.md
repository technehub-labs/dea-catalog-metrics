## 2. Definition

Project Closure Discipline Rate (PCDR) captures conformance to standards, plans, or obligations for organizations tracking pmo & portfolio governance. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Projects Closed with Formal Closure / Completed Projects; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Projects Closed with Formal Closure / Completed Projects
```
