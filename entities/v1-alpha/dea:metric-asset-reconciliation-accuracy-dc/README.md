## 2. Definition

Asset Reconciliation Accuracy (DC) (ARA-D) measures the quality of outputs and outcomes in the Data Centers & Cloud Infrastructure domain. It is defined as CMDB Records Verified / Sampled; the result is stated in percent (%). In Technology, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CMDB Records Verified / Sampled
```
