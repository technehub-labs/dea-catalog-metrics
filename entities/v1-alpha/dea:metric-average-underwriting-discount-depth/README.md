## 2. Definition

Within Insurance Underwriting, Average Underwriting Discount Depth (AUDD) is used to gauge the economic value created or preserved. Its calculation is Average Discount from Technical Price / Technical Price, measured in percent (%). It originates from and is most used in Insurance practice. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Average Discount from Technical Price / Technical Price
```
