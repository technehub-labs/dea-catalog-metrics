## 2. Definition

Feed Conversion Ratio (FCR) addresses how efficiently resources are converted into outputs and is a fixture of agriculture & food processing reporting. The formula is Feed Consumed / Animal Weight Gain - reported in ratio (x:1 or x). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Agriculture & food sector.

## Formula

```
Feed Consumed / Animal Weight Gain
```
