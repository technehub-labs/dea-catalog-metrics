## 2. Definition

Employee Resource Group Participation (ERGP) addresses the engagement or satisfaction of the people involved and is a fixture of diversity, equity & inclusion (deep dive) reporting. It is defined as Active ERG Members / Employees; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Active ERG Members / Employees
```
