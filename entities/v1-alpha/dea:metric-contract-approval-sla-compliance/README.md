## 2. Definition

Within Contract Lifecycle Management, Contract Approval SLA Compliance (CASLAC) is used to gauge how efficiently resources are converted into outputs. It is computed as Approvals Completed within SLA / Approvals, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Approvals Completed within SLA / Approvals
```
