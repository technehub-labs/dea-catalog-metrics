## 2. Definition

Within Continuous Delivery & Deployment, Promotion Cycle Time - Stage to Stage (PCTSS) is used to gauge how efficiently resources are converted into outputs. It is computed as Days from One Pipeline Stage to Next, expressed in days. It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.
