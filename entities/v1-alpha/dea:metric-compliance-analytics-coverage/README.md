## 2. Definition

Compliance Analytics Coverage (CAC-CM) measures how efficiently resources are converted into outputs in the Compliance Monitoring & Testing domain. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Obligations Monitored via Automated Data / Automatable Obligations - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of compliance obligations monitored through data and analytics rather than manual attestation. Analytics shift compliance from sampled after-the-fact to continuous detection. Coverage on the easy obligations while high-risk ones stay manual misdirects. Read with compliance monitoring coverage and compliance testing plan completion rate.

## Formula

```
Obligations Monitored via Automated Data / Automatable Obligations
```
