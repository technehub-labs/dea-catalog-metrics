## 2. Definition

IP Value Realization Rate (IPVRR) addresses the economic value created or preserved and is a fixture of intellectual property & licensing reporting. It is computed as Products Launched Using Owned IP / Portfolio Assets, expressed in percent (%). It is applied across virtually every sector. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Values outside the intended band, on either side, warrant investigation.

## 3. Context

Measures how much of the portfolio's potential value is actually monetized or strategically deployed. Most portfolios monetize a fraction of their holdings. Strategic-use value (defensive, cross-license) is real but hard to count. Read with outbound license revenue yield and patent portfolio growth rate.

## Formula

```
Products Launched Using Owned IP / Portfolio Assets
```
