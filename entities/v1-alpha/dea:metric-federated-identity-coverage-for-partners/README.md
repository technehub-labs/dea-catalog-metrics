## 2. Definition

Within Identity & Access Management Operations, Federated Identity Coverage for Partners (FICP) is used to gauge exposure to adverse outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Partner Identities Using Federation / Partner Identities; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Partner Identities Using Federation / Partner Identities
```
