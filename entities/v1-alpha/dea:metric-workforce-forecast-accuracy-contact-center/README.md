## 2. Definition

Workforce Forecast Accuracy (Contact Center) (WFA-CC) captures the quality of outputs and outcomes for organizations tracking contact center standard measures (deep dive). It is defined as Forecast vs Actual Contact Volume Variance / Actual; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Forecast vs Actual Contact Volume Variance / Actual
```
