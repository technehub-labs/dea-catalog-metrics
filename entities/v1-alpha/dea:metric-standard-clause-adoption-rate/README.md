## 2. Definition

Standard Clause Adoption Rate (SCAR) measures how efficiently resources are converted into outputs in the Legal domain. It is computed as Contracts Using Approved Playbook / Contracts Drafted, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of new contracts built from approved standard clauses and templates. It matters because standardization is what makes legal speed and compliance scalable. Adoption can be inflated by counting templates used as a starting point then heavily redlined. Read with Contract Cycle Time and Contract Clause Compliance Rate to confirm standardization is delivering its promised speed and protection.

## Formula

```
Contracts Using Approved Playbook / Contracts Drafted
```
