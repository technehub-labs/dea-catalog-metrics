## 2. Definition

Learning Platform Engagement Rate (LPER) captures the engagement or satisfaction of the people involved for organizations tracking learning & development effectiveness (deep dive). It is computed as Monthly Active Learners / Employees, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Monthly Active Learners / Employees
```
