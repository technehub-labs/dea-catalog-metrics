## 2. Definition

Internal Trainer Contribution Rate (ITCR) addresses how efficiently resources are converted into outputs and is a fixture of learning & development effectiveness (deep dive) reporting. It is computed as Sessions Delivered by Internal Experts / Sessions, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Sessions Delivered by Internal Experts / Sessions
```
