## 2. Definition

A Automation & Robotic Process Automation indicator, Bot Change Deployment Frequency (BCDF) quantifies how efficiently resources are converted into outputs. It is a working-level control: thresholds trigger immediate operational response. It is defined as Bot Updates Deployed per Period; the result is stated in times per period. Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
BCDF = Bot Updates Deployed per Period
```
