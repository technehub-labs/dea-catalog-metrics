## 2. Definition

Bug Discovery-to-Fix Lead Time (Gaming) (BDFL) measures how efficiently resources are converted into outputs in the Gaming Development & Live Operations domain. Its calculation is Days from Bug Report to Resolved, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Gaming practice.

## Formula

```
BDFL = Days from Bug Report to Resolved
```
