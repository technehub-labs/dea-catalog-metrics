## 2. Definition

Within Corporate Treasury (Deep Dive), Bank Fee Analysis Savings Rate (BFAS) is used to gauge the economic value created or preserved. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Fee Reductions Identified / Analyzed Fees, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
BFAS = Fee Reductions Identified / Analyzed Fees
```
