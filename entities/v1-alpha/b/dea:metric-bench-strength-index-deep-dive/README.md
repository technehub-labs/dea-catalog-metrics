## 2. Definition

Bench Strength Index (Deep Dive) (BSIDD) addresses exposure to adverse outcomes and is a fixture of learning & development effectiveness (deep dive) reporting. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Successors Ready Now for Critical Roles / Critical Roles; the result is stated in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the depth of ready successors behind critical roles. Bench strength is what converts succession from plan to capability. Indexes counting named successors without readiness assessment are paperwork. Read with succession plan coverage (Deep Dive) and leadership pipeline strength index.

## Formula

```
BSIDD = Successors Ready Now for Critical Roles / Critical Roles
```
