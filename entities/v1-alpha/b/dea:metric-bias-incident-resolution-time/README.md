## 2. Definition

Bias Incident Resolution Time (BIRT) addresses exposure to adverse outcomes and is a fixture of diversity, equity & inclusion (deep dive) reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Days from Report to Formal Resolution, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
BIRT = Days from Report to Formal Resolution
```
