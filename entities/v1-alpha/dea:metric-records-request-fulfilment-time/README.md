## 2. Definition

A Records & Information Management indicator, Records Request Fulfilment Time (RRFT-RM) quantifies how efficiently resources are converted into outputs. It is a working-level control: thresholds trigger immediate operational response. It is defined as Days to Fulfil Internal Records Requests; the result is stated in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
