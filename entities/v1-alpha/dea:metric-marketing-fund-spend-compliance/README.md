## 2. Definition

A Franchise Operations (Deep Dive) indicator, Marketing Fund Spend Compliance (MFSC) quantifies conformance to standards, plans, or obligations. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Spend per Approved Plan / Approved Fund, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Spend per Approved Plan / Approved Fund
```
