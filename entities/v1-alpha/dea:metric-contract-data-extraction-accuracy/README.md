## 2. Definition

A Contract Lifecycle Management indicator, Contract Data Extraction Accuracy (CDEA) quantifies the quality of outputs and outcomes. It is computed as Key Fields Extracted Correctly / Fields Sampled, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Key Fields Extracted Correctly / Fields Sampled
```
