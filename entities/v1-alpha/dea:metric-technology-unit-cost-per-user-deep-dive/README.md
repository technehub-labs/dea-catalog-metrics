## 2. Definition

Technology Unit Cost per User (Deep Dive) (TUCU-D) addresses how efficiently resources are converted into outputs and is a fixture of it financial management & technology budgeting reporting. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Total Technology Cost / Users, expressed in currency per unit. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures total technology cost per supported user. Unit cost trends reveal whether scale benefits are being captured. Averages blend executives and standard users; segment-level views are more honest. Read with infrastructure unit cost trend and showback or chargeback coverage.

## Formula

```
Total Technology Cost / Users
```
