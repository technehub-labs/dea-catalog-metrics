## 2. Definition

Balanced Scorecard Action Follow-Through Rate (BSAFT) measures conformance to standards, plans, or obligations in the Balanced Scorecard Implementation & Review domain. The formula is Review Actions Closed by Next Review / Actions - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Review Actions Closed by Next Review / Actions
```
