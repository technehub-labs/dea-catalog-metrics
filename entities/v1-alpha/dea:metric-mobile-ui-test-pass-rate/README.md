## 2. Definition

Mobile UI Test Pass Rate (MUITP) captures the quality of outputs and outcomes for organizations tracking mobile & client development. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Automated UI Tests Passing / Executed - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Software sector.

## Formula

```
Automated UI Tests Passing / Executed
```
