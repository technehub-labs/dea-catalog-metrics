## 2. Definition

Physical Security Access Compliance (DC) (PSAC-D) measures conformance to standards, plans, or obligations in the Data Centers & Cloud Infrastructure domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Access Events per Policy / Events, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Technology.

## Formula

```
Access Events per Policy / Events
```
