## 2. Definition

A Financial Planning & Analysis indicator, Scenario Analysis Coverage (SAC-FP) quantifies exposure to adverse outcomes. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Material Uncertainties with Modeled Scenarios / Identified Uncertainties; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how completely the plan addresses defined downside and upside scenarios. Scenarios are the antidote to single-point-plan fragility. Coverage limited to comfortable scenarios is planning theater. Read with stress test scenario coverage and workforce scenario readiness score.

## Formula

```
Material Uncertainties with Modeled Scenarios / Identified Uncertainties
```
