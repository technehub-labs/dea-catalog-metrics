## 2. Definition

Staff Turnover in Hospitality (STOH) captures exposure to adverse outcomes for organizations tracking hospitality & food service. It is defined as Departures / Average Headcount; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Hospitality, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures employee turnover in hospitality operations. It matters because turnover destroys service consistency and training economics in a labor-centric business. Managers can suppress it by reclassifying seasonal staff or delaying separations past measurement windows. Read with Schedule Adherence and Guest Satisfaction to check whether stable staffing is actually improving service.

## Formula

```
Departures / Average Headcount
```
