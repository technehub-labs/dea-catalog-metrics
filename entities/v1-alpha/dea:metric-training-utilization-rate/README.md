## 2. Definition

A Learning & Development indicator, Training Utilization Rate (TUR) quantifies the utilization or availability of capacity. It is a working-level control: thresholds trigger immediate operational response. It is defined as Seats Consumed / Seats Made Available; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Seats Consumed / Seats Made Available
```
