## 2. Definition

A Project Risk & Issue Management indicator, Risk Owner Assignment Rate (ROAR-P) quantifies governance. Its calculation is Risks with Named Owner / Open Risks, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Risks with Named Owner / Open Risks
```
