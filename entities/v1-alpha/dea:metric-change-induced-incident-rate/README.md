## 2. Definition

Within Network Change & Configuration Management, Change-Induced Incident Rate (CIIR) is used to gauge the quality of outputs and outcomes. Its calculation is Incidents Caused by Change / Changes, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Incidents Caused by Change / Changes
```
