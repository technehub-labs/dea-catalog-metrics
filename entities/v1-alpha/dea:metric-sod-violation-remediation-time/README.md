## 2. Definition

A Identity & Access Management Operations indicator, SoD Violation Remediation Time (SODVRT) quantifies how efficiently resources are converted into outputs. The formula is Days to Resolve SoD Conflicts - reported in days. It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Days to Resolve SoD Conflicts
```
