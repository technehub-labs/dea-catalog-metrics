## 2. Definition

Cycle Time per Layer (CTPL) measures how efficiently resources are converted into outputs in the Semiconductor Manufacturing (Deep Dive) domain. Its calculation is Days per Mask Layer Processed, measured in days. It originates from and is most used in Semiconductors practice. Its value drives prioritization and resource reallocation among competing initiatives. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula
