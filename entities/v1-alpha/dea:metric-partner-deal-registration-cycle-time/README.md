## 2. Definition

Partner Deal Registration Cycle Time (PDRC) measures how efficiently resources are converted into outputs in the Channel & Distribution Management domain. It is computed as Days from Registration Request to Decision, expressed in days. It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
PDRC = Days from Registration Request to Decision
```
