## 2. Definition

A Insurance Underwriting indicator, Underwriting Referral Accuracy (UWRA) quantifies the quality of outputs and outcomes. It is defined as Correctly Referred Risks / Total Referrals; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Insurance, it is a recognized element of the standard performance toolkit.

## Formula

```
Correctly Referred Risks / Total Referrals
```
