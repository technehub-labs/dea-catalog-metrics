## 2. Definition

A Insurance Underwriting indicator, Underwriting Decision Consistency (UDC) quantifies the quality of outputs and outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Identical Risk Decisions Matching / Identical Risks Sampled; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Insurance, it is a recognized element of the standard performance toolkit.

## Formula

```
Identical Risk Decisions Matching / Identical Risks Sampled
```
