## 2. Definition

Vacancy Rate (Deep Dive) (VRDD) captures the utilization or availability of capacity for organizations tracking standard workforce & pay metrics. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Open Positions / Total Positions, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Open Positions / Total Positions
```
