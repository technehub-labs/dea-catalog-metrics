## 2. Definition

Within Change Management, Change Communication Reach (CCR-C) is used to gauge the engagement or satisfaction of the people involved. Its calculation is Audience Members Reached per Key Message / Audience, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Audience Members Reached per Key Message / Audience
```
