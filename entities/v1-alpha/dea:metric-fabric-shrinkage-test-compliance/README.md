## 2. Definition

Fabric Shrinkage Test Compliance (FSTC-T) captures the quality of outputs and outcomes for organizations tracking textile & apparel (deep dive). It is defined as Tests within Shrinkage Spec / Tests; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Textiles & Apparel, it is a recognized element of the standard performance toolkit.

## Formula

