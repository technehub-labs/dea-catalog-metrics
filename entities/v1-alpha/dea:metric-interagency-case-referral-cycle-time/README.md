## 2. Definition

Interagency Case Referral Cycle Time (ICRC) addresses how efficiently resources are converted into outputs and is a fixture of government & public administration reporting. Its calculation is Days for Cross-Agency Case Completion, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Public Sector practice.
