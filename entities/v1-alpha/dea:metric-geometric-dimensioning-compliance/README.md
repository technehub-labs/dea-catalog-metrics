## 2. Definition

A Engineering & Design indicator, Geometric Dimensioning Compliance (GDC) quantifies conformance to standards, plans, or obligations. It is defined as GD&T Conformant Features / Features Checked; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
GD&T Conformant Features / Features Checked
```
