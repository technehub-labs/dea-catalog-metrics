## 2. Definition

Within Aerospace & Defense Program Management, Test Point Success Rate (Aerospace) (TPSA) is used to gauge the quality of outputs and outcomes. The formula is Test Points Passed / Test Points Executed - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Aerospace & Defense sector.

## Formula

```
Test Points Passed / Test Points Executed
```
