## 2. Definition

Performance Review Completion Rate (PRCR) captures conformance to standards, plans, or obligations for organizations tracking human resources. It is defined as Completed Reviews / Required Reviews; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Completed Reviews / Required Reviews
```
