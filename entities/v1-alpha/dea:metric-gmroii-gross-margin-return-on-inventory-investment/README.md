## 2. Definition

Within Retail Standard Measures, GMROII (Gross Margin Return on Inventory Investment) (GMROII) is used to gauge the economic value created or preserved. It is computed as Gross Margin / Average Inventory Cost, expressed in ratio (x:1 or x). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Retail & E-commerce.

## 3. Context

Measures gross margin generated per unit of average inventory investment. It is the retailer's master inventory productivity metric. GMROII that ignores markdowns pending in the inventory is flattered. Read with inventory turnover (retail) and sell-through rate.

## Formula

```
GMROII = Gross Margin / Average Inventory Cost
```
