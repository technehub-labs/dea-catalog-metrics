## 2. Definition

Obligation Fulfilment Rate (OFR-CL) addresses conformance to standards, plans, or obligations and is a fixture of contract lifecycle management reporting. It is defined as Contractual Obligations Met on Time / Obligations; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Contractual Obligations Met on Time / Obligations
```
