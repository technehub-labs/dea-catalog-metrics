## 2. Definition

Cash Drag Ratio (CDR-IM) captures how efficiently resources are converted into outputs for organizations tracking investment management - portfolio operations. It is defined as Return Lost to Idle Cash / Portfolio Return; the result is stated in percent (%). In Financial Services, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Return Lost to Idle Cash / Portfolio Return
```
