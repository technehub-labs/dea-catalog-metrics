## 2. Definition

A IT Service Management indicator, First Line Resolution Rate (FLRR) quantifies how efficiently resources are converted into outputs. It is defined as Tickets Resolved at First Line / Total Tickets; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Tickets Resolved at First Line / Total Tickets
```
