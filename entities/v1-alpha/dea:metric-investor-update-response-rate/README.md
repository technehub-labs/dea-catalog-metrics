## 2. Definition

Within Startup & Venture-Backed Business, Investor Update Response Rate (IURR) is used to gauge the engagement or satisfaction of the people involved. It is a working-level control: thresholds trigger immediate operational response. It is defined as Investors Responding to Updates / Updates Sent; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
IURR = Investors Responding to Updates / Updates Sent
```
