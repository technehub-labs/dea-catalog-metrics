## 2. Definition

Within Culture & Employee Experience, Exit Interview Completion Rate (EICR) is used to gauge conformance to standards, plans, or obligations. The formula is Exit Interviews Conducted / Departures - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Exit Interviews Conducted / Departures
```
