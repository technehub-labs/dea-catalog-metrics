## 2. Definition

A Public Sector & Citizen Service Standard Measures (Deep Dive) indicator, Open Data Publication Compliance (ODPC) quantifies conformance to standards, plans, or obligations. The formula is Datasets Published per Mandate / Mandated Datasets - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Public sector sector.

## 3. Context

Measures whether publishable datasets are released per open data policy. Openness is increasingly a statutory expectation and an innovation enabler. Compliance measured by dataset count can publish empties while withholding the valuable ones. Read with data quality (open data) completeness and freedom of information response timeliness.

## Formula

```
ODPC = Datasets Published per Mandate / Mandated Datasets
```
