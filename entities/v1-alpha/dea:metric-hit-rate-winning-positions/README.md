## 2. Definition

Hit Rate (Winning Positions) (HRWP) captures the economic value created or preserved for organizations tracking investment performance measurement. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Positions with Positive Return / Positions; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Investment management, it is a recognized element of the standard performance toolkit.

## Formula

```
Positions with Positive Return / Positions
```
