## 2. Definition

Within Aerospace & Defense Program Management, Program Risk Exposure Index (PREI) is used to gauge exposure to adverse outcomes. It is computed as Weighted Risk Exposure Score, expressed in index (0-100 or normalized). Its use is concentrated in Aerospace & Defense. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Reduction is the goal, and sustained decreases indicate successful intervention.

## 3. Context

Aggregates program risks - technical, supply, schedule, cost - into a weighted exposure score. It gives leadership a single strategic-risk dial for portfolios of complex programs, and trends concentrate attention before failures crystallize. Index construction is the credibility question: unweighted risk registers and stale scores make the index decorative. Read with technical performance measure variance and cost performance index (Programs) trends for ground truth.
