## 2. Definition

Line Efficiency - Sewing Floor (Deep Dive) (LEF-D) measures how efficiently resources are converted into outputs in the Textile & Apparel (Deep Dive) domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Produced Standard Minutes / Attended Minutes; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Textiles & Apparel, it is a recognized element of the standard performance toolkit.

## Formula

```
Produced Standard Minutes / Attended Minutes
```
