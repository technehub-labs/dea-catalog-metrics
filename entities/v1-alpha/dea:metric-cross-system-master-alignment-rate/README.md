## 2. Definition

A Master Data Management indicator, Cross-System Master Alignment Rate (CSMAR) quantifies the quality of outputs and outcomes. The formula is Subscribing Systems Aligned with Master within Tolerance / Systems - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Subscribing Systems Aligned with Master within Tolerance / Systems
```
