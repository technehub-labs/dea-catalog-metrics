## 2. Definition

Exploratory Testing Hours per Sprint (ETHPS) addresses the quality of outputs and outcomes and is a fixture of software testing & quality engineering reporting. Its calculation is Exploratory Testing Hours / Sprint, measured in hours. Its value drives prioritization and resource reallocation among competing initiatives. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Exploratory Testing Hours / Sprint
```
