## 2. Definition

Tangible Book Value Coverage (TBVC) measures exposure to adverse outcomes in the Valuation & Corporate Finance Standard Measures domain. It is computed as Tangible Book Value / Total Debt, expressed in ratio (x:1 or x). It is applied across virtually every sector. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the tangible asset cushion beneath obligations or per share. Tangible book strips goodwill and intangibles that cannot be sold in distress. Coverage is the liquidation-floor view of the balance sheet. Read with price-to-book ratio (Deep Dive) and debt-to-assets ratio (Deep Dive).

## Formula

```
Tangible Book Value / Total Debt
```
