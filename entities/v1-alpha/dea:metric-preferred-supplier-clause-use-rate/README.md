## 2. Definition

A Contract Lifecycle Management indicator, Preferred Supplier Clause Use Rate (PSCUR) quantifies how efficiently resources are converted into outputs. Its calculation is Negotiations Starting from Preferred Positions / Negotiations, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Negotiations Starting from Preferred Positions / Negotiations
```
