## 2. Definition

Concentrate Quality Penalty Rate (CQPR) addresses the quality of outputs and outcomes and is a fixture of metals & mining operations (deep dive) reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Shipments Incurring Penalty Elements / Shipments, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Its use is concentrated in Metals & Mining.

## Formula

```
Shipments Incurring Penalty Elements / Shipments
```
