## 2. Definition

Within Process Excellence (Lean Six Sigma), Kaizen Implementation Rate (KIR) is used to gauge capability maturity or development. It is computed as Improvement Actions Implemented / Improvement Actions Identified, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of improvement ideas actually implemented. It matters because improvement suggestion volume is meaningless without completion. Implementation can be claimed for cosmetic changes while the substantive idea dies. Read with Sustained Benefit verification and post-implementation drift to confirm implementations hold past the celebration.

## Formula

```
Improvement Actions Implemented / Improvement Actions Identified
```
