## 2. Definition

A Code Quality & Static Analysis indicator, Abstractness Ratio (ABSTR) quantifies the quality of outputs and outcomes. It is defined as Abstract Components / Total Components; the result is stated in percent (%). In Software, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Abstract Components / Total Components
```
