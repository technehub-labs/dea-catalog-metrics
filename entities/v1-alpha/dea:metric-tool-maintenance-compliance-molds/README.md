## 2. Definition

Within Packaging & Plastics, Tool Maintenance Compliance (Molds) (TMC) is used to gauge conformance to standards, plans, or obligations. It is defined as Preventive Tool Maintenance Done on Time / Due; the result is stated in percent (%). In Manufacturing, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

