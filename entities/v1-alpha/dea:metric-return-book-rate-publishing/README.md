## 2. Definition

Within Publishing & News Media, Return Book Rate (Publishing) (RBR-P) is used to gauge exposure to adverse outcomes. The formula is Books Returned / Books Shipped to Retail - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Media & Entertainment sector.

## Formula

```
Books Returned / Books Shipped to Retail
```
