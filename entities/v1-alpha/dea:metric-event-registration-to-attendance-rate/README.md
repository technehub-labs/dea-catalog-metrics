## 2. Definition

Event Registration-to-Attendance Rate (ERAR) measures how effectively a process or entity achieves its intended outcome in the Events & Exhibitions domain. The formula is Attendees / Registrations - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Media & Entertainment sector.

## Formula

```
ERAR = Attendees / Registrations
```
