## 2. Definition

Priority Escalation Accuracy (PEA-IT) measures the quality of outputs and outcomes in the IT Incident & Major Problem Management domain. It is defined as Incidents Correctly Prioritized on Intake / Sampled; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Incidents Correctly Prioritized on Intake / Sampled
```
