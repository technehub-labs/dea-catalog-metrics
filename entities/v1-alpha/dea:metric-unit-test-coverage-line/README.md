## 2. Definition

Within Software Testing & Quality Engineering, Unit Test Coverage - Line (UTCL-QA) is used to gauge the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Lines Covered by Tests / Total Lines, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Lines Covered by Tests / Total Lines
```
