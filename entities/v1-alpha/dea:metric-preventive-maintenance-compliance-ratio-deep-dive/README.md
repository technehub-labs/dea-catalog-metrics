## 2. Definition

Within Reliability & Maintainability Engineering (Deep Dive), Preventive Maintenance Compliance Ratio (Deep Dive) (PMCRD) is used to gauge conformance to standards, plans, or obligations. It is defined as PM Tasks Done in Window / Scheduled PM; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
PM Tasks Done in Window / Scheduled PM
```
