## 2. Definition

Accessibility Accommodation Fulfilment Time (AAFT-D) measures conformance to standards, plans, or obligations in the Diversity, Equity & Inclusion domain. The formula is Days from Accommodation Request to Fulfilment - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
AAFT-D = Days from Accommodation Request to Fulfilment
```
