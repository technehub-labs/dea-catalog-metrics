## 2. Definition

A Credit & Collections Risk (Enterprise) indicator, Approval Rate (Credit Applications) (Deep Dive) (ARDD) quantifies growth over time. Its calculation is Applications Approved / Applications Received, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Applications Approved / Applications Received
```
