## 2. Definition

Within Program & Portfolio Management, Strategic Initiative Funding Fulfilment (SIFF) is used to gauge the economic value created or preserved. Its calculation is Initiatives Funded as Planned / Planned Initiatives, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures whether strategic initiatives receive the funding actually committed to them. Quiet defunding of strategic work to cover operational overruns is the most common strategy-execution failure. Fulfilment measured at allocation rather than actual spend over time misses mid-year raids. Read with portfolio value delivery rate and initiative kill decision timeliness.

## Formula

```
Initiatives Funded as Planned / Planned Initiatives
```
