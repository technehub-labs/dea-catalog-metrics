## 2. Definition

A Knowledge Management (Deep Dive) indicator, Knowledge Curation Cycle Time (KCCT) quantifies how efficiently resources are converted into outputs. It is defined as Days from Capture to Published Curated Article; the result is stated in days. It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula
