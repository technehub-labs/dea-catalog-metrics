## 2. Definition

Paint Shop First Pass Yield (PSFPY) addresses the quality of outputs and outcomes and is a fixture of automotive reporting. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Bodies Passing Paint Inspection First Time / Bodies Painted, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Automotive.

## Formula

```
Bodies Passing Paint Inspection First Time / Bodies Painted
```
