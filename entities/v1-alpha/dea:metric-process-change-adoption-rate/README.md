## 2. Definition

Process Change Adoption Rate (PCAR) measures transformation in the Operating Model & Process Health Deep Dive domain. Its calculation is Staff Using Updated Process within Lead Time / Staff, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Staff Using Updated Process within Lead Time / Staff
```
