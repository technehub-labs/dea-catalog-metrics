## 2. Definition

Defective Parts per Hundred - Audit (Deep Dive) (DPH-D) captures the quality of outputs and outcomes for organizations tracking textile & apparel (deep dive). The formula is Defects Found / Garments Audited x 100 - reported in ratio (x:1 or x). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Textiles & Apparel sector.

## Formula

```
Defects Found / Garments Audited x 100
```
