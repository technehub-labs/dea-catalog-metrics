## 2. Definition

Privacy Incident Recurrence Rate (PIRR) addresses the quality of outputs and outcomes and is a fixture of data privacy & protection reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Incidents of Same Root Cause Recurring / Incidents, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Incidents of Same Root Cause Recurring / Incidents
```
