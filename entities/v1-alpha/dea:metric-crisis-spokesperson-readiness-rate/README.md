## 2. Definition

Within Crisis Management & Emergency Response, Crisis Spokesperson Readiness Rate (CSRR) is used to gauge capability maturity or development. Its calculation is Trained and Current Spokespersons / Designated Spokespersons, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CSRR = Trained and Current Spokespersons / Designated Spokespersons
```
