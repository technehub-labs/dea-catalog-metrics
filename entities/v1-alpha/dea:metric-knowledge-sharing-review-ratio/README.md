## 2. Definition

Within Code Review & Peer Quality, Knowledge Sharing Review Ratio (KSR) is used to gauge capability maturity or development. Its calculation is Cross-Team Reviews / Total Reviews, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Software practice.

## Formula

```
Cross-Team Reviews / Total Reviews
```
