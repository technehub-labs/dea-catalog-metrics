## 2. Definition

Within Retail & E-commerce, Checkout Completion Rate (CCR-R) is used to gauge how effectively a process or entity achieves its intended outcome. It is computed as Completed Checkouts / Checkout Starts, expressed in percent (%). Its use is concentrated in Retail. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Completed Checkouts / Checkout Starts
```
