## 2. Definition

Recruiter Funnel Efficiency (RFE-TA) measures how efficiently resources are converted into outputs in the Talent Acquisition Deep Dive domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Hires per Recruiter per Quarter, expressed in events per thousand or million (scaled). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Hires per Recruiter per Quarter
```
