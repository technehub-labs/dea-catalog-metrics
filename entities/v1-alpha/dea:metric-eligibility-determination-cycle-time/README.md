## 2. Definition

Within Public Sector & Citizen Service Standard Measures (Deep Dive), Eligibility Determination Cycle Time (EDCT) is used to gauge how efficiently resources are converted into outputs. The formula is Days from Application to Eligibility Decision - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Public sector sector.

## Formula

```
Days from Application to Eligibility Decision
```
