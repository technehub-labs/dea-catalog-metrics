## 2. Definition

Interview Panel Diversity Rate (IPDR) measures conformance to standards, plans, or obligations in the Diversity, Equity & Inclusion (Deep Dive) domain. It is computed as Interviews with Diverse Panel / Interviews, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Interviews with Diverse Panel / Interviews
```
