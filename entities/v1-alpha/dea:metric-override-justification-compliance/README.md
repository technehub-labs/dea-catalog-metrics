## 2. Definition

Override Justification Compliance (OJC-AI) measures conformance to standards, plans, or obligations in the AI Governance & Model Risk Management domain. Its calculation is Overrides with Documented Justification / Overrides, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Overrides with Documented Justification / Overrides
```
