## 2. Definition

Within Pharmacy Retail, Medication Adherence Program Enrollment (MAPE) is used to gauge growth over time. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Enrolled Patients / Eligible Patients; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Healthcare, it is a recognized element of the standard performance toolkit.

## Formula

```
Enrolled Patients / Eligible Patients
```
