## 2. Definition

Within Corporate Communications & PR (Deep Dive), Executive Speech Coverage Rate (ESCR-C) is used to gauge conformance to standards, plans, or obligations. It is computed as Executive Engagements Delivered per Plan / Planned, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Executive Engagements Delivered per Plan / Planned
```
