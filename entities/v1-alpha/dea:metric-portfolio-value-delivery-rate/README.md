## 2. Definition

Portfolio Value Delivery Rate (PVDR) measures the economic value created or preserved in the Program & Portfolio Management domain. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Value Realized / Portfolio Investment, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of portfolio investment converted into realized, measured business value. This is the scoreboard of the portfolio office: money in, value out. Value frameworks that score subjectively drift toward optimism. Read with benefits realization rate and portfolio outcome review cadence compliance.

## Formula

```
Value Realized / Portfolio Investment
```
