## 2. Definition

Price Image Index (PII-RT) measures the economic value created or preserved in the Retail Standard Measures domain. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Composite of Key Value Item Price Position vs Competitors, expressed in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Retail & E-commerce.

## 3. Context

Measures customers' perception of the retailer's price position versus competitors. Price image, not actual price, drives store choice. Perceptions surveyed among current customers miss the lost shoppers. Read with price realization rate (Market) and price competitiveness index.

## Formula

```
Composite of Key Value Item Price Position vs Competitors
```
