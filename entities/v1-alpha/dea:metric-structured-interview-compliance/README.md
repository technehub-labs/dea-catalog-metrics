## 2. Definition

A Talent Acquisition Deep Dive indicator, Structured Interview Compliance (SIC-TA) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Interviews Using Structured Guides / Interviews, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Interviews Using Structured Guides / Interviews
```
