## 2. Definition

Sanctions Screening Accuracy (SSA-CM) addresses exposure to adverse outcomes and is a fixture of compliance monitoring & testing reporting. The formula is True Matches Correctly Screened / Screening Population - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
True Matches Correctly Screened / Screening Population
```
