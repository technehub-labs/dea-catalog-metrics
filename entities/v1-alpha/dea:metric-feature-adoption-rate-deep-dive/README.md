## 2. Definition

Feature Adoption Rate (Deep Dive) (FAR-D) captures the engagement or satisfaction of the people involved for organizations tracking software product operations (deep dive). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Users Using Feature / Eligible Users - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Technology sector.

## Formula

```
Users Using Feature / Eligible Users
```
