## 2. Definition

A Process Excellence (Lean Six Sigma) indicator, Standard Work Compliance (SWC) quantifies conformance to standards, plans, or obligations. The formula is Operations Executed per Standard Work / Operations Observed - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Operations Executed per Standard Work / Operations Observed
```
