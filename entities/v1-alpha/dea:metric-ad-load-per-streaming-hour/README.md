## 2. Definition

Within Broadcasting & Streaming Media, Ad Load per Streaming Hour (ALSH) is used to gauge the economic value created or preserved. It is computed as Ad Minutes / Streaming Hours, expressed in minutes. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is concentrated in Media & Entertainment.

## Formula

```
ALSH = Ad Minutes / Streaming Hours
```
