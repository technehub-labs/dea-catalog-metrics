## 2. Definition

Prompt Version Control Adoption (PVCA-LLM) captures conformance to standards, plans, or obligations for organizations tracking generative ai & llm operations. The formula is Prompts under Version Control / Prompts in Production - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Prompts under Version Control / Prompts in Production
```
