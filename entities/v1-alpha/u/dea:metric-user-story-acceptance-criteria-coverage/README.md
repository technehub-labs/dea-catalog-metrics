## 2. Definition

A Requirements Engineering & Product Discovery indicator, User Story Acceptance Criteria Coverage (USACC) quantifies the quality of outputs and outcomes. It is defined as Stories with Clear Acceptance Criteria / Stories; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
USACC = Stories with Clear Acceptance Criteria / Stories
```
