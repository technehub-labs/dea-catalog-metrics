## 2. Definition

UAT Sign-off Cycle Time (UATSCT) measures how efficiently resources are converted into outputs in the Software Testing & Quality Engineering domain. It is defined as Days from UAT Start to Sign-off; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
UATSCT = Days from UAT Start to Sign-off
```
