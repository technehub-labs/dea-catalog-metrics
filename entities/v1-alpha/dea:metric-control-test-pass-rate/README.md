## 2. Definition

Control Test Pass Rate (CTPR-CM) addresses conformance to standards, plans, or obligations and is a fixture of compliance monitoring & testing reporting. It is defined as Controls Passing without Exception / Controls Tested; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Controls Passing without Exception / Controls Tested
```
