## 2. Definition

Within Risk & Compliance, Conflict of Interest Disclosure Rate (COI) is used to gauge conformance to standards, plans, or obligations. It is defined as Required Disclosures Filed / Required Population; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Required Disclosures Filed / Required Population
```
