## 2. Definition

A Medical Practice & Clinical Operations indicator, Patient Access - Third Next Available Appointment (TNAA) quantifies the utilization or availability of capacity. It is a working-level control: thresholds trigger immediate operational response. It is defined as Days to Third Next Available Appointment Slot; the result is stated in days. It should be driven down, since lower readings signal healthier performance. In Healthcare, it is a recognized element of the standard performance toolkit.
