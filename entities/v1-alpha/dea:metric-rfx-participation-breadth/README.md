## 2. Definition

Within Strategic Sourcing & Supplier Performance (Deep Dive), RFx Participation Breadth (RFXPB) is used to gauge how efficiently resources are converted into outputs. Its calculation is Average Bidders per Competitive RFx, measured in count (items per period). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.
