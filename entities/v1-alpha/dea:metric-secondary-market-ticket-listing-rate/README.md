## 2. Definition

Within Sports Clubs & Leagues (Deep Dive), Secondary Market Ticket Listing Rate (SMTL) is used to gauge exposure to adverse outcomes. It is defined as Season Seats Listed for Resale / Season Seats; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. In Sports, it is a recognized element of the standard performance toolkit.

## Formula

```
SMTL = Season Seats Listed for Resale / Season Seats
```
