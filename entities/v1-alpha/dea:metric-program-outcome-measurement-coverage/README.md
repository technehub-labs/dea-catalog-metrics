## 2. Definition

Program Outcome Measurement Coverage (POMC) addresses how effectively a process or entity achieves its intended outcome and is a fixture of nonprofit & donor operations (deep dive) reporting. It is computed as Programs with Measured Outcomes / Programs, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Nonprofit.

## 3. Context

Measures the share of programs with defined, measured outcomes against mission goals. Coverage is the credibility gate for impact claims: funders increasingly require outcome evidence rather than activity reporting, and unmeasured programs cannot demonstrate the value that fundraising sells. Outcome measurement must be proportionate - excessive measurement burden diverts program capacity - so weight by program size. Read with program spend ratio (Deep Dive) and evaluation findings.

## Formula

```
Programs with Measured Outcomes / Programs
```
