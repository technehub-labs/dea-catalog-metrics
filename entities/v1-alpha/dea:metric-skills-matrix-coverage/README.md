## 2. Definition

A Workforce Planning & Productivity indicator, Skills Matrix Coverage (SMC-WF) quantifies capability maturity or development. Its calculation is Roles with Current Skills Matrix / Roles, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Roles with Current Skills Matrix / Roles
```
