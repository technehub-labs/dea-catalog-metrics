## 2. Definition

Dashboard Data Freshness Compliance (DDFC) measures the quality of outputs and outcomes in the Data Science & Analytics Operations domain. It is defined as Dashards Meeting Freshness SLA / Dashboards; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Dashards Meeting Freshness SLA / Dashboards
```
