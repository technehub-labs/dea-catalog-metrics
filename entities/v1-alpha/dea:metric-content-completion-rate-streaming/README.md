## 2. Definition

A Broadcasting & Streaming Media indicator, Content Completion Rate (Streaming) (CCR-S) quantifies the engagement or satisfaction of the people involved. It is defined as Titles Completed / Titles Started; the result is stated in percent (%). In Media & Entertainment, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Titles Completed / Titles Started
```
