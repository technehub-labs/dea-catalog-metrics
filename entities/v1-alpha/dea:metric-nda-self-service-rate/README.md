## 2. Definition

A Legal Operations indicator, NDA Self-Service Rate (NSR-L) quantifies how efficiently resources are converted into outputs. The formula is NDAs Executed without Legal Review / NDAs Executed - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
NDAs Executed without Legal Review / NDAs Executed
```
