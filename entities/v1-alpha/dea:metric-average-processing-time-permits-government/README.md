## 2. Definition

Within Government & Public Administration, Average Processing Time - Permits (Government) (APTP) is used to gauge how efficiently resources are converted into outputs. It is defined as Days from Application to Permit Decision; the result is stated in days. In Public Sector, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.
