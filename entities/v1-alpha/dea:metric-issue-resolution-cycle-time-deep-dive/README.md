## 2. Definition

Issue Resolution Cycle Time (Deep Dive) (IRCT-D) measures how efficiently resources are converted into outputs in the Project Management (Deep Dive) domain. Its calculation is Days from Issue Logging to Closure, measured in days. It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Days from Issue Logging to Closure
```
