## 2. Definition

Within Corporate Communications & PR, Town Hall Participation Rate (THPR) is used to gauge the engagement or satisfaction of the people involved. It is a working-level control: thresholds trigger immediate operational response. It is defined as Attendees / Eligible Employees; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Attendees / Eligible Employees
```
