## 2. Definition

Expert Elicitation Participation Rate (EEPR) measures capability maturity or development in the Emerging Risk & Horizon Scanning domain. It is defined as Panels Conducted per Plan / Planned Panels; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Panels Conducted per Plan / Planned Panels
```
