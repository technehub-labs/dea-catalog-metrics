## 2. Definition

Within Operating Model & Process Health Deep Dive, Operating Model Health Index (OMHI) is used to gauge strategy. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Composite of Alignment, Accountability, Efficiency Subscores; the result is stated in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the composite condition of the operating model across accountability, process, and decision dimensions. A single health signal helps boards track drift between redesigns. Composite indexes can mask a failing dimension behind healthy averages. Read with target operating model realization rate and operating model review cadence compliance (Deep Dive).

## Formula

```
Composite of Alignment, Accountability, Efficiency Subscores
```
