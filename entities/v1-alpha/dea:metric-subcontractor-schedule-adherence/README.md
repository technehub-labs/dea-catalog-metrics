## 2. Definition

A Construction Contracting (Deep Dive) indicator, Subcontractor Schedule Adherence (SSA-C) quantifies conformance to standards, plans, or obligations. The formula is Subcontractor Tasks on Schedule / Tasks - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Construction sector.

## Formula

```
Subcontractor Tasks on Schedule / Tasks
```
