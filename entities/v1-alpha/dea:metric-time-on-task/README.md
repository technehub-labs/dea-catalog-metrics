## 2. Definition

Time on Task (TOT-UX) captures how efficiently resources are converted into outputs for organizations tracking ux & design systems. The formula is Median Time for Users to Complete Standard Task - reported in seconds. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Median Time for Users to Complete Standard Task
```
