## 2. Definition

Time to Staff Engagement (TSE) measures how efficiently resources are converted into outputs in the Professional Services domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Days from Engagement Win to Team Mobilized, measured in days. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Professional services practice.

## Formula

```
TSE = Days from Engagement Win to Team Mobilized
```
