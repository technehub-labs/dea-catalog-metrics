## 2. Definition

Within Metals & Mining Operations (Deep Dive), Mill Throughput per Operating Hour (MTOH) is used to gauge the utilization or availability of capacity. It is defined as Tonnes Milled / Operating Hours; the result is stated in ratio (x:1 or x). In Metals & Mining, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Tonnes Milled / Operating Hours
```
