## 2. Definition

Within Market Structure & Economics Standard Measures, Bid Win Rate (Deep Dive) (BWRDD) is used to gauge growth over time. It is defined as Deals Won / Deals Bid; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Deals Won / Deals Bid
```
