## 2. Definition

Within Field Service & Asset Performance, Repeat Visit Rate (Field) (RVR-F) is used to gauge the quality of outputs and outcomes. Its calculation is Jobs Requiring Return Visit / Jobs, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Jobs Requiring Return Visit / Jobs
```
