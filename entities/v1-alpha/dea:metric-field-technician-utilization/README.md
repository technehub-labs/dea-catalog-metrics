## 2. Definition

A Field Service & Asset Performance indicator, Field Technician Utilization (FTU-F) quantifies how efficiently resources are converted into outputs. It is defined as Billable or Value-Add Hours / Paid Hours; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Billable or Value-Add Hours / Paid Hours
```
