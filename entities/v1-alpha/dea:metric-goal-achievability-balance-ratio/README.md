## 2. Definition

Goal Achievability Balance Ratio (GABR-OKR) addresses the quality of outputs and outcomes and is a fixture of enterprise okr & performance management reporting. It is defined as Key Results Set at Appropriate Ambition Level / Key Results; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Key Results Set at Appropriate Ambition Level / Key Results
```
