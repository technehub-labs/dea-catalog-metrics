## 2. Definition

Exception Approval Cycle Time (EACT-IR) measures how efficiently resources are converted into outputs in the Investment Risk & Middle Office Operations domain. The formula is Days from Risk Exception Raised to Approval Decision - reported in days. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Investment management sector.

## Formula

```
Days from Risk Exception Raised to Approval Decision
```
