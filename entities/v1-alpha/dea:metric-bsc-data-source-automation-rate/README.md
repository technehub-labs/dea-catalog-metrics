## 2. Definition

BSC Data Source Automation Rate (BSAR) addresses how efficiently resources are converted into outputs and is a fixture of balanced scorecard implementation & review reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Automated Data Feeds / Measure Feeds; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Automated Data Feeds / Measure Feeds
```
