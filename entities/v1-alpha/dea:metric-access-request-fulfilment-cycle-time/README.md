## 2. Definition

Access Request Fulfilment Cycle Time (ARFCT) measures how efficiently resources are converted into outputs in the Identity & Access Management Operations domain. It is defined as Hours from Request to Access Granted; the result is stated in hours. It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Hours from Request to Access Granted
```
