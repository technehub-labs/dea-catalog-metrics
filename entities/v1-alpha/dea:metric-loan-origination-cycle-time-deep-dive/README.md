## 2. Definition

A Real Estate & Mortgage Standard Measures indicator, Loan Origination Cycle Time (Deep Dive) (LOCTDD) quantifies how efficiently resources are converted into outputs. It provides the day-to-day signal that a process is running as designed. Its calculation is Days from Application to Closing, measured in days. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Real estate practice.
