## 2. Definition

Field Mobility App Adoption Rate (FMAAR) captures capability maturity or development for organizations tracking field maintenance & technical field service (deep dive). It is computed as Technicians Using Digital Work Order App / Technicians, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Technicians Using Digital Work Order App / Technicians
```
