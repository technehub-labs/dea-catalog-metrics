## 2. Definition

Static Analysis Gate Pass Rate (SAGPR) captures conformance to standards, plans, or obligations for organizations tracking software development - coding & engineering practices. It is defined as Builds Passing Static Analysis Gate / Builds; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Builds Passing Static Analysis Gate / Builds
```
