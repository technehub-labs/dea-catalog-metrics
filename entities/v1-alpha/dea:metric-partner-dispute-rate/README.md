## 2. Definition

Within Alliances & Partnerships Management, Partner Dispute Rate (PDR-AP) is used to gauge exposure to adverse outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Formal Disputes per Alliance per Year; the result is stated in count (items per period). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Formal Disputes per Alliance per Year
```
