## 2. Definition

Manager 1:1 Cadence Compliance (MCC) measures the engagement or satisfaction of the people involved in the Employee Wellbeing domain. Its calculation is Direct Reports Receiving Regular 1:1s / Direct Reports, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Direct Reports Receiving Regular 1:1s / Direct Reports
```
