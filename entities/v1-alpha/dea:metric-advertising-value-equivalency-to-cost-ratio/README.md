## 2. Definition

Within Corporate Communications & PR (Deep Dive), Advertising Value Equivalency to Cost Ratio (AVECR) is used to gauge the economic value created or preserved. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Earned Media Value / Program Cost, expressed in ratio (x:1 or x). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Earned Media Value / Program Cost
```
