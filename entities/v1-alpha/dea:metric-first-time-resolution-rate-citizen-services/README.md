## 2. Definition

First-Time Resolution Rate (Citizen Services) (FTRCS) measures the quality of outputs and outcomes in the Public Sector & Citizen Service Standard Measures (Deep Dive) domain. Its calculation is Citizen Requests Resolved without Follow-up / Requests, measured in percent (%). It originates from and is most used in Public sector practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Citizen Requests Resolved without Follow-up / Requests
```
