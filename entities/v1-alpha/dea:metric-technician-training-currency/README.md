## 2. Definition

Technician Training Currency (TTC-F) measures capability maturity or development in the Field Service & Asset Performance domain. The formula is Technicians with Current Certifications / Technicians - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
TTC-F = Technicians with Current Certifications / Technicians
```
