## 2. Definition

Project Cost Recovery Rate (PCRR-ITFM) captures conformance to standards, plans, or obligations for organizations tracking it financial management & technology budgeting. The formula is Capitalized Project Costs Recovered per Policy / Eligible - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
PCRR-ITFM = Capitalized Project Costs Recovered per Policy / Eligible
```
