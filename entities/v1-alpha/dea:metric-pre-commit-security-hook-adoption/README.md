## 2. Definition

Pre-Commit Security Hook Adoption (PCSHA) measures conformance to standards, plans, or obligations in the DevSecOps & Application Security Engineering domain. It is defined as Developers Using Pre-Commit Security Hooks / Developers; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Developers Using Pre-Commit Security Hooks / Developers
```
