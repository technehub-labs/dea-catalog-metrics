## 2. Definition

Crisis Simulation Cadence Compliance (CSCC) measures conformance to standards, plans, or obligations in the Crisis Management & Emergency Response domain. It is computed as Required Simulations Held per Year / Required, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures whether crisis simulations run on the committed schedule at realistic depth. Simulations are the only safe way to find activation failures. Tabletop-only programs never test muscle memory. Read with tabletop exercise completion rate and incident command structure deployment rate.

## Formula

```
Required Simulations Held per Year / Required
```
