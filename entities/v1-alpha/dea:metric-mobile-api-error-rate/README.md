## 2. Definition

A Mobile & Client Development indicator, Mobile API Error Rate (MAER) quantifies the quality of outputs and outcomes. It is defined as Client-Reported Errors / Client Requests; the result is stated in percent (%). In Software, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Client-Reported Errors / Client Requests
```
