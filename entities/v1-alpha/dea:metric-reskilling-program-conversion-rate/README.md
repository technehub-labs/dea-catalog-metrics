## 2. Definition

Reskilling Program Conversion Rate (RPCR-LD) captures the economic value created or preserved for organizations tracking learning & development effectiveness (deep dive). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Participants Redeployed to New Roles / Participants, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how many program participants actually transition into the target roles. Conversion is the only honest test of reskilling investment. Low conversion usually reflects demand-side planning, not participant failure. Read with internal mobility fill ratio and redeployment rate.

## Formula

```
Participants Redeployed to New Roles / Participants
```
