## 2. Definition

Project Team Attrition Rate (Deep Dive) (PTAR-D) measures exposure to adverse outcomes in the Project Management (Deep Dive) domain. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Team Members Departing Mid-Project / Team, measured in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Team Members Departing Mid-Project / Team
```
