## 2. Definition

Media Response Time (Deep Dive) (MRT-D) captures how efficiently resources are converted into outputs for organizations tracking corporate communications & pr (deep dive). It provides the day-to-day signal that a process is running as designed. Its calculation is Hours to Respond to Media Inquiry, measured in hours. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula
