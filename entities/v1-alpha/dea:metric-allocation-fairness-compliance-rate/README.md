## 2. Definition

Allocation Fairness Compliance Rate (AFCR) captures conformance to standards, plans, or obligations for organizations tracking supply chain standard measures (deep dive). It is defined as Allocations Following Agreed Rules / Allocations; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Allocations Following Agreed Rules / Allocations
```
