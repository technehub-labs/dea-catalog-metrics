## 2. Definition

Attrition Driver Insight Coverage (ADIC) measures the quality of outputs and outcomes in the Employee Engagement & Culture (Deep Dive) domain. It is defined as Leavers with Coded Attributed Drivers / Leavers; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
ADIC = Leavers with Coded Attributed Drivers / Leavers
```
