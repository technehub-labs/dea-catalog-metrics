## 2. Definition

Look-through Transparency Coverage (LTTC-IM) measures conformance to standards, plans, or obligations in the Investment Management - Portfolio Operations domain. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Holdings with Full Transparency / Holdings - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Financial Services sector.

## Formula

```
Holdings with Full Transparency / Holdings
```
