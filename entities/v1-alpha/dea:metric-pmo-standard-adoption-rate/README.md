## 2. Definition

PMO Standard Adoption Rate (PSAR) captures conformance to standards, plans, or obligations for organizations tracking pmo & portfolio governance. The formula is Projects Using Mandated Methods / Projects - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PSAR = Projects Using Mandated Methods / Projects
```
