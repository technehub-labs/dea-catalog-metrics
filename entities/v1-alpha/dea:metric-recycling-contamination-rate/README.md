## 2. Definition

Recycling Contamination Rate (RCR-E2) captures environmental and social sustainability performance for organizations tracking cleaning & environmental services. It is computed as Contaminated Recycling Loads / Loads, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is concentrated in Facility Services.

## Formula

```
Contaminated Recycling Loads / Loads
```
