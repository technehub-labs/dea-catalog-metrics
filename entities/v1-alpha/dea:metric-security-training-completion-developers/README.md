## 2. Definition

A Application Security (AppSec) indicator, Security Training Completion (Developers) (STCD) quantifies capability maturity or development. It is computed as Developers Completing Annual Security Training / Developers, expressed in percent (%). Its use is concentrated in Software. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Developers Completing Annual Security Training / Developers
```
