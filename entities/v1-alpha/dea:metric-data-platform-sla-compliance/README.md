## 2. Definition

A Database & Data Platform Operations indicator, Data Platform SLA Compliance (DPSLA) quantifies conformance to standards, plans, or obligations. It is computed as Platform SLA Targets Met / Targets, expressed in percent (%). Its use is concentrated in Software. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Platform SLA Targets Met / Targets
```
