## 2. Definition

Ecosystem Coverage Ratio (ECR-AP) addresses capability maturity or development and is a fixture of alliances & partnerships management reporting. The formula is Target Ecosystem Roles Filled by Partners / Target Roles - reported in percent (%). It is applied across virtually every sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures how completely the partner ecosystem covers the capabilities and geographies the strategy requires. Coverage is what turns partnerships from opportunistic to architectural. Coverage counted as signed agreements rather than active capability is nominal. Read with channel coverage of target markets and ecosystem gravity score.

## Formula

```
Target Ecosystem Roles Filled by Partners / Target Roles
```
