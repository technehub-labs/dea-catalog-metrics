## 2. Definition

A Education & Training (Deep Dive) indicator, Grading Turnaround Time (GTT) quantifies how efficiently resources are converted into outputs. The formula is Days from Assessment to Grade Release - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Education sector.

## Formula

```
Days from Assessment to Grade Release
```
