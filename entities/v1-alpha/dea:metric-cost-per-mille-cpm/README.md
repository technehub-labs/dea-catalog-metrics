## 2. Definition

Within Marketing & Advertising Standard Measures (Deep Dive), Cost per Mille (CPM) (CPMAD) is used to gauge how efficiently resources are converted into outputs. It is a working-level control: thresholds trigger immediate operational response. It is defined as Spend / Impressions x 1,000; the result is stated in currency per unit. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Spend / Impressions x 1,000
```
