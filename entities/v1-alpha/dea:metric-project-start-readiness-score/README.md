## 2. Definition

Project Start Readiness Score (PSRS-PM) addresses conformance to standards, plans, or obligations and is a fixture of project management (deep dive) reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Readiness Checklist Items Complete at Kickoff / Items - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Readiness Checklist Items Complete at Kickoff / Items
```
