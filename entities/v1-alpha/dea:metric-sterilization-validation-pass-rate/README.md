## 2. Definition

Sterilization Validation Pass Rate (SVPR) measures the quality of outputs and outcomes in the Medical Devices domain. Its calculation is Sterilization Cycles Meeting Validation Criteria / Cycles, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Medical devices practice.

## Formula

```
Sterilization Cycles Meeting Validation Criteria / Cycles
```
