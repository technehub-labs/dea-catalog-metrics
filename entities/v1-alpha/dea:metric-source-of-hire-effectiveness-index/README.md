## 2. Definition

Source of Hire Effectiveness Index (SOHEI) measures how efficiently resources are converted into outputs in the Talent Acquisition Deep Dive domain. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Quality-Retention Adjusted Yield per Sourcing Channel; the result is stated in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how well each recruiting channel produces hires who perform and stay. Channel value differs enormously beyond cost-per-hire: some sources produce fast hires who churn. Effectiveness requires linking hire source to later performance and retention data. Read with quality of hire index and first-year retention rate (New Hires).

## Formula

```
SOHEI = Quality-Retention Adjusted Yield per Sourcing Channel
```
