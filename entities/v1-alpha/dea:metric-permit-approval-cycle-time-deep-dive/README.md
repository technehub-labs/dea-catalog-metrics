## 2. Definition

Permit Approval Cycle Time (Deep Dive) (PACTDD) measures how efficiently resources are converted into outputs in the Public Sector & Citizen Service Standard Measures (Deep Dive) domain. It is defined as Days from Complete Application to Decision; the result is stated in days. It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Public sector, it is a recognized element of the standard performance toolkit.
