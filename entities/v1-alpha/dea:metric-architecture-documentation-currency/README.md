## 2. Definition

Architecture Documentation Currency (ADOC-SA) measures the quality of outputs and outcomes in the Software Architecture & Technical Design domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Docs Updated within Two Releases / Docs; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Docs Updated within Two Releases / Docs
```
