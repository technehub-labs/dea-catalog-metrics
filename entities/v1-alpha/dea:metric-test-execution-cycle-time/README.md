## 2. Definition

A Software Testing & Quality Engineering indicator, Test Execution Cycle Time (TECT-QA) quantifies how efficiently resources are converted into outputs. Its calculation is Duration of Full Regression Suite, measured in hours. It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.
