## 2. Definition

Process Ownership Coverage (Deep Dive) (POCD) captures governance for organizations tracking operating model & process health deep dive. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Value Streams with Named Process Owner / Value Streams - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of end-to-end processes with a named, accountable owner holding genuine decision rights. Owned processes improve by design; unowned ones drift. Ownership without metric authority is sponsorship. Read with process ownership coverage and end-to-end service accountability coverage.

## Formula

```
Value Streams with Named Process Owner / Value Streams
```
