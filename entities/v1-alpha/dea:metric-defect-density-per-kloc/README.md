## 2. Definition

Defect Density per KLOC (DDKLOC) addresses the quality of outputs and outcomes and is a fixture of software development - coding & engineering practices reporting. The formula is Defects per 1,000 Lines of Code - reported in events per thousand or million (scaled). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.
