## 2. Definition

Carve-Out Standalone Cost Readiness (CSCR) addresses capability maturity or development and is a fixture of mergers & acquisitions reporting. It is computed as Readiness Checklist Items Complete / Items, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Readiness Checklist Items Complete / Items
```
