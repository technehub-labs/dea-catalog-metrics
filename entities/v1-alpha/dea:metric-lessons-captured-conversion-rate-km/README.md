## 2. Definition

Lessons Captured Conversion Rate (KM) (LCCR) captures capability maturity or development for organizations tracking knowledge management (deep dive). It is computed as Retrospectives Converted to Knowledge Articles / Retrospectives, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Retrospectives Converted to Knowledge Articles / Retrospectives
```
