## 2. Definition

Passive Candidate Conversion Rate (PCCR) addresses how efficiently resources are converted into outputs and is a fixture of talent acquisition deep dive reporting. It is defined as Sourced Passive Candidates Entering Process / Contacted; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PCCR = Sourced Passive Candidates Entering Process / Contacted
```
