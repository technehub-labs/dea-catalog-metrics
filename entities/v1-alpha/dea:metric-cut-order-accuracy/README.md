## 2. Definition

Within Textile & Apparel, Cut Order Accuracy (COA-T) is used to gauge the quality of outputs and outcomes. Its calculation is Cut Pieces Meeting Specification / Pieces Cut, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Textile & apparel practice.

## Formula

```
Cut Pieces Meeting Specification / Pieces Cut
```
