## 2. Definition

Watchlist Triage Ratio (WTR) measures how efficiently resources are converted into outputs in the Emerging Risk & Horizon Scanning domain. It is computed as Watchlist Items Promoted to Active Risk / Watchlist Items, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Watchlist Items Promoted to Active Risk / Watchlist Items
```
