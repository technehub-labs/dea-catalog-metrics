## 2. Definition

Facility Work Order First-Time Fix Rate (Deep Dive) (FWOF-D) captures the quality of outputs and outcomes for organizations tracking facility management & workplace (deep dive). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Work Orders Resolved on First Visit / Work Orders, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Work Orders Resolved on First Visit / Work Orders
```
