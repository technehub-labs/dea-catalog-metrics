## 2. Definition

Due Diligence Cycle Time (DDCT) measures how efficiently resources are converted into outputs in the Mergers & Acquisitions domain. The formula is Days from Data Room Open to Diligence Report - reported in days. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Data Room Open to Diligence Report
```
