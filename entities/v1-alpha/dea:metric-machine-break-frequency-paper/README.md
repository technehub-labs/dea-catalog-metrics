## 2. Definition

Within Pulp, Paper & Forest Products, Machine Break Frequency (Paper) (MBF-P) is used to gauge the quality of outputs and outcomes. The formula is Breaks per 1,000 Machine Hours - reported in events per thousand or million (scaled). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Manufacturing sector.

## Formula

```
Breaks per 1,000 Machine Hours
```
