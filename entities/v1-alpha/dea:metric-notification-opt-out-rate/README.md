## 2. Definition

A Web & Digital Analytics Standard Measures indicator, Notification Opt-Out Rate (NOOR) quantifies the retention of customers, users, or assets over time. Its calculation is Users Disabling Notifications / Notified Users, measured in percent (%). It originates from and is most used in Digital product practice. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
NOOR = Users Disabling Notifications / Notified Users
```
