## 2. Definition

LLM Latency - First Token (LLMFTL) measures the quality of outputs and outcomes in the Generative AI & LLM Operations domain. Its calculation is Milliseconds to First Generated Token, measured in milliseconds (ms). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.
