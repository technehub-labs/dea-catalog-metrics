## 2. Definition

Schedule Adherence Rate (Contact Center) (SAR-CC) addresses conformance to standards, plans, or obligations and is a fixture of contact center standard measures (deep dive) reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Time on Scheduled Activities / Scheduled Time; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Time on Scheduled Activities / Scheduled Time
```
