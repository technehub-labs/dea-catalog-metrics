## 2. Definition

Disaster Relief Disbursement Speed (DRDS) measures how effectively a process or entity achieves its intended outcome in the Government & Public Administration domain. It is defined as Days from Declaration to First Relief Payment; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Public Sector, it is a recognized element of the standard performance toolkit.

## Formula

```
Days from Declaration to First Relief Payment
```
