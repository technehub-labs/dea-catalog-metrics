## 2. Definition

A Media & Entertainment indicator, Cost per Ad-Impression (CPM) quantifies how efficiently resources are converted into outputs. Its calculation is Ad Campaign Cost / Impressions x 1,000, measured in currency per unit. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Media & entertainment practice.

## Formula

```
Ad Campaign Cost / Impressions x 1,000
```
