## 2. Definition

Average Speed of Answer (Contact Center) (ASA-CC) measures the quality of outputs and outcomes in the Contact Center Standard Measures (Deep Dive) domain. Its calculation is Seconds Waiting before Agent Answer, measured in seconds. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.
