## 2. Definition

Tariff Classification Accuracy (TCA) measures conformance to standards, plans, or obligations in the International Trade & Customs domain. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Lines Correctly Classified / Lines Audited - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Logistics & Trade sector.

## Formula

```
Lines Correctly Classified / Lines Audited
```
