## 2. Definition

Within Veterinary & Animal Health, Stock Loss Rate (Pharmacy - Vet) (SLR-V) is used to gauge how efficiently resources are converted into outputs. Its calculation is Expired or Lost Inventory Value / Inventory Value, measured in percent (%). It originates from and is most used in Healthcare practice. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Expired or Lost Inventory Value / Inventory Value
```
