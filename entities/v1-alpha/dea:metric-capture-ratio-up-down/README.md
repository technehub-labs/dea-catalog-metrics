## 2. Definition

Capture Ratio (Up/Down) (CRUD) captures exposure to adverse outcomes for organizations tracking investment performance measurement. It is defined as Upside Capture / Downside Capture; the result is stated in ratio (x:1 or x). In Investment management, it is a recognized element of the standard performance toolkit. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the paired ratio of upside captured to downside captured versus the benchmark. The pair, not either number alone, describes the return asymmetry managers sell. Monthly computation obscures intra-month behavior. Read with downside capture ratio and upside capture ratio.

## Formula

```
Upside Capture / Downside Capture
```
