## 2. Definition

Documentation Comment Coverage (DCC-SD) captures the quality of outputs and outcomes for organizations tracking software development - coding & engineering practices. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Public APIs with Documentation / Public APIs - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Public APIs with Documentation / Public APIs
```
