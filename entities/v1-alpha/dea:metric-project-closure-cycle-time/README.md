## 2. Definition

Project Closure Cycle Time (PCCT-PM) addresses how efficiently resources are converted into outputs and is a fixture of project management (deep dive) reporting. The formula is Days from Final Deliverable to Formal Closure - reported in days. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Final Deliverable to Formal Closure
```
