## 2. Definition

Care Plan Review Currency (CPRC) addresses the quality of outputs and outcomes and is a fixture of medical practice & clinical operations reporting. Its calculation is Care Plans Reviewed within Interval / Care Plans, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Healthcare practice.

## Formula

```
Care Plans Reviewed within Interval / Care Plans
```
