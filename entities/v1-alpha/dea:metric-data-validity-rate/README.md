## 2. Definition

Data Validity Rate (DVR-DQ) captures the quality of outputs and outcomes for organizations tracking data quality management. It is a working-level control: thresholds trigger immediate operational response. It is defined as Values Passing Format and Range Rules / Values; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Values Passing Format and Range Rules / Values
```
