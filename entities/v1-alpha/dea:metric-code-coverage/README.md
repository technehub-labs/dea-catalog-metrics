## 2. Definition

Code Coverage (CC) measures the quality of outputs and outcomes in the Software Engineering domain. The formula is Covered Lines or Branches / Total Lines or Branches - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CC = Covered Lines or Branches / Total Lines or Branches
```
