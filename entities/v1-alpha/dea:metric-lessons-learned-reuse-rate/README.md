## 2. Definition

Lessons Learned Reuse Rate (LLRR-PM) addresses capability maturity or development and is a fixture of project management (deep dive) reporting. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Projects Citing Prior Lessons / New Projects, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how often prior lessons demonstrably shape later project decisions. Reuse, not capture, is where learning pays. Reuse is hard to detect and often self-reported. Read with lessons learned capture rate and estimate accuracy trends.

## Formula

```
Projects Citing Prior Lessons / New Projects
```
