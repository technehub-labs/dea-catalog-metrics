## 2. Definition

Training Currency Rate (Security) (TCR-S) addresses capability maturity or development and is a fixture of security services & guarding reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Guards with Current Training / Guards; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Security, it is a recognized element of the standard performance toolkit.

## Formula

```
Guards with Current Training / Guards
```
