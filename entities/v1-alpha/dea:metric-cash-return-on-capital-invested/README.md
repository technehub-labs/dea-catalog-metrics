## 2. Definition

Within Valuation & Corporate Finance Standard Measures, Cash Return on Capital Invested (CROCI) is used to gauge the economic value created or preserved. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as After-Tax Pre-Financing Cash Flow / Gross Invested Capital, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures cash flow returns relative to invested capital. Cash returns strip accounting noise from the return question. Invested-capital definitions vary and drive comparability. Read with cash flow return on investment (Deep Dive) and ROIC-WACC spread.

## Formula

```
After-Tax Pre-Financing Cash Flow / Gross Invested Capital
```
