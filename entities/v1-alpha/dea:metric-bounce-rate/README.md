## 2. Definition

Bounce Rate (BounceR) measures the engagement or satisfaction of the people involved in the Marketing domain. It is defined as Single-Page Sessions / Total Sessions; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Single-Page Sessions / Total Sessions
```
