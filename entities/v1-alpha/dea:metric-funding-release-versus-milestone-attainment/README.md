## 2. Definition

Funding Release versus Milestone Attainment (FRVMA) measures conformance to standards, plans, or obligations in the Program & Portfolio Management domain. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Funding Tranches Released on Milestone Achievement / Tranches, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how tightly funding tranches track demonstrated milestone progress. Release ahead of attainment funds failure; release behind it starves progress. Milestone definitions that are easy to game (documents delivered) break the linkage. Read with strategic initiative funding fulfilment and benefits realization rate.

## Formula

```
Funding Tranches Released on Milestone Achievement / Tranches
```
