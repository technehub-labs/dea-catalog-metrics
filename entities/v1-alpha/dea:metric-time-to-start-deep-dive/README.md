## 2. Definition

Time to Start (Deep Dive) (TTSDD) addresses how efficiently resources are converted into outputs and is a fixture of talent acquisition deep dive reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Days from Offer Acceptance to First Day, measured in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Days from Offer Acceptance to First Day
```
