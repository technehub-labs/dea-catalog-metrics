## 2. Definition

Supplier Defect Escape Rate (Aerospace) (SDER) measures the quality of outputs and outcomes in the Aerospace & Defense Program Management domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Supplier Defects Found Downstream / Receipts; the result is stated in events per thousand or million (scaled). It should be driven down, since lower readings signal healthier performance. In Aerospace & Defense, it is a recognized element of the standard performance toolkit.

## Formula

```
Supplier Defects Found Downstream / Receipts
```
