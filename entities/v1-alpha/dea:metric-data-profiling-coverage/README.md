## 2. Definition

Data Profiling Coverage (DPROFC) measures the quality of outputs and outcomes in the Data Quality Management domain. It is defined as Critical Tables Profiled in Period / Critical Tables; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Critical Tables Profiled in Period / Critical Tables
```
