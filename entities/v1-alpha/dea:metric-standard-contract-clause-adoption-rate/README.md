## 2. Definition

Standard Contract Clause Adoption Rate (SCCA) addresses how efficiently resources are converted into outputs and is a fixture of legal operations reporting. It is computed as Agreements using Standard Positions / Agreements, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of executed contracts using approved standard clauses and templates rather than negotiated deviations. Standard clauses compress cycle time and reduce risk drift, since every bespoke negotiation is a new place for error. Watch for adoption undermined by lawyer preference for personal precedent libraries, and for deviation logging that is incomplete. Read with contract cycle time and deviation-approval compliance.

## Formula

```
Agreements using Standard Positions / Agreements
```
