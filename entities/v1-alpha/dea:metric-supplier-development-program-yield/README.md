## 2. Definition

Within Strategic Sourcing & Supplier Performance (Deep Dive), Supplier Development Program Yield (SDPY) is used to gauge capability maturity or development. It is defined as Suppliers Improving Tier after Program / Program Suppliers; the result is stated in percent (%). It is applied across virtually every sector. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures how much supplier capability improvement the development programs actually produce. Developed suppliers are how strategic categories escape the spot market. Yield measured by activity completion rather than supplier performance change is program vanity. Read with supplier performance improvement rate and supplier innovation contribution rate.

## Formula

```
Suppliers Improving Tier after Program / Program Suppliers
```
