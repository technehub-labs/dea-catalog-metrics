## 2. Definition

Attribution Residual (ATTR) addresses the quality of outputs and outcomes and is a fixture of investment performance measurement reporting. It is computed as Unexplained Return after Factor Attribution, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is concentrated in Investment management.

## Formula

```
Unexplained Return after Factor Attribution
```
