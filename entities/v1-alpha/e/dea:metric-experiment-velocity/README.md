## 2. Definition

Experiment Velocity (EXPV) addresses capability maturity or development and is a fixture of web & digital analytics standard measures reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Experiments Concluded with Decision per Period; the result is stated in count (items per period). The objective is neither maximization nor minimization but staying within an agreed operating band. In Digital product, it is a recognized element of the standard performance toolkit.

## Formula

```
EXPV = Experiments Concluded with Decision per Period
```
