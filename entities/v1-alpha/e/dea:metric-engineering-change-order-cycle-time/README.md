## 2. Definition

Engineering Change Order Cycle Time (ECOT) measures how efficiently resources are converted into outputs in the Engineering & Design domain. It is defined as Days from ECR to ECO Implementation; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
ECOT = Days from ECR to ECO Implementation
```
