## 2. Definition

Escalation Resolution Cycle Time (ERCT-P) measures how efficiently resources are converted into outputs in the PMO & Portfolio Governance domain. It is defined as Days from Escalation to Decision; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
ERCT-P = Days from Escalation to Decision
```
