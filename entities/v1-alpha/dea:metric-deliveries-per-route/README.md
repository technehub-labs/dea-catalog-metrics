## 2. Definition

Within Logistics & Transportation, Deliveries per Route (DPR) is used to gauge how efficiently resources are converted into outputs. It is defined as Total Deliveries / Total Routes; the result is stated in ratio (x:1 or x). In Logistics, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Total Deliveries / Total Routes
```
