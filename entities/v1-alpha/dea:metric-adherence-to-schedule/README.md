## 2. Definition

A Contact Center indicator, Adherence to Schedule (SCH-AD) quantifies conformance to standards, plans, or obligations. Its calculation is Time Working as Scheduled / Scheduled Time, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Time Working as Scheduled / Scheduled Time
```
