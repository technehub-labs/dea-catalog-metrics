## 2. Definition

A Records & Information Management indicator, Digital Repository Availability (DRA-RM) quantifies the quality of outputs and outcomes. Its calculation is Uptime of Records Repository, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Uptime of Records Repository
```
