## 2. Definition

Incident Triage Accuracy (ITA-IT) measures the quality of outputs and outcomes in the IT Incident & Major Problem Management domain. The formula is Correct Routing on First Assignment / Sampled - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Correct Routing on First Assignment / Sampled
```
