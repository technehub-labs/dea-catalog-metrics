## 2. Definition

A Process Capability & Six Sigma (Deep Dive) indicator, Defect Opportunity Density (DOD) quantifies the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Defect Opportunities per Unit; the result is stated in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. In Manufacturing, it is a recognized element of the standard performance toolkit.
