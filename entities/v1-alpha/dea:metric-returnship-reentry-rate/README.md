## 2. Definition

Returnship Reentry Rate (RRR-DEI) addresses capability maturity or development and is a fixture of diversity, equity & inclusion (deep dive) reporting. Its calculation is Reentry Program Participants Converted to Roles / Participants, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Reentry Program Participants Converted to Roles / Participants
```
