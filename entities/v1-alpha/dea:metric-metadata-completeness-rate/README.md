## 2. Definition

Within Data Governance & Stewardship, Metadata Completeness Rate (MCDR) is used to gauge the quality of outputs and outcomes. The formula is Required Metadata Fields Populated / Required Fields - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
MCDR = Required Metadata Fields Populated / Required Fields
```
