## 2. Definition

Within Real Estate Portfolio & Property Management, Facility Condition Index (Property) (FCI-P) is used to gauge the utilization or availability of capacity. It is defined as Deferred Maintenance Backlog / Replacement Value; the result is stated in ratio (x:1 or x). Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. In Real Estate, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures the physical condition of assets against renewal and maintenance standards - deferred maintenance backlog relative to replacement value. It quantifies the classic real-estate temptation: deferring capex flatters cash flow while quietly accruing a liability that capitalizes into valuation at exit. Inspection currency and backlog valuation drive credibility. Read with reactive-versus-planned maintenance ratios and asset capex plans.

## Formula

```
Deferred Maintenance Backlog / Replacement Value
```
