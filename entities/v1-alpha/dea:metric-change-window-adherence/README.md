## 2. Definition

Change Window Adherence (CWA-NW) measures conformance to standards, plans, or obligations in the Network Change & Configuration Management domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Changes Completed within Approved Window / Changes, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Changes Completed within Approved Window / Changes
```
