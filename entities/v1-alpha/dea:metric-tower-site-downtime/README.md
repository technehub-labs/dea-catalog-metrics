## 2. Definition

Tower Site Downtime (TSD) addresses the quality of outputs and outcomes and is a fixture of telecommunications reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Site Unavailability Hours per Period, measured in hours. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Telecommunications practice.

## Formula

```
Site Unavailability Hours per Period
```
