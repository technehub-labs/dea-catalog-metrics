## 2. Definition

Agent Attrition Rate (Contact Center) (Deep Dive) (AARDD) captures the retention of customers, users, or assets over time for organizations tracking contact center standard measures (deep dive). It is computed as Voluntary Agent Leavers / Average Agents, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Voluntary Agent Leavers / Average Agents
```
