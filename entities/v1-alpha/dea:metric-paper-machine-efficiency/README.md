## 2. Definition

Paper Machine Efficiency (PME) measures the utilization or availability of capacity in the Pulp, Paper & Forest Products domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Good Production Time / Available Time, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Manufacturing.

## Formula

```
Good Production Time / Available Time
```
