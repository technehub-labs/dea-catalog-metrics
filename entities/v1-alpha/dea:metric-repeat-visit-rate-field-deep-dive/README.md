## 2. Definition

Repeat Visit Rate - Field (Deep Dive) (RVR-D) captures the quality of outputs and outcomes for organizations tracking field maintenance & technical field service (deep dive). It is computed as Jobs Requiring Return Visit / Jobs, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Jobs Requiring Return Visit / Jobs
```
