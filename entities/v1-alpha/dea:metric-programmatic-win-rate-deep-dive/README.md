## 2. Definition

Within Advertising & Media Buying, Programmatic Win Rate (Deep Dive) (PWR-D) is used to gauge how efficiently resources are converted into outputs. The formula is Impressions Won / Bids Submitted - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Media & Entertainment sector.

## Formula

```
Impressions Won / Bids Submitted
```
