## 2. Definition

Insight-to-Action Cycle Time (I2ACT) captures how effectively a process or entity achieves its intended outcome for organizations tracking data science & analytics operations. It is defined as Days from Insight Delivered to Action Taken; the result is stated in days. Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures elapsed time from insight generation to implemented action. It is the metabolism metric of data-driven organizations: the value of insight decays with delay, and cycle time exposes where the handoff between analytics and operations breaks. Cycle time compression from skipping decision governance produces action without alignment. Read with decision adoption rate - analytics insights (Deep Dive) and stage-level bottleneck analysis.

Days from Insight Delivered to Action Taken
