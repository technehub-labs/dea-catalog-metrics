## 2. Definition

Requirements Volatility (Engineering) (RV-E) captures exposure to adverse outcomes for organizations tracking engineering & design. The formula is Changed Requirements after Baseline / Baseline Requirements - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
RV-E = Changed Requirements after Baseline / Baseline Requirements
```
