## 2. Definition

A DevSecOps & Application Security Engineering indicator, Security Champion Coverage per Team (SCCPT) quantifies capability maturity or development. Its calculation is Teams with Trained Security Champion / Teams, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the proportion of delivery teams with an embedded, trained security advocate. Champions decentralize security expertise so issues get caught where code is written. Coverage counts presence, not influence - a champion excluded from design discussions adds nothing. Read with shift-left security scan coverage and security test debt closure rate.

## Formula

```
Teams with Trained Security Champion / Teams
```
