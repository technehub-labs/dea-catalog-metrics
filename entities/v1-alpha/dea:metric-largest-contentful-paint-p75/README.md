## 2. Definition

Largest Contentful Paint (P75) (LCP75) measures the quality of outputs and outcomes in the Web & Digital Analytics Standard Measures domain. Its calculation is 75th Percentile Time to Largest Contentful Paint, measured in seconds. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Digital product practice.

## Formula

```
75th Percentile Time to Largest Contentful Paint
```
