## 2. Definition

Within Advertising & Media Buying, Viewability Rate (Deep Dive) (VR-D) is used to gauge the quality of outputs and outcomes. It is defined as Viewable Impressions / Measurable Impressions; the result is stated in percent (%). In Media & Entertainment, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Viewable Impressions / Measurable Impressions
```
