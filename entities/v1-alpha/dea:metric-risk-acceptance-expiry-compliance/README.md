## 2. Definition

Risk Acceptance Expiry Compliance (RAEC) captures conformance to standards, plans, or obligations for organizations tracking vulnerability & exposure management. It is defined as Accepted Risks Reviewed before Expiry / Accepted Risks; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Accepted Risks Reviewed before Expiry / Accepted Risks
```
