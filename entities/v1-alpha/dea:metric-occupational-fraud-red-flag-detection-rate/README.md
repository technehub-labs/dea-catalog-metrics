## 2. Definition

Occupational Fraud Red Flag Detection Rate (OFRFDR) captures exposure to adverse outcomes for organizations tracking enterprise fraud & financial crime management. It is computed as Red Flags Escalated per Detection Policy / Red Flags Identified, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Red Flags Escalated per Detection Policy / Red Flags Identified
```
