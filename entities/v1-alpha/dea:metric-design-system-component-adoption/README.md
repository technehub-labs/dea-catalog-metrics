## 2. Definition

Design System Component Adoption (DSCA) addresses how efficiently resources are converted into outputs and is a fixture of ux & design systems reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Components Using Design System / Total UI Components, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Components Using Design System / Total UI Components
```
