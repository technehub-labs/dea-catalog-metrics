## 2. Definition

A Regulatory Affairs & Compliance Operations indicator, Compliance System Alert Triage Time (CSAT) quantifies how efficiently resources are converted into outputs. Its calculation is Hours to Triage Compliance Alert, measured in hours. It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
CSAT = Hours to Triage Compliance Alert
```
