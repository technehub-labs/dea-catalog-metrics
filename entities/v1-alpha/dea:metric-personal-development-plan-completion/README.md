## 2. Definition

Personal Development Plan Completion (PDPC) measures the engagement or satisfaction of the people involved in the Learning & Development Effectiveness (Deep Dive) domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Employees Completing PDP Milestones / Plans, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Employees Completing PDP Milestones / Plans
```
