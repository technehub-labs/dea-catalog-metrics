## 2. Definition

Within Program & Portfolio Management, Time-to-Decision on Portfolio Changes (TTDOPC) is used to gauge how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Days for Portfolio Board Decisions on Change Requests; the result is stated in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
