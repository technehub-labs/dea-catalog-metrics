## 2. Definition

Quality Batch Investigation Cycle Time (QBICT) measures how efficiently resources are converted into outputs in the Chemicals & Specialty Materials domain. It is defined as Days from Deviation to Investigation Close; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Chemicals, it is a recognized element of the standard performance toolkit.

## Formula

```
Days from Deviation to Investigation Close
```
