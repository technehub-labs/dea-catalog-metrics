## 2. Definition

Physical Records Location Accuracy (PRLA) measures the quality of outputs and outcomes in the Records & Information Management domain. Its calculation is Physical Files at Recorded Location / Files Sampled, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Physical Files at Recorded Location / Files Sampled
```
