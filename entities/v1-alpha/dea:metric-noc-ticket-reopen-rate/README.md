## 2. Definition

NOC Ticket Reopen Rate (NOC-TRR) addresses the quality of outputs and outcomes and is a fixture of network operations center (deep dive) reporting. Its calculation is Tickets Reopened after Closure / Closed, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Tickets Reopened after Closure / Closed
```
