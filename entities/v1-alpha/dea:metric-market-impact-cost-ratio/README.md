## 2. Definition

Market Impact Cost Ratio (MICR-T) addresses how efficiently resources are converted into outputs and is a fixture of investment research & trading operations reporting. It is computed as Price Impact Cost / Order Value, expressed in percent (%). Its use is concentrated in Financial Services. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Price Impact Cost / Order Value
```
