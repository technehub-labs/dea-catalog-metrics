## 2. Definition

Within Gig & Contingent Workforce, Cost per Gig Task vs Employee Baseline (PGC) is used to gauge the economic value created or preserved. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Gig Task Cost / Equivalent Internal Task Cost, expressed in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Compares fully loaded cost of gig-completed work against the employee cost baseline for the same output. It is the decision metric for gig leverage: many tasks look cheaper until supervision, quality variance, and rework are loaded. Baseline honesty is critical - employee baselines built on peak productivity flatter gig economics by construction. Read with quality variance between gig and employee work and misclassification risk exposure.

## Formula

```
Gig Task Cost / Equivalent Internal Task Cost
```
