## 2. Definition

Quote and Buy Abandonment Rate (QBAR) measures exposure to adverse outcomes in the Insurance Distribution - Direct & Digital domain. It is defined as Abandoned Quote Sessions / Started Sessions; the result is stated in percent (%). In Insurance, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Abandoned Quote Sessions / Started Sessions
```
