## 2. Definition

A Statistical Model Performance Diagnostics indicator, Model Gain Chart Capture (GAINCC) quantifies the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Positive Events Captured in Top Deciles / All Events, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Software.

## Formula

```
Positive Events Captured in Top Deciles / All Events
```
