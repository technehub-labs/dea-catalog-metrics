## 2. Definition

A Fitness & Wellness (Deep Dive) indicator, Membership Freeze Rate (Deep Dive) (MFR-D) quantifies exposure to adverse outcomes. It is defined as Members Freezing Membership / Members; the result is stated in percent (%). In Health & Fitness, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Members Freezing Membership / Members
```
