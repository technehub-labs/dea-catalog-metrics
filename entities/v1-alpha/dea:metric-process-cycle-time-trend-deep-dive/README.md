## 2. Definition

Within Balanced Scorecard - Internal Process Perspective, Process Cycle Time Trend (Deep Dive) (PCTT-D) is used to gauge how efficiently resources are converted into outputs. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Change in Process Cycle Time between Periods, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the direction of end-to-end process durations. Falling cycle time compounds into faster cash conversion and customer responsiveness. Local step improvements often leave end-to-end time untouched when queues dominate. Read with process effectiveness index and order fulfilment lead time trend.

Change in Process Cycle Time between Periods
