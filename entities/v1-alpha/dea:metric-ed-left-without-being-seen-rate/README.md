## 2. Definition

ED Left Without Being Seen Rate (LWBS) measures the quality of outputs and outcomes in the Medical Practice & Clinical Operations domain. It is defined as Patients Leaving before Care / ED Arrivals; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Healthcare, it is a recognized element of the standard performance toolkit.

## Formula

```
Patients Leaving before Care / ED Arrivals
```
