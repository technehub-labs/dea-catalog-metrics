## 2. Definition

Within Contract Lifecycle Management, Contract Repository Coverage (CRC-CL) is used to gauge conformance to standards, plans, or obligations. It is defined as Active Contracts in Central Repository / Active Contracts; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of the organization's contracts in the governed repository. Uncatalogued contracts are invisible obligations and unclaimed rights. Coverage excluding legacy or side agreements preserves the riskiest documents. Read with contract repository coverage rate and obligations tracking.

## Formula

```
Active Contracts in Central Repository / Active Contracts
```
