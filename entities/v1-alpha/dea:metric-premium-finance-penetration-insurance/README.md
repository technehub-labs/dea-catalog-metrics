## 2. Definition

A Insurance Distribution & Agency Management indicator, Premium Finance Penetration (Insurance) (PFPI) quantifies how efficiently resources are converted into outputs. The formula is Premium Financed via Plan / Collectable Premium - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. It is a standard measure in the Insurance sector.

## Formula

```
Premium Financed via Plan / Collectable Premium
```
