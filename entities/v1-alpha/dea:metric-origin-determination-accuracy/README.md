## 2. Definition

Origin Determination Accuracy (ODA) captures conformance to standards, plans, or obligations for organizations tracking international trade & customs. It is defined as Origin Declarations Correct / Declarations Audited; the result is stated in percent (%). In Logistics & Trade, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Origin Declarations Correct / Declarations Audited
```
