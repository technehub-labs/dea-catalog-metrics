## 2. Definition

Project Manager Span of Control (PMSOC) measures the utilization or availability of capacity in the Project Management (Deep Dive) domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Concurrent Projects per Manager; the result is stated in count (items per period). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Concurrent Projects per Manager
```
