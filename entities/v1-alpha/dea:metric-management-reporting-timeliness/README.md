## 2. Definition

Within Financial Planning & Analysis, Management Reporting Timeliness (MRT-FP) is used to gauge the quality of outputs and outcomes. It is defined as Reports Delivered by Commit Date / Reports; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Reports Delivered by Commit Date / Reports
```
