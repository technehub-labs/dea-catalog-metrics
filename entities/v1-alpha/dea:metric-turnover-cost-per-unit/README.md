## 2. Definition

Within Real Estate Portfolio & Property Management, Turnover Cost per Unit (TCPU) is used to gauge how efficiently resources are converted into outputs. The formula is Make-Ready Costs / Units Turned - reported in currency value. It is a standard measure in the Real Estate sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Make-Ready Costs / Units Turned
```
