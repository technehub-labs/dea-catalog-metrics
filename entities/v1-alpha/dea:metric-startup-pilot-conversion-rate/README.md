## 2. Definition

Within Corporate Venturing & Partnerships, Startup Pilot Conversion Rate (SPCR) is used to gauge how effectively a process or entity achieves its intended outcome. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Pilots Converted to Scaled Deployment / Pilots Run - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how many startup pilots progress to scaled adoption, contract, or investment. Corporate venturing lives or dies on this funnel: pilot theater - endless proof-of-concepts that never convert - is the classic failure mode. Define conversion milestones unambiguously before the pilot starts, or every engagement will claim success retrospectively. Read with time-to-first-decision and venture deal flow quality for input health.

## Formula

```
Pilots Converted to Scaled Deployment / Pilots Run
```
