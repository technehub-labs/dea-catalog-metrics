## 2. Definition

Test Coverage (Electronics) (TCV) addresses the quality of outputs and outcomes and is a fixture of semiconductor & electronics reporting. It is defined as Circuit Nodes or Functions Tested / Total Nodes; the result is stated in percent (%). In Electronics & semiconductors, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Circuit Nodes or Functions Tested / Total Nodes
```
