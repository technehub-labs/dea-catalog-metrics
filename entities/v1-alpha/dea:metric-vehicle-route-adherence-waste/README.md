## 2. Definition

A Cleaning & Environmental Services indicator, Vehicle Route Adherence (Waste) (VRA) quantifies how efficiently resources are converted into outputs. It provides the day-to-day signal that a process is running as designed. Its calculation is Routes Completed to Plan / Routes, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Facility Services practice.

## Formula

```
Routes Completed to Plan / Routes
```
