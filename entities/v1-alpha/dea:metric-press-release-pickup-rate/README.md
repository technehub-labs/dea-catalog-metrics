## 2. Definition

Press Release Pickup Rate (PRPR) measures how effectively a process or entity achieves its intended outcome in the Corporate Communications & PR domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Outlets Publishing Release / Outlets Targeted, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of press releases earning meaningful media pickup. It matters because it tests whether the newsroom produces newsworthy stories or noise. Pickup can be inflated by counting syndicated wire echoes as coverage. Read with Share of Negative Coverage and referral traffic from earned media to confirm pickup is substantive.

## Formula

```
Outlets Publishing Release / Outlets Targeted
```
