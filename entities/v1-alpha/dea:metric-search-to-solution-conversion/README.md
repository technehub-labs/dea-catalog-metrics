## 2. Definition

Within Knowledge Management, Search-to-Solution Conversion (S2SC) is used to gauge the quality of outputs and outcomes. It is defined as Searches Ending in Solution Use / Searches; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Searches Ending in Solution Use / Searches
```
