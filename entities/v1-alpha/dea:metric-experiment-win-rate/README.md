## 2. Definition

Experiment Win Rate (EXPWR) addresses the quality of outputs and outcomes and is a fixture of web & digital analytics standard measures reporting. The formula is Experiments with Statistically Significant Positive Result / Experiments - reported in percent (%). It is a standard measure in the Digital product sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Experiments with Statistically Significant Positive Result / Experiments
```
