## 2. Definition

A Employee Engagement & Culture (Deep Dive) indicator, Internal Job Posting Visibility Rate (IJPVR) quantifies the engagement or satisfaction of the people involved. It is computed as Openings Posted Internally First / Openings, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Openings Posted Internally First / Openings
```
