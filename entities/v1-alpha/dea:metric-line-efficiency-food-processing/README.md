## 2. Definition

Line Efficiency (Food Processing) (LEF) captures how efficiently resources are converted into outputs for organizations tracking agriculture & food processing. Its calculation is Actual Output / Theoretical Line Capacity Output, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Agriculture & food practice.

## Formula

```
Actual Output / Theoretical Line Capacity Output
```
