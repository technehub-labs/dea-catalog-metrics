## 2. Definition

System Integration Test Cycle Time (SITC) measures how efficiently resources are converted into outputs in the Aerospace & Defense Program Management domain. It is defined as Days per Integration Test Cycle; the result is stated in days. In Aerospace & Defense, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
