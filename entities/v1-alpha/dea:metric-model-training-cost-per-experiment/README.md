## 2. Definition

Model Training Cost per Experiment (MTCE) captures how efficiently resources are converted into outputs for organizations tracking mlops & model lifecycle operations. It is defined as Compute Cost for Experiments / Experiments; the result is stated in currency value. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Compute Cost for Experiments / Experiments
```
