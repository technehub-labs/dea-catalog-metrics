## 2. Definition

Within Food & Beverage Manufacturing, Product Date Code Accuracy (PDCA) is used to gauge the quality of outputs and outcomes. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Correctly Coded Packages / Packages Sampled - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Food & Beverage sector.

## Formula

```
Correctly Coded Packages / Packages Sampled
```
