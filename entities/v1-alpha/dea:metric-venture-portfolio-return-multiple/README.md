## 2. Definition

A Corporate Venturing & Partnerships indicator, Venture Portfolio Return Multiple (VPRM) quantifies the economic value created or preserved. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Portfolio Exit and Fair Value / Capital Invested - reported in ratio (x:1 or x). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures realized and unrealized value of a corporate venture portfolio against invested capital. It is the bottom-line honesty metric for venturing: corporate programs routinely rationalize poor financial returns with strategic benefits that are never specified. Value unrealized for many years deserves discount skepticism, and mark-to-model valuations inflate multiples at fundraising peaks. Read with startup pilot conversion rate for the front of the funnel and integration success of acquired startups.

## Formula

```
Portfolio Exit and Fair Value / Capital Invested
```
