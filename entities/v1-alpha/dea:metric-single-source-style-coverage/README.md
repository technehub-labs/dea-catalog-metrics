## 2. Definition

A UX & Design Systems indicator, Single-Source Style Coverage (SSSC) quantifies how efficiently resources are converted into outputs. The formula is UI Tokens Sourced from Central Library / Tokens in Use - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
SSSC = UI Tokens Sourced from Central Library / Tokens in Use
```
