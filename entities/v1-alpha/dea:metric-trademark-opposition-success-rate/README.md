## 2. Definition

A Legal Operations indicator, Trademark Opposition Success Rate (TOSR) quantifies how effectively a process or entity achieves its intended outcome. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Oppositions Won / Oppositions Filed; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
TOSR = Oppositions Won / Oppositions Filed
```
