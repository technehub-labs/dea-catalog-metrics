## 2. Definition

Itinerary Change Rate (ICR-S) measures exposure to adverse outcomes in the Cruise & Passenger Shipping domain. The formula is Port Calls Skipped or Changed / Scheduled Port Calls - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Hospitality sector.

## Formula

```
Port Calls Skipped or Changed / Scheduled Port Calls
```
