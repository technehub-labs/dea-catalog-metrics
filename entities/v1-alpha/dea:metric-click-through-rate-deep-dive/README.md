## 2. Definition

Click-Through Rate (Deep Dive) (CTRDD) measures the engagement or satisfaction of the people involved in the Marketing & Advertising Standard Measures (Deep Dive) domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Clicks / Impressions, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Clicks / Impressions
```
