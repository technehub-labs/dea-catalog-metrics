## 2. Definition

A Restaurant Operations (Deep Dive) indicator, Average Check per Guest (Deep Dive) (ACPG-D) quantifies the economic value created or preserved. The formula is Revenue / Guests Served - reported in currency per unit. It is a standard measure in the Restaurants sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.
