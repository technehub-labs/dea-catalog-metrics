## 2. Definition

Certification Attainment Rate (CAR-L) measures capability maturity or development in the Learning & Development domain. The formula is Employees Earning Certifications / Employees Enrolled - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of learners achieving certification within enrolled programs. It matters because certifications validate capability and drive talent mobility economics. Attainment can be inflated by making exams easier or allowing unlimited retries without rigor. Read with Assessment Integrity data and post-certification performance to confirm credentials carry weight.

## Formula

```
Employees Earning Certifications / Employees Enrolled
```
