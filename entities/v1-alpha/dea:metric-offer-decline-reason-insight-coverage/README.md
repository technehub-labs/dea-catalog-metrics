## 2. Definition

Offer Decline Reason Insight Coverage (ODRIC) captures the quality of outputs and outcomes for organizations tracking talent acquisition deep dive. It is computed as Declines with Coded Reason / Declines, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
ODRIC = Declines with Coded Reason / Declines
```
