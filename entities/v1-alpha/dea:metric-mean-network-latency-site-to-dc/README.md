## 2. Definition

A Network Performance & Capacity indicator, Mean Network Latency (Site-to-DC) (MNLS) quantifies the quality of outputs and outcomes. Its calculation is Average Round-Trip Time from Site to Data Center, measured in milliseconds (ms). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.
