## 2. Definition

A International Trade & Customs indicator, Advance Ruling Coverage (ARC-T) quantifies exposure to adverse outcomes. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Value Covered by Advance Rulings / Total Import Value, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Logistics & Trade practice.

## Formula

```
Value Covered by Advance Rulings / Total Import Value
```
