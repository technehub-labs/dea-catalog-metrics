## 2. Definition

Within Crisis Management & Emergency Response, Crisis Media Response Accuracy Rate (CMRAR) is used to gauge the quality of outputs and outcomes. Its calculation is Public Statements Requiring Correction / Statements, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Reduction is the goal, and sustained decreases indicate successful intervention.

## 3. Context

Measures whether public statements during crises were accurate and required no retraction. Retractions multiply damage: credibility spent in a crisis rarely returns. Accuracy requires pre-crisis fact-gathering capability, not just communications skill. Read with crisis decision log completeness and brand sentiment recovery time.

## Formula

```
CMRAR = Public Statements Requiring Correction / Statements
```
