## 2. Definition

Within Software Product Operations (Deep Dive), Uninstall Rate (Mobile Deep Dive) (UNR-D) is used to gauge the retention of customers, users, or assets over time. Its calculation is Uninstalls / Installs, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Technology practice.

## Formula

```
Uninstalls / Installs
```
