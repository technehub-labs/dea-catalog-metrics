## 2. Definition

Within Master Data Management, Match Rule Recall (MRR-MD) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as True Matches Matched Automatically / All True Matches, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
True Matches Matched Automatically / All True Matches
```
