## 2. Definition

Low Performer Action Plan Rate (LPAPR) captures capability maturity or development for organizations tracking enterprise okr & performance management. The formula is Underperformers with Development Plans / Identified - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Underperformers with Development Plans / Identified
```
