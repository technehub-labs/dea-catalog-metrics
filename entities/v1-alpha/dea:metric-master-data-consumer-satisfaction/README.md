## 2. Definition

Master Data Consumer Satisfaction (MDCS) addresses the economic value created or preserved and is a fixture of master data management reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Downstream Consumer Satisfaction Score, expressed in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

Downstream Consumer Satisfaction Score
