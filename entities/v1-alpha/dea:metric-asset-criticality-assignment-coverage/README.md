## 2. Definition

Asset Criticality Assignment Coverage (ACAC-VM) addresses capability maturity or development and is a fixture of vulnerability & exposure management reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Assets with Assigned Criticality / Assets, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Assets with Assigned Criticality / Assets
```
