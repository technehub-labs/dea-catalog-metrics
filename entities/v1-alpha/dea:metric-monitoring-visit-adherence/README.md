## 2. Definition

Within Pharma R&D & Clinical Trials, Monitoring Visit Adherence (MVA-P) is used to gauge conformance to standards, plans, or obligations. It is defined as Monitoring Visits Completed per Schedule / Planned; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Pharmaceuticals, it is a recognized element of the standard performance toolkit.

## Formula

```
Monitoring Visits Completed per Schedule / Planned
```
