## 2. Definition

Within Knowledge Management (Deep Dive), Expert Location Rate (ELR-KM) is used to gauge how efficiently resources are converted into outputs. It provides the day-to-day signal that a process is running as designed. Its calculation is Cases Where Expert Found within SLA / Cases Needing Expertise, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Cases Where Expert Found within SLA / Cases Needing Expertise
```
