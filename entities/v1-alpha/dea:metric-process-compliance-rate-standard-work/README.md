## 2. Definition

Process Compliance Rate (Standard Work) (PCR-SW) addresses conformance to standards, plans, or obligations and is a fixture of operating model & process health deep dive reporting. Its calculation is Executions Following Standard Operating Procedure / Sampled Executions, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Executions Following Standard Operating Procedure / Sampled Executions
```
