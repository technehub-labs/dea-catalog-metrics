## 2. Definition

Ad Trafficking Error Rate (ATER) addresses the quality of outputs and outcomes and is a fixture of advertising & media buying reporting. Its calculation is Campaigns Launched with Errors / Campaigns, measured in percent (%). It originates from and is most used in Media & Entertainment practice. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Campaigns Launched with Errors / Campaigns
```
