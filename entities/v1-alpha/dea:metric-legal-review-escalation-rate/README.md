## 2. Definition

A Contract Lifecycle Management indicator, Legal Review Escalation Rate (LRER) quantifies how efficiently resources are converted into outputs. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Contracts Escalated to Legal beyond Self-Serve / Contracts, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Contracts Escalated to Legal beyond Self-Serve / Contracts
```
