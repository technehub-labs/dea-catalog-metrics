## 2. Definition

Within International Trade & Customs, Trade Lane Cost Variance (TLCV) is used to gauge how efficiently resources are converted into outputs. It is defined as Actual Lane Cost - Benchmark Cost / Benchmark; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Logistics & Trade, it is a recognized element of the standard performance toolkit.

## Formula

```
Actual Lane Cost - Benchmark Cost / Benchmark
```
