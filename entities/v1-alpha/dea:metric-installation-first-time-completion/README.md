## 2. Definition

A Telecom Field & Installation indicator, Installation First-Time Completion (IFTC) quantifies the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Installations Completed on First Visit / Installation Jobs; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Telecommunications, it is a recognized element of the standard performance toolkit.

## Formula

```
Installations Completed on First Visit / Installation Jobs
```
