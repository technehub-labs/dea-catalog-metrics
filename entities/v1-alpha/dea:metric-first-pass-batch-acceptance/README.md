## 2. Definition

First Pass Batch Acceptance (FPBA) addresses the quality of outputs and outcomes and is a fixture of pharmaceuticals & life sciences reporting. It is defined as Batches Accepted without Rework / Batches Manufactured; the result is stated in percent (%). In Pharmaceuticals, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Batches Accepted without Rework / Batches Manufactured
```
