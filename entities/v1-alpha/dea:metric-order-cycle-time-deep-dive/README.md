## 2. Definition

Order Cycle Time (Deep Dive) (OCTDD) measures how efficiently resources are converted into outputs in the Supply Chain Standard Measures (Deep Dive) domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Days from Customer Order to Delivery, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
