## 2. Definition

Whistleblower Case Resolution Cycle Time (WCRC) captures how efficiently resources are converted into outputs for organizations tracking internal controls & financial reporting integrity. It is computed as Days from Hotline Report to Case Closure, expressed in days. It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Hotline Report to Case Closure
```
