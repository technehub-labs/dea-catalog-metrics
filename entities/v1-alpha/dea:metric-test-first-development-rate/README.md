## 2. Definition

Within Software Development - Coding & Engineering Practices, Test-First Development Rate (TFDR) is used to gauge the quality of outputs and outcomes. It is defined as Changes with Tests Written Before Code / Sampled Changes; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Changes with Tests Written Before Code / Sampled Changes
```
