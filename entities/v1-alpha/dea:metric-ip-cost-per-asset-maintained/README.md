## 2. Definition

IP Cost per Asset Maintained (IPCpA) addresses how efficiently resources are converted into outputs and is a fixture of intellectual property & licensing reporting. The formula is Annual IP Spend / Active IP Assets - reported in currency per unit. It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Annual IP Spend / Active IP Assets
```
