## 2. Definition

Within Employee Wellbeing, Wellbeing Program Participation (WPP) is used to gauge the engagement or satisfaction of the people involved. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Employees Participating in Wellbeing Programs / Eligible Employees, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures employee take-up of wellbeing offerings. It matters because participation is the input layer for any wellbeing outcome claim. Participation can be bought with incentives while disengaged employees stay absent. Read with Absence Rate and Burnout Survey results to confirm participation moves real outcomes.

## Formula

```
WPP = Employees Participating in Wellbeing Programs / Eligible Employees
```
