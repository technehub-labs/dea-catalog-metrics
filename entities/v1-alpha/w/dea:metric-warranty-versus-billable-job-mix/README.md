## 2. Definition

Within Field Maintenance & Technical Field Service (Deep Dive), Warranty versus Billable Job Mix (WBJM-F) is used to gauge the economic value created or preserved. It is defined as Warranty Jobs / Total Jobs; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
WBJM-F = Warranty Jobs / Total Jobs
```
