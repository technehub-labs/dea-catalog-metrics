## 2. Definition

Audience Match Rate (Deep Dive) (AMR-D) addresses capability maturity or development and is a fixture of advertising & media buying reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Matched Targetable Audience / Addressable Audience; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
Matched Targetable Audience / Addressable Audience
```
