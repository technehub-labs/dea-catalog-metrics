## 2. Definition

Editorial Production Cycle Time (EPCT) measures how efficiently resources are converted into outputs in the Publishing & News Media domain. Its calculation is Days from Commission to Publication, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Media & Entertainment practice.

## Formula

```
Days from Commission to Publication
```
