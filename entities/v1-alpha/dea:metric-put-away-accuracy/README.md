## 2. Definition

Put-Away Accuracy (PAA) measures the quality of outputs and outcomes in the Warehousing domain. Its calculation is Correctly Placed Units / Units Put Away, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Correctly Placed Units / Units Put Away
```
