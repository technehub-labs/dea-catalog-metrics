## 2. Definition

A Network Operations Center (Deep Dive) indicator, Escalation Rate - NOC to Engineering (ERNOC) quantifies how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Tickets Escalated beyond NOC / Tickets; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Tickets Escalated beyond NOC / Tickets
```
