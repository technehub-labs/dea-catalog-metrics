## 2. Definition

Waste Collection Miss Rate (WCMR) measures the quality of outputs and outcomes in the Cleaning & Environmental Services domain. It is defined as Missed Collections / Scheduled Collections; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Facility Services, it is a recognized element of the standard performance toolkit.

## Formula

```
Missed Collections / Scheduled Collections
```
