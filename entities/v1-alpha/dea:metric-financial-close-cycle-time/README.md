## 2. Definition

Within Finance & Accounting, Financial Close Cycle Time (FCCT) is used to gauge how efficiently resources are converted into outputs. It is computed as Days from Period End to Signed Financial Statements, expressed in days. It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Days from Period End to Signed Financial Statements
```
