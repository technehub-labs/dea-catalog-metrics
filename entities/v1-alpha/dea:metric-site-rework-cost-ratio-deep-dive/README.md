## 2. Definition

Site Rework Cost Ratio (Deep Dive) (SRCR-D) addresses how efficiently resources are converted into outputs and is a fixture of construction contracting (deep dive) reporting. It is defined as Rework Cost / Total Construction Cost; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. In Construction, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures rework cost against total project cost. Rework is the purest waste in construction - labor hours that create no progress while the clock runs on the same overhead - and it is usually the largest controllable cost driver after productivity. Rework surfaced late (punch-list discovery rather than in-process inspection) indicates inspection-discipline gaps upstream. Read with first-time-quality inspection pass rates and design-change frequency.

## Formula

```
Rework Cost / Total Construction Cost
```
