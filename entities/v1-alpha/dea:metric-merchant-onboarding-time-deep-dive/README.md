## 2. Definition

Merchant Onboarding Time (Deep Dive) (MOT-D) measures how efficiently resources are converted into outputs in the Payments & Cards (Deep Dive) domain. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Days from Application to Live Merchant - reported in days. It should be driven down, since lower readings signal healthier performance. It is a standard measure in the Payments sector.

## Formula

Days from Application to Live Merchant
