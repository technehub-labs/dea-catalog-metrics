## 2. Definition

A Data Governance & Stewardship indicator, Data Literacy Program Reach (DLPR) quantifies capability maturity or development. It is defined as Staff Completing Data Literacy Training / Staff in Scope; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Staff Completing Data Literacy Training / Staff in Scope
```
