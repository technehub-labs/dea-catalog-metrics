## 2. Definition

Payment Success Rate (PSR) addresses the quality of outputs and outcomes and is a fixture of banking & financial services reporting. The formula is Successful Transactions / Total Transaction Attempts - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Financial services sector.

## Formula

```
Successful Transactions / Total Transaction Attempts
```
