## 2. Definition

Within Corporate Travel Management, Average Advance Booking Days (AABD) is used to gauge how efficiently resources are converted into outputs. The formula is Days between Booking and Travel, Averaged - reported in days. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Days between Booking and Travel, Averaged
```
