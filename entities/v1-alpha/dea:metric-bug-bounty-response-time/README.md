## 2. Definition

Within DevSecOps & Application Security Engineering, Bug Bounty Response Time (BBRT-DSO) is used to gauge how efficiently resources are converted into outputs. The formula is Hours to First Response on Valid Bug Bounty Report - reported in hours. It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Hours to First Response on Valid Bug Bounty Report
```
