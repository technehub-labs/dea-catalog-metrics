## 2. Definition

Within Advertising & Media Buying, Effective Frequency Attainment (EFA) is used to gauge how effectively a process or entity achieves its intended outcome. It is defined as Audience Meeting Effective Frequency / Targeted Audience; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
Audience Meeting Effective Frequency / Targeted Audience
```
