## 2. Definition

A Web & Digital Analytics Standard Measures indicator, Conversion Funnel Completion Rate (Deep Dive) (CFCRDD) quantifies growth over time. It provides the day-to-day signal that a process is running as designed. Its calculation is Users Completing Funnel / Users Entering Funnel, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Digital product practice.

## Formula

```
Users Completing Funnel / Users Entering Funnel
```
