## 2. Definition

Channel Marketing Fund Utilization (CMFU) addresses how efficiently resources are converted into outputs and is a fixture of channel & distribution management reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as MDF Spent on Approved Programs / MDF Allocated, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
MDF Spent on Approved Programs / MDF Allocated
```
