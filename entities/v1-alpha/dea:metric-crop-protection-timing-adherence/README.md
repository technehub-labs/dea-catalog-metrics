## 2. Definition

Within Agriculture & Agronomy (Deep Dive), Crop Protection Timing Adherence (CPTA) is used to gauge conformance to standards, plans, or obligations. It is computed as Applications within Agronomic Window / Planned, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Agriculture.

## Formula

```
Applications within Agronomic Window / Planned
```
