## 2. Definition

Within Software Development - Coding & Engineering Practices, Pair or Mob Programming Adoption Rate (PMPAR) is used to gauge capability maturity or development. It is computed as Sessions Using Pairing / Development Sessions, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Sessions Using Pairing / Development Sessions
```
