## 2. Definition

Within Beauty & Personal Care Services, Waste per Service (Beauty) (WPS-B) is used to gauge how efficiently resources are converted into outputs. It provides the day-to-day signal that a process is running as designed. Its calculation is Product Wasted / Services Delivered, measured in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Personal Services practice.

## Formula

```
Product Wasted / Services Delivered
```
