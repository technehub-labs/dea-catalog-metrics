## 2. Definition

Post Coverage Rate (Security) (PCR-S) addresses conformance to standards, plans, or obligations and is a fixture of security services & guarding reporting. Its calculation is Shifts Covered as Rostered / Rostered Shifts, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Security practice.

## Formula

```
Shifts Covered as Rostered / Rostered Shifts
```
