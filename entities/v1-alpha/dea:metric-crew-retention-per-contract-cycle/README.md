## 2. Definition

Crew Retention per Contract Cycle (CRCC) measures the retention of customers, users, or assets over time in the Cruise & Passenger Shipping domain. It is defined as Crew Re-signing / Eligible Crew; the result is stated in percent (%). In Hospitality, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Crew Re-signing / Eligible Crew
```
