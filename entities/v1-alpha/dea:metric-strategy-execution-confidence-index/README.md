## 2. Definition

Strategy Execution Confidence Index (SECI) measures strategy in the Balanced Scorecard Implementation & Review domain. Its calculation is Leadership Survey on Strategy Delivery Confidence, measured in index (0-100 or normalized). It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures leadership's evidence-based confidence that strategic commitments will land. The index aggregates leading indicators of execution rather than trailing results. Self-reported confidence unanchored to leading data is mood, not measurement. Read with BSC target attainment rate and strategy execution capability assessment.

## Formula

```
Leadership Survey on Strategy Delivery Confidence
```
