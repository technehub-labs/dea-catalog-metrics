## 2. Definition

Rework Rate - Code (RRC-SD) measures the quality of outputs and outcomes in the Software Development - Coding & Engineering Practices domain. It is defined as Lines Reworked after Review / Lines Submitted; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Lines Reworked after Review / Lines Submitted
```
