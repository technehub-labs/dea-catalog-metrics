## 2. Definition

A Knowledge Management indicator, Knowledge Base Deflection Rate (KBDR) quantifies how efficiently resources are converted into outputs. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Issues Self-Resolved via Knowledge Base / Issues Seeking Help, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of support demand resolved by knowledge base content without human contact. It matters because deflection is the ROI mechanism of knowledge management. Deflection can be inflated when users give up rather than succeed. Read with Self-Service Resolution Rate and Customer Effort Score to confirm deflection means resolution, not abandonment.

## Formula

```
Issues Self-Resolved via Knowledge Base / Issues Seeking Help
```
