## 2. Definition

Within Project Management (Deep Dive), Estimation Bias Calibration Index (EBCI-PM) is used to gauge the quality of outputs and outcomes. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Systematic Bias in Historical Estimates, expressed in ratio (x:1 or x). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures systematic over- or under-estimation across the project portfolio. Calibrated estimation is a learnable organizational capability; uncalibrated estimation is a repeated surprise. Bias computed only on completed projects lags current practice. Read with estimate accuracy - cost and estimate accuracy - schedule.

## Formula

```
Systematic Bias in Historical Estimates
```
