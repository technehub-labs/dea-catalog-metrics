## 2. Definition

A UX & Design Systems indicator, Error Message Clarity Score (EMCS) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is User-Tested Comprehension Score for Error Messages, measured in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
EMCS = User-Tested Comprehension Score for Error Messages
```
