## 2. Definition

Whistleblower Report Volume (Deep Dive) (WRV-EF) measures exposure to adverse outcomes in the Enterprise Fraud & Financial Crime Management domain. It is defined as Hotline Reports Received per Period; the result is stated in count (items per period). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.
