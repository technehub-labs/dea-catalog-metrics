## 2. Definition

Interagency Case Referral Cycle Time (Public Sector) (ICRCT) measures how efficiently resources are converted into outputs in the Public Sector & Citizen Service Standard Measures (Deep Dive) domain. Its calculation is Days for Referral between Agencies to be Actioned, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Public sector practice.

## Formula

```
ICRCT = Days for Referral between Agencies to be Actioned
```
