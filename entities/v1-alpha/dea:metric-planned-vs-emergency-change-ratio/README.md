## 2. Definition

Planned vs Emergency Change Ratio (PECR) measures governance in the Network Change & Configuration Management domain. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Planned Changes / Emergency Changes, measured in ratio (x:1 or x). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Planned Changes / Emergency Changes
```
