## 2. Definition

A Chemicals & Specialty Materials indicator, Maintenance-Induced Downtime Share (Chemicals) (MIDS) quantifies how efficiently resources are converted into outputs. It is defined as Downtime from Maintenance / Total Downtime; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. In Chemicals, it is a recognized element of the standard performance toolkit.

## Formula

```
Downtime from Maintenance / Total Downtime
```
