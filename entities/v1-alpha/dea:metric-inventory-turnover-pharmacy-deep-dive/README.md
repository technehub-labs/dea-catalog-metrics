## 2. Definition

Inventory Turnover - Pharmacy (Deep Dive) (ITP-D) measures how efficiently resources are converted into outputs in the Pharmacy Retail domain. It is computed as Cost of Goods / Average Inventory, expressed in times per period. Its use is concentrated in Healthcare. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Cost of Goods / Average Inventory
```
