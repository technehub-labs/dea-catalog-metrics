## 2. Definition

Occupancy Cost Ratio (Tenant) (OCR-RE) addresses the economic value created or preserved and is a fixture of real estate & mortgage standard measures reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Tenant Occupancy Cost / Tenant Sales; the result is stated in percent (%). It should be driven down, since lower readings signal healthier performance. In Real estate, it is a recognized element of the standard performance toolkit.

## Formula

```
Tenant Occupancy Cost / Tenant Sales
```
