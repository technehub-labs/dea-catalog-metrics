## 2. Definition

Backlog Age (Public Services) (BAPS) measures how efficiently resources are converted into outputs in the Public Sector & Citizen Service Standard Measures (Deep Dive) domain. It is defined as Average Age of Open Citizen Cases; the result is stated in days. In Public sector, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.
