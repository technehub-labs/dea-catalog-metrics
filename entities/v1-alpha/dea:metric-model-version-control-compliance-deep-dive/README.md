## 2. Definition

A Financial Planning & Analysis indicator, Model Version Control Compliance (Deep Dive) (MVCCC) quantifies the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Planning Models under Version Control / Models, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Planning Models under Version Control / Models
```
