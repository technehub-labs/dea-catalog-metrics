## 2. Definition

Within Agriculture & Agronomy (Deep Dive), Livestock Mortality Rate (Deep Dive) (LMR-D) is used to gauge exposure to adverse outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Deaths / Herd Size; the result is stated in percent (%). It should be driven down, since lower readings signal healthier performance. In Agriculture, it is a recognized element of the standard performance toolkit.

## Formula

```
LMR-D = Deaths / Herd Size
```
