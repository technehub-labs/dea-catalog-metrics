## 2. Definition

A Publishing & News Media indicator, Newsroom Error Correction Rate (NECR) quantifies the quality of outputs and outcomes. It is defined as Corrections Issued / Articles Published; the result is stated in events per thousand or million (scaled). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
NECR = Corrections Issued / Articles Published
```
