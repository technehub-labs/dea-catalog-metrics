## 2. Definition

Defects per Unit - Final Audit (Deep Dive) (DPU-D) measures the quality of outputs and outcomes in the Automotive Manufacturing (Deep Dive) domain. It is defined as Audit Defects / Vehicles Audited; the result is stated in ratio (x:1 or x). In Automotive, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
DPU-D = Audit Defects / Vehicles Audited
```
