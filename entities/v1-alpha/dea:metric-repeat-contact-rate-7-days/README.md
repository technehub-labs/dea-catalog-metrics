## 2. Definition

Within Contact Center Standard Measures (Deep Dive), Repeat Contact Rate (7 Days) (RCR7) is used to gauge the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Customers Contacting Again within 7 Days / Contacts; the result is stated in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Customers Contacting Again within 7 Days / Contacts
```
