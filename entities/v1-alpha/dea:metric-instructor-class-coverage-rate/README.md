## 2. Definition

Instructor Class Coverage Rate (ICCR) captures conformance to standards, plans, or obligations for organizations tracking fitness & wellness (deep dive). Its calculation is Classes Covered by Scheduled Instructor / Classes, measured in percent (%). It originates from and is most used in Health & Fitness practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Classes Covered by Scheduled Instructor / Classes
```
