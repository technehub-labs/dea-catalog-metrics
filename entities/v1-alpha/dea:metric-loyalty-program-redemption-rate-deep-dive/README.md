## 2. Definition

Loyalty Program Redemption Rate (Deep Dive) (LPRTDD) addresses the engagement or satisfaction of the people involved and is a fixture of retail standard measures reporting. It is defined as Points Redeemed / Points Issued; the result is stated in percent (%). In Retail & E-commerce, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Points Redeemed / Points Issued
```
