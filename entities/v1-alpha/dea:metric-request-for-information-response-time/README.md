## 2. Definition

Request for Information Response Time (RFIT) addresses how efficiently resources are converted into outputs and is a fixture of construction & engineering reporting. It is defined as Days from RFI Receipt to Response; the result is stated in days. It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Construction & engineering, it is a recognized element of the standard performance toolkit.
