## 2. Definition

IP Portfolio Grant Rate (Deep Dive) (IPGR) addresses the economic value created or preserved and is a fixture of legal operations reporting. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Granted Applications / Filed Applications, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of patent applications that grant, by technology area. Grant rates reveal both drafting quality and portfolio strategy: a high rate from filing only bulletproof claims signals a timid portfolio, while indiscriminate filing wastes budget on low-value continuations. Value-weight the portfolio, since one foundational patent usually outweighs dozens of defensive publications. Read with citation impact and litigation-validated claims.

## Formula

```
Granted Applications / Filed Applications
```
