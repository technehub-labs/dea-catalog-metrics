## 2. Definition

Canary Analysis Accuracy (CAA-CD) measures the quality of outputs and outcomes in the Continuous Delivery & Deployment domain. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Canary Decisions Matching Final Outcome / Canary Analyses, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Canary Decisions Matching Final Outcome / Canary Analyses
```
