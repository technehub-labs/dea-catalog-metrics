## 2. Definition

Within Software Engineering, Code Churn (CHN) is used to gauge the quality of outputs and outcomes. Its calculation is Lines Rewritten or Deleted shortly after Writing / Total Lines, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Lines Rewritten or Deleted shortly after Writing / Total Lines
```
