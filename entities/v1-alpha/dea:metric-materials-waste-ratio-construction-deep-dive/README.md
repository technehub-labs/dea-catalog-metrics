## 2. Definition

Materials Waste Ratio (Construction Deep Dive) (MWR-D) measures how efficiently resources are converted into outputs in the Construction Contracting (Deep Dive) domain. The formula is Wasted Materials / Materials Purchased - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Construction sector.

## Formula

```
Wasted Materials / Materials Purchased
```
