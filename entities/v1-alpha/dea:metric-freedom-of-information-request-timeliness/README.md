## 2. Definition

Within Government & Public Administration, Freedom of Information Request Timeliness (FOIT) is used to gauge conformance to standards, plans, or obligations. Its calculation is FOI Responses within Statutory Time / Requests, measured in percent (%). It originates from and is most used in Public Sector practice. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
FOI Responses within Statutory Time / Requests
```
