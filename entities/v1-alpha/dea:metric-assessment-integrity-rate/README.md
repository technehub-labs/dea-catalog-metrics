## 2. Definition

Assessment Integrity Rate (ASIR) measures conformance to standards, plans, or obligations in the Education & Training Outcome Standard Measures domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Assessments Completed within Integrity Rules / Assessments, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Education practice.

## Formula

```
ASIR = Assessments Completed within Integrity Rules / Assessments
```
