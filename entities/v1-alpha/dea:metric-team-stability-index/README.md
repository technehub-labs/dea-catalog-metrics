## 2. Definition

A Agile Delivery & Team Effectiveness indicator, Team Stability Index (TSI-AG) quantifies capability maturity or development. It is defined as Team Composition Unchanged over Quarter / Team; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Team Composition Unchanged over Quarter / Team
```
