## 2. Definition

Within Retail Banking Branch Network (Deep Dive), Sales per Branch FTE (Deep Dive) (SPBF-D) is used to gauge how efficiently resources are converted into outputs. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Products Sold / Branch FTE, measured in count (items per period). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Banking practice.
