## 2. Definition

Within Airline & Transportation Standard Measures (Deep Dive), Revenue per Available Seat Kilometer (RASK) is used to gauge the economic value created or preserved. The formula is Passenger Revenue / Available Seat Kilometers - reported in currency per unit. It is a standard measure in the Airlines & Aviation sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures passenger revenue per seat-kilometer offered. RASK is the standard traffic-yield measure of airline revenue performance. Stage length and network structure dominate RASK comparisons between carriers. Read with passenger load factor (Deep Dive) and cost per available seat kilometer.

## Formula

```
Passenger Revenue / Available Seat Kilometers
```
