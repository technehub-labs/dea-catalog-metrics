## 2. Definition

Post-Campaign Report Turnaround (PCRT) measures how efficiently resources are converted into outputs in the Advertising & Media Buying domain. The formula is Days from Campaign End to Final Report - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Media & Entertainment sector.

## Formula

```
PCRT = Days from Campaign End to Final Report
```
