## 2. Definition

Standards Compliance of Projects (SCP) measures conformance to standards, plans, or obligations in the Enterprise Architecture domain. It is defined as Projects Compliant with Architecture Standards / Projects Audited; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of projects conforming to enterprise architecture and engineering standards. It matters because standards drift makes every future integration harder. Compliance can be declared with approved waivers that are never revisited. Read with Architecture Review Pass Rate and waiver aging to confirm compliance is substantive.

## Formula

```
Projects Compliant with Architecture Standards / Projects Audited
```
