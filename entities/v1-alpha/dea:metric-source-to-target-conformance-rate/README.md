## 2. Definition

Source-to-Target Conformance Rate (STCR) measures the quality of outputs and outcomes in the Data Quality Management domain. It is computed as ETL Outputs Conforming to Target Schema and Rules / Outputs, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
ETL Outputs Conforming to Target Schema and Rules / Outputs
```
