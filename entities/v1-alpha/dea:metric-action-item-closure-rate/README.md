## 2. Definition

Action Item Closure Rate (AICR) measures conformance to standards, plans, or obligations in the Operating Model & Decision Effectiveness domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Action Items Closed by Due Date / Action Items; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Action Items Closed by Due Date / Action Items
```
