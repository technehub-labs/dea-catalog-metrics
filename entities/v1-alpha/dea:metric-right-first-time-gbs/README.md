## 2. Definition

Within Shared Services & Global Business Services, Right First Time (GBS) (RFT-GBS) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Requests Completed without Rework / Requests Completed, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Requests Completed without Rework / Requests Completed
```
