## 2. Definition

Within Education & Training Outcome Standard Measures, Early Alert Intervention Effectiveness (EAIE) is used to gauge the economic value created or preserved. It is computed as Interventions Preventing Withdrawal / Interventions, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Education.

## Formula

```
Interventions Preventing Withdrawal / Interventions
```
