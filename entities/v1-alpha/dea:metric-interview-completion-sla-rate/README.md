## 2. Definition

Interview Completion SLA Rate (ICSLA) captures how efficiently resources are converted into outputs for organizations tracking talent acquisition deep dive. It provides the day-to-day signal that a process is running as designed. Its calculation is Interview Stages Completed within SLA / Stages, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Interview Stages Completed within SLA / Stages
```
