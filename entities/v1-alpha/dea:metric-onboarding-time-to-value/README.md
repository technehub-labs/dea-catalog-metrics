## 2. Definition

A Customer indicator, Onboarding Time to Value (TTV) quantifies how efficiently resources are converted into outputs. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Days from Signup to First Value Outcome, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Days from Signup to First Value Outcome
```
