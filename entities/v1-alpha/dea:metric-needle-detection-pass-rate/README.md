## 2. Definition

Within Textile & Apparel (Deep Dive), Needle Detection Pass Rate (NDPR) is used to gauge exposure to adverse outcomes. The formula is Garments Passing Metal Detection / Garments - reported in percent (%). It is a standard measure in the Textiles & Apparel sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Garments Passing Metal Detection / Garments
```
