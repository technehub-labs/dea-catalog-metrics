## 2. Definition

Energy Use Intensity (Portfolio) (EUI-P) captures environmental and social sustainability performance for organizations tracking real estate portfolio & property management. The formula is Building Energy / Gross Floor Area - reported in ratio (x:1 or x). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Real Estate sector.

## Formula

```
EUI-P = Building Energy / Gross Floor Area
```
