## 2. Definition

A Balanced Scorecard - Internal Process Perspective indicator, Continuous Improvement Idea Implementation Rate (Deep Dive) (CIIR-D) quantifies capability maturity or development. Its calculation is Implemented Improvement Ideas / Submitted, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of employee improvement suggestions actually implemented. Implementation, not collection, determines whether improvement culture is real. A high rate on trivia with strategic ideas shelved is theatre. Read with kaizen event completion rate and innovation climate score.

## Formula

```
Implemented Improvement Ideas / Submitted
```
