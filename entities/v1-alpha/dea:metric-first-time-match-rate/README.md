## 2. Definition

First-Time Match Rate (FTMR) addresses the quality of outputs and outcomes and is a fixture of accounts payable & receivable operations (deep dive) reporting. Its calculation is Invoices Auto-Matched on First Pass / Invoices, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Invoices Auto-Matched on First Pass / Invoices
```
