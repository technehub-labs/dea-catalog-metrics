## 2. Definition

Within Web & Digital Analytics Standard Measures, Feature Adoption Depth (Deep Dive) (FADD) is used to gauge the engagement or satisfaction of the people involved. It is computed as Users Using Feature's Full Capability Set / Feature Adopters, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Digital product.

## Formula

```
Users Using Feature's Full Capability Set / Feature Adopters
```
