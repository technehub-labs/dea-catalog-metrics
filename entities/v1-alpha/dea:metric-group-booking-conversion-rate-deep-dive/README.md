## 2. Definition

Group Booking Conversion Rate (Deep Dive) (GBR-D) captures growth over time for organizations tracking hotel & resort operations (deep dive). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Group Contracts Signed / Leads - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Hospitality sector.

## Formula

```
GBR-D = Group Contracts Signed / Leads
```
