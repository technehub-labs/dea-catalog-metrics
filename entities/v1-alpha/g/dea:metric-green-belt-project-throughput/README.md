## 2. Definition

Green Belt Project Throughput (GBPT) captures capability maturity or development for organizations tracking process excellence (lean six sigma). Its calculation is Certified Projects Completed per Practitioner per Year, measured in ratio (x:1 or x). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures completed improvement projects per trained belt. It matters because it tests whether training investment converts into applied improvement. Throughput can chase small easy projects to rack up counts. Read with verified savings per project and project difficulty mix to confirm throughput is meaningful.

## Formula

```
GBPT = Certified Projects Completed per Practitioner per Year
```
