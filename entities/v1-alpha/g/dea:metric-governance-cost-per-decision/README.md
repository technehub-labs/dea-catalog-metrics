## 2. Definition

Within Enterprise Decision Effectiveness & Governance Monitoring, Governance Cost per Decision (GCPD) is used to gauge how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Governance Body Cost / Decisions Taken; the result is stated in currency value. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
GCPD = Governance Body Cost / Decisions Taken
```
