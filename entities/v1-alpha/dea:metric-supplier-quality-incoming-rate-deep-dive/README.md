## 2. Definition

Supplier Quality Incoming Rate (Deep Dive) (SQIR-D) addresses the quality of outputs and outcomes and is a fixture of balanced scorecard - internal process perspective reporting. It is computed as Supplier Lots Accepted / Lots Received, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Supplier Lots Accepted / Lots Received
```
