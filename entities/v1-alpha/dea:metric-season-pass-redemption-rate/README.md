## 2. Definition

Season Pass Redemption Rate (SPRR) addresses the retention of customers, users, or assets over time and is a fixture of entertainment venues & attractions reporting. The formula is Visits per Pass / Planned Visits - reported in times per period. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Media & Entertainment sector.

## Formula

```
Visits per Pass / Planned Visits
```
