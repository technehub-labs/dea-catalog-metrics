## 2. Definition

Planning Cycle Compression (PCC-FP) addresses how efficiently resources are converted into outputs and is a fixture of financial planning & analysis reporting. Its calculation is Reduction in Cycle Days vs Prior Year / Prior Year, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PCC-FP = Reduction in Cycle Days vs Prior Year / Prior Year
```
