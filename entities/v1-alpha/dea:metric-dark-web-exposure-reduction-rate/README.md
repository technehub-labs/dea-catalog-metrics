## 2. Definition

Within Threat Intelligence & Red Team, Dark Web Exposure Reduction Rate (DWERR) is used to gauge exposure to adverse outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Exposed Credential Posts Removed / Posts Discovered; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Exposed Credential Posts Removed / Posts Discovered
```
