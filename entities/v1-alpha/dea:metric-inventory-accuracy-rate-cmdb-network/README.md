## 2. Definition

Inventory Accuracy Rate (CMDB Network) (IARN) addresses the quality of outputs and outcomes and is a fixture of network change & configuration management reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as CMDB Records Matching Discovery / Records Sampled; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
CMDB Records Matching Discovery / Records Sampled
```
