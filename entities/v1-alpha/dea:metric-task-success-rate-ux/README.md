## 2. Definition

A UX & Design Systems indicator, Task Success Rate (UX) (TSR-UX) quantifies the quality of outputs and outcomes. It is computed as Tasks Completed Successfully by Users / Task Attempts, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Tasks Completed Successfully by Users / Task Attempts
```
