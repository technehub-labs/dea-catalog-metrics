## 2. Definition

Story Cycle Time (Deep Dive) (SCT-AG) captures how efficiently resources are converted into outputs for organizations tracking agile delivery & team effectiveness. The formula is Days from Story Start to Done - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.
