## 2. Definition

Application-to-Offer Cycle Time (Deep Dive) (AOT-D) addresses how efficiently resources are converted into outputs and is a fixture of banking retail lending (deep dive) reporting. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Days from Application to Offer Decision, measured in days. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Banking practice.
