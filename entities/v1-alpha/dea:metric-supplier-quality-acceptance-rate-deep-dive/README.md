## 2. Definition

Supplier Quality Acceptance Rate (Deep Dive) (SQAR) addresses the quality of outputs and outcomes and is a fixture of strategic sourcing & supplier performance (deep dive) reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Receipts Accepted without Rejection / Receipts, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Receipts Accepted without Rejection / Receipts
```
