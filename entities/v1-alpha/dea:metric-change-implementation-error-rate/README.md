## 2. Definition

Within Network Change & Configuration Management, Change Implementation Error Rate (CIER) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Changes Requiring Correction during Implementation / Changes, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Changes Requiring Correction during Implementation / Changes
```
