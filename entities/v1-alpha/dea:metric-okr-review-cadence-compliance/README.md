## 2. Definition

Within Enterprise OKR & Performance Management, OKR Review Cadence Compliance (OKRRCC) is used to gauge conformance to standards, plans, or obligations. It is defined as Check-ins Completed per Cadence / Scheduled; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Check-ins Completed per Cadence / Scheduled
```
