## 2. Definition

Within Financial Planning & Analysis, Rolling Forecast Refresh Cycle Time (RFRCT) is used to gauge how efficiently resources are converted into outputs. It is computed as Days to Complete Forecast Refresh Cycle, expressed in days. It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.
