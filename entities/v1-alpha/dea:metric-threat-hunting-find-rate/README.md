## 2. Definition

Within Threat Intelligence & Red Team, Threat Hunting Find Rate (THFR) is used to gauge exposure to adverse outcomes. It is defined as Hunts Producing Actionable Findings / Hunts; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Hunts Producing Actionable Findings / Hunts
```
