## 2. Definition

Knowledge Capture Rate (KCR-K) measures capability maturity or development in the Knowledge Management domain. It is defined as Documented Solutions / Resolved Novel Issues; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of critical knowledge formally captured before it walks out the door. It matters because expertise attrition is unplanned single-point-of-failure risk. Capture can be counted for documents nobody can find or use. Read with Expertise Location Coverage and Post-Attrition Incident trends to confirm capture is usable.

## Formula

```
Documented Solutions / Resolved Novel Issues
```
