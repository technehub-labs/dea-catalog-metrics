## 2. Definition

Data Archival Compliance (DAC-E) measures conformance to standards, plans, or obligations in the ERP & Enterprise Application Operations domain. The formula is Records Archived per Policy / Due - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Records Archived per Policy / Due
```
