## 2. Definition

A Conversational AI & Chatbots indicator, Escalation Quality (Context Passed) (EQCP) quantifies the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Escalations with Complete Context / Escalations; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
EQCP = Escalations with Complete Context / Escalations
```
