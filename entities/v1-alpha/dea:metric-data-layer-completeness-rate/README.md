## 2. Definition

Data Layer Completeness Rate (DLCR) captures the quality of outputs and outcomes for organizations tracking web & digital analytics standard measures. The formula is Required Data Layer Attributes Populated / Required - reported in percent (%). It is a standard measure in the Digital product sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Required Data Layer Attributes Populated / Required
```
