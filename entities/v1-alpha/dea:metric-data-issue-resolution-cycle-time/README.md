## 2. Definition

Within Data Governance & Stewardship, Data Issue Resolution Cycle Time (DIRC) is used to gauge how efficiently resources are converted into outputs. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Days from Data Issue Raised to Resolved, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Days from Data Issue Raised to Resolved
```
