## 2. Definition

Within Pharmacy Retail, Pharmacist Counsel Rate (PCR-Ph) is used to gauge the quality of outputs and outcomes. The formula is Counseling Interactions / New Prescriptions - reported in percent (%). It is a standard measure in the Healthcare sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Counseling Interactions / New Prescriptions
```
