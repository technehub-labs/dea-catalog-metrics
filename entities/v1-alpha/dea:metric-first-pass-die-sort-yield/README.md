## 2. Definition

A Semiconductor & Electronics indicator, First Pass Die Sort Yield (FPDY) quantifies the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Die Passing Sort on First Test / Die Tested, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Electronics & semiconductors.

## Formula

```
FPDY = Die Passing Sort on First Test / Die Tested
```
