## 2. Definition

Within Standard Workforce & Pay Metrics, Salary Compression Ratio (SCR-PAY) is used to gauge exposure to adverse outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is New Hire Pay vs Incumbent Pay for Same Role - reported in ratio (x:1 or x). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
New Hire Pay vs Incumbent Pay for Same Role
```
