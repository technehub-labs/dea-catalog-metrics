## 2. Definition

A Restaurant Operations (Deep Dive) indicator, Server Sales per Labor Hour (SSPLH) quantifies how efficiently resources are converted into outputs. It is defined as Sales / Labor Hour; the result is stated in currency per unit. It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Restaurants, it is a recognized element of the standard performance toolkit.

## Formula

```
Sales / Labor Hour
```
