## 2. Definition

Role Clarity Ratio (Deep Dive) (RCRD) measures governance in the Workforce Planning & Productivity domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Roles with Documented Accountabilities / Roles, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
RCRD = Roles with Documented Accountabilities / Roles
```
