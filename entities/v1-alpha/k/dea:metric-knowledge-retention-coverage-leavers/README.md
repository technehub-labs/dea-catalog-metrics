## 2. Definition

Within Knowledge Management (Deep Dive), Knowledge Retention Coverage (Leavers) (KRC) is used to gauge exposure to adverse outcomes. Its calculation is Leavers with Documented Handover of Critical Knowledge / Leavers, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
KRC = Leavers with Documented Handover of Critical Knowledge / Leavers
```
