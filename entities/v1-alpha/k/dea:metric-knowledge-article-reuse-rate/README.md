## 2. Definition

Knowledge Article Reuse Rate (KARR) addresses the economic value created or preserved and is a fixture of knowledge management (deep dive) reporting. It is defined as Article Views Leading to Reuse / Views; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
KARR = Article Views Leading to Reuse / Views
```
