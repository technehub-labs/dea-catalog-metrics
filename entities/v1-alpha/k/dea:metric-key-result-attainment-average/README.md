## 2. Definition

A Enterprise OKR & Performance Management indicator, Key Result Attainment Average (KRAA-OKR) quantifies how effectively a process or entity achieves its intended outcome. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Average Attainment across Key Results, expressed in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures average achievement of committed key results. Attainment distribution matters more than the mean: chronic 100% means sandbagging, chronic 40% means fantasy planning. Averages hide the variance that reveals calibration quality. Read with OKR coverage - cascading ratio and performance incentive payout accuracy.

## Formula

```
KRAA-OKR = Average Attainment across Key Results
```
