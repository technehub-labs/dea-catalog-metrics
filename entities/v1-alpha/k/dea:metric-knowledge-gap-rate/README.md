## 2. Definition

Knowledge Gap Rate (KGR) addresses capability maturity or development and is a fixture of conversational ai & chatbots reporting. It is defined as Unanswered Query Topics Identified / Total Query Topics; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
KGR = Unanswered Query Topics Identified / Total Query Topics
```
