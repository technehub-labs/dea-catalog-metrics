## 2. Definition

Blocked Time Ratio (BTR-AG) addresses how efficiently resources are converted into outputs and is a fixture of agile delivery & team effectiveness reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Blocked Hours / Total Working Hours; the result is stated in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Blocked Hours / Total Working Hours
```
