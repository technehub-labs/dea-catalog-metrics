## 2. Definition

A Standard Workforce & Pay Metrics indicator, Time-to-Productivity Ratio (TPR-WF) quantifies how efficiently resources are converted into outputs. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Ramp Weeks / Standard Ramp Benchmark - reported in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Ramp Weeks / Standard Ramp Benchmark
```
