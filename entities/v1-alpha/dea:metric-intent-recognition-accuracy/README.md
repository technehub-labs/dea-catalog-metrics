## 2. Definition

Intent Recognition Accuracy (IRA) measures the quality of outputs and outcomes in the Conversational AI & Chatbots domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Correctly Classified Utterances / Utterances, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
IRA = Correctly Classified Utterances / Utterances
```
