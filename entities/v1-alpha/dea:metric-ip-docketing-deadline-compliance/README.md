## 2. Definition

IP Docketing Deadline Compliance (IDDC) measures exposure to adverse outcomes in the Intellectual Property & Licensing domain. It is computed as Docketed Deadlines Met without Urgent Action / Deadlines, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Docketed Deadlines Met without Urgent Action / Deadlines
```
