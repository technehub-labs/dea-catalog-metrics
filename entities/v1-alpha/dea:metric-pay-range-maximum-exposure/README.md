## 2. Definition

Pay Range Maximum Exposure (PRME) measures conformance to standards, plans, or obligations in the Standard Workforce & Pay Metrics domain. It is computed as Employees above Range Maximum / Employees, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Employees above Range Maximum / Employees
```
