## 2. Definition

Workforce Scheduling Efficiency - Field (WSEF) measures how efficiently resources are converted into outputs in the Field Maintenance & Technical Field Service (Deep Dive) domain. It is computed as Jobs Scheduled versus Travel-Optimized Plan / Plan, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Jobs Scheduled versus Travel-Optimized Plan / Plan
```
