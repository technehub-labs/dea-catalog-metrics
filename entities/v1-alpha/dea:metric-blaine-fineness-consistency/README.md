## 2. Definition

Blaine Fineness Consistency (BFC) addresses the quality of outputs and outcomes and is a fixture of cement & building materials reporting. It is defined as Samples within Blaine Range / Samples; the result is stated in percent (%). In Manufacturing, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Samples within Blaine Range / Samples
```
