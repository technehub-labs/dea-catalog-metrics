## 2. Definition

Contractual Right-to-Audit Usage Rate (RAUR) captures conformance to standards, plans, or obligations for organizations tracking third-party risk management. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Audits Exercised on Critical Vendors / Planned Audits - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Audits Exercised on Critical Vendors / Planned Audits
```
