## 2. Definition

Engineering Change Order Cost (ECOC) captures the economic value created or preserved for organizations tracking engineering & design. It is computed as Total Cost of Implemented Changes / Changes, expressed in currency value. It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Total Cost of Implemented Changes / Changes
```
