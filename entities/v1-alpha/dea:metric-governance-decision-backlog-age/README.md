## 2. Definition

Within Enterprise Decision Effectiveness & Governance Monitoring, Governance Decision Backlog Age (GDBA) is used to gauge how efficiently resources are converted into outputs. It is computed as Days Decisions Await Governance Body, expressed in days. It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.
