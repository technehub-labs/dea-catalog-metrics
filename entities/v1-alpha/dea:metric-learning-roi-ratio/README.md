## 2. Definition

Learning ROI Ratio (LROIR) measures the economic value created or preserved in the Learning & Development Effectiveness (Deep Dive) domain. Its calculation is Monetized Performance Gain / L&D Cost, measured in ratio (x:1 or x). It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures business value returned per unit of learning investment. ROI forces L&D to connect to outcomes or lose budget honesty. ROI models built on participant estimates are soft. Read with learning transfer rate (Deep Dive - L&D) and human capital ROI.

## Formula

```
Monetized Performance Gain / L&D Cost
```
