## 2. Definition

A Insurance Distribution & Agency Management indicator, Agent Training Certification Currency (ATCC) quantifies capability maturity or development. It is computed as Agents with Current Certifications / Agents, expressed in percent (%). Its use is concentrated in Insurance. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
ATCC = Agents with Current Certifications / Agents
```
