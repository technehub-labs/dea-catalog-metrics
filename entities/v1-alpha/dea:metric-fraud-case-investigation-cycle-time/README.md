## 2. Definition

Within Enterprise Fraud & Financial Crime Management, Fraud Case Investigation Cycle Time (FCICT) is used to gauge how efficiently resources are converted into outputs. Its calculation is Days from Case Opening to Disposition, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Case Opening to Disposition
```
