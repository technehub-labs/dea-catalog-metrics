## 2. Definition

A Aerospace & Defense Program Management indicator, Configuration Control Board Cycle Time (CCBC) quantifies how efficiently resources are converted into outputs. It is computed as Days from Change Proposal to CCB Decision, expressed in days. It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is concentrated in Aerospace & Defense.

## Formula

```
Days from Change Proposal to CCB Decision
```
