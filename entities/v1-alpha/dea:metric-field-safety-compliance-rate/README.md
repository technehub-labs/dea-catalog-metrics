## 2. Definition

Within Telecom Field & Installation, Field Safety Compliance Rate (FSCR) is used to gauge conformance to standards, plans, or obligations. Its calculation is Audited Jobs Meeting Safety Standards / Jobs Audited, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Telecommunications practice.

## Formula

```
Audited Jobs Meeting Safety Standards / Jobs Audited
```
