## 2. Definition

Portfolio Dashboard Currency (PDC-PPM) addresses the quality of outputs and outcomes and is a fixture of program & portfolio management reporting. Its calculation is Initiatives with Data Refreshed on Cadence / Initiatives, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PDC-PPM = Initiatives with Data Refreshed on Cadence / Initiatives
```
