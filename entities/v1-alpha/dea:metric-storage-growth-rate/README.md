## 2. Definition

A Database & Data Platform Operations indicator, Storage Growth Rate (SGR-DB) quantifies the utilization or availability of capacity. It is defined as Month-over-Month Data Volume Growth; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. In Software, it is a recognized element of the standard performance toolkit.

## Formula

Month-over-Month Data Volume Growth
