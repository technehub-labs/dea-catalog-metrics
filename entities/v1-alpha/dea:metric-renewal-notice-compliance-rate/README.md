## 2. Definition

Within Contract Lifecycle Management, Renewal Notice Compliance Rate (RNCR) is used to gauge conformance to standards, plans, or obligations. It provides the day-to-day signal that a process is running as designed. Its calculation is Renewals Decided before Auto-Renewal Deadline / Renewals, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Renewals Decided before Auto-Renewal Deadline / Renewals
```
