## 2. Definition

A Chemicals & Specialty Materials indicator, Batch Right-First-Time Rate (Chemicals) (BRFT-C) quantifies the quality of outputs and outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Batches to Spec on First Pass / Batches - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Chemicals sector.

## Formula

```
Batches to Spec on First Pass / Batches
```
