## 2. Definition

A SRE & Observability Standard Measures indicator, SLO Review Cadence Compliance (SLOCC) quantifies conformance to standards, plans, or obligations. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as SLOs Reviewed per Cadence / SLOs; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Software, it is a recognized element of the standard performance toolkit.

## Formula

```
SLOs Reviewed per Cadence / SLOs
```
