## 2. Definition

A ERP & Enterprise Application Operations indicator, Change-Induced Incident Rate (ERP) (CIIR) quantifies exposure to adverse outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Incidents Caused by Change / Changes - reported in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Incidents Caused by Change / Changes
```
