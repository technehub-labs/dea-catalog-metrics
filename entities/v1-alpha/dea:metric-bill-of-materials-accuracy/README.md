## 2. Definition

Bill of Materials Accuracy (BOMA) captures the quality of outputs and outcomes for organizations tracking engineering & design. It provides the day-to-day signal that a process is running as designed. Its calculation is BOMs without Discrepancy / BOMs Audited, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
BOMs without Discrepancy / BOMs Audited
```
