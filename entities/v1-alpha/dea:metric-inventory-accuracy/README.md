## 2. Definition

A Supply Chain indicator, Inventory Accuracy (IA) quantifies the quality of outputs and outcomes. Its calculation is Accurate Inventory Records / Inventory Records Counted, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Accurate Inventory Records / Inventory Records Counted
```
