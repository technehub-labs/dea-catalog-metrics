## 2. Definition

Within Continuous Delivery & Deployment, Release Train Adherence (RTA-CD) is used to gauge conformance to standards, plans, or obligations. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Changes Shipping in Scheduled Release Train / Changes Ready; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Changes Shipping in Scheduled Release Train / Changes Ready
```
