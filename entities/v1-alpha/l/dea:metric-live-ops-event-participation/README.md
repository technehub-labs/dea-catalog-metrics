## 2. Definition

Live Ops Event Participation (LOEP) addresses the engagement or satisfaction of the people involved and is a fixture of gaming development & live operations reporting. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Players Joining Events / Active Players, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Gaming practice.

## Formula

```
LOEP = Players Joining Events / Active Players
```
