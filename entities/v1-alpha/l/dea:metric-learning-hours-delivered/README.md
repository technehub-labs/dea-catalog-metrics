## 2. Definition

Learning Hours Delivered (LHD) addresses the utilization or availability of capacity and is a fixture of learning & development reporting. Its calculation is Total Learner Instruction Hours per Period, measured in hours. It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
LHD = Total Learner Instruction Hours per Period
```
