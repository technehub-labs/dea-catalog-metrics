## 2. Definition

Load Test Baseline Adherence (LTBA-QA) measures the quality of outputs and outcomes in the Software Testing & Quality Engineering domain. It is computed as Load Tests Meeting Response Baselines / Tests, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
LTBA-QA = Load Tests Meeting Response Baselines / Tests
```
