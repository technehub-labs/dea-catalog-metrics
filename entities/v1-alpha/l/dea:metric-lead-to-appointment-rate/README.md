## 2. Definition

Lead to Appointment Rate (L2A) captures how effectively a process or entity achieves its intended outcome for organizations tracking real estate brokerage. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Appointments Set / Leads, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Real estate.

## Formula

```
L2A = Appointments Set / Leads
```
