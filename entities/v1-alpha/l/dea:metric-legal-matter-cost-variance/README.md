## 2. Definition

Within Legal Operations, Legal Matter Cost Variance (LMCV) is used to gauge how efficiently resources are converted into outputs. It is defined as Actual Matter Cost - Budgeted Cost / Budget; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
LMCV = Actual Matter Cost - Budgeted Cost / Budget
```
