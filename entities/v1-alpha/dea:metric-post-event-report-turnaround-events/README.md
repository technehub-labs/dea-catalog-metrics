## 2. Definition

Post-Event Report Turnaround (Events) (PERT) measures how efficiently resources are converted into outputs in the Events & Exhibitions domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Days from Event Close to Stakeholder Report, measured in days. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Media & Entertainment practice.

## Formula

```
Days from Event Close to Stakeholder Report
```
