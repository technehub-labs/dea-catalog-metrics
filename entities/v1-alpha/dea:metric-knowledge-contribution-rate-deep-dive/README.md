## 2. Definition

Knowledge Contribution Rate (Deep Dive) (KCR-KM) captures the engagement or satisfaction of the people involved for organizations tracking knowledge management (deep dive). The formula is Active Contributors / Employees - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
KCR-KM = Active Contributors / Employees
```
