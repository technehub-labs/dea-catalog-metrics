## 2. Definition

Engineering Escalation Resolution Time (EERT) captures how efficiently resources are converted into outputs for organizations tracking engineering & design. The formula is Days to Resolve Technical Escalation - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days to Resolve Technical Escalation
```
