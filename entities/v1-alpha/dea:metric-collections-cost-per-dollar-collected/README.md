## 2. Definition

Collections Cost per Dollar Collected (CCPDC) measures how efficiently resources are converted into outputs in the Credit & Collections Risk (Enterprise) domain. It is defined as Collections Spend / Dollars Collected; the result is stated in currency per unit. It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Collections Spend / Dollars Collected
```
