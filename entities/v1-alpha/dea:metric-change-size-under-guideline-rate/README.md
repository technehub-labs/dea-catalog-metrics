## 2. Definition

A Code Review & Peer Quality indicator, Change Size Under Guideline Rate (CSUG) quantifies the quality of outputs and outcomes. The formula is Changes within Size Guideline / Merged Changes - reported in percent (%). It is a standard measure in the Software sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Changes within Size Guideline / Merged Changes
```
