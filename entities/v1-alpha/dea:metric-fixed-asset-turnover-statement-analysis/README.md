## 2. Definition

A Financial Statement Analysis Ratios (Deep Dive) indicator, Fixed Asset Turnover (Statement Analysis) (FATO) quantifies how efficiently resources are converted into outputs. The formula is Revenue / Net Fixed Assets - reported in ratio (x:1 or x). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures revenue generated per unit of fixed assets in analytical comparison. It exposes whether the capital base is productive. Asset-light business models make cross-sector comparison misleading. Read with capital intensity ratio and return on assets (Deep Dive).

## Formula

```
Revenue / Net Fixed Assets
```
