## 2. Definition

Channel Program ROI (CPROI) addresses the economic value created or preserved and is a fixture of channel & distribution management reporting. The formula is Channel Contribution Margin / Program Cost - reported in ratio (x:1 or x). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the full return of the partner program against its cost (incentives, MDF, support). ROI keeps programs honest about whether the channel builds or merely bills. ROI excluding partner-management overhead flatters. Read with channel partner productivity and marketing development fund utilization rate.

## Formula

```
Channel Contribution Margin / Program Cost
```
