## 2. Definition

A Sports Clubs & Leagues (Deep Dive) indicator, Broadcast Compliance Rate (Sports) (BCR-S) quantifies conformance to standards, plans, or obligations. It is defined as Matches Meeting Broadcast Standards / Matches; the result is stated in percent (%). In Sports, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Matches Meeting Broadcast Standards / Matches
```
