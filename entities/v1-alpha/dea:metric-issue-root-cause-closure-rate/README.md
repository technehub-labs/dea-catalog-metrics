## 2. Definition

Within Project Risk & Issue Management, Issue Root Cause Closure Rate (IRCCR) is used to gauge the quality of outputs and outcomes. The formula is Issues Closed with RCA / Recurring-Issue Class - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Issues Closed with RCA / Recurring-Issue Class
```
