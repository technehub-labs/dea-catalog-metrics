## 2. Definition

Hospital-Acquired Pressure Injury Rate (HAPIR) addresses the quality of outputs and outcomes and is a fixture of healthcare quality & patient safety standard measures reporting. Its calculation is Stage 2+ Pressure Injuries Acquired / Admissions, measured in events per thousand or million (scaled). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Healthcare practice.

## Formula

```
Stage 2+ Pressure Injuries Acquired / Admissions
```
