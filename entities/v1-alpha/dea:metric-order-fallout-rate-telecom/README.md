## 2. Definition

Order Fallout Rate (Telecom) (OFR-T) measures the quality of outputs and outcomes in the Telecom Customer Experience & Billing domain. Its calculation is Orders Requiring Manual Intervention / Orders Processed, measured in percent (%). It originates from and is most used in Telecommunications practice. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Orders Requiring Manual Intervention / Orders Processed
```
