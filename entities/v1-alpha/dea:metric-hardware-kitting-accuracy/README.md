## 2. Definition

Hardware Kitting Accuracy (HKA) captures the quality of outputs and outcomes for organizations tracking furniture & wood products. It provides the day-to-day signal that a process is running as designed. Its calculation is Kits Complete on First Pick / Kits, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Manufacturing practice.

## Formula

```
Kits Complete on First Pick / Kits
```
