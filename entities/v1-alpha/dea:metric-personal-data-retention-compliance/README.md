## 2. Definition

A Data Privacy & Protection indicator, Personal Data Retention Compliance (PDRC) quantifies conformance to standards, plans, or obligations. The formula is Personal Data Purged per Schedule / Data Due for Purge - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Personal Data Purged per Schedule / Data Due for Purge
```
