## 2. Definition

A Marketing Attribution & Analytics indicator, Identity Resolution Rate (IRR-M) quantifies capability maturity or development. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Touchpoints Resolved to Person / Total Touchpoints, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Touchpoints Resolved to Person / Total Touchpoints
```
