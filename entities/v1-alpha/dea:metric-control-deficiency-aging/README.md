## 2. Definition

Control Deficiency Aging (CDA-IC) captures exposure to adverse outcomes for organizations tracking internal controls & financial reporting integrity. It is defined as Average Age of Open Control Deficiencies; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Average Age of Open Control Deficiencies
```
