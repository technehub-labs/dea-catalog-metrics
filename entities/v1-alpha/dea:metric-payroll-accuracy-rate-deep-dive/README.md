## 2. Definition

Payroll Accuracy Rate (Deep Dive) (PARD) captures the quality of outputs and outcomes for organizations tracking standard workforce & pay metrics. Its calculation is Payroll Records Paid Correctly / Records Processed, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Payroll Records Paid Correctly / Records Processed
```
