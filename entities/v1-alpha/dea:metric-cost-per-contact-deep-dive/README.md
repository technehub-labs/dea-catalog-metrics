## 2. Definition

A Contact Center Standard Measures (Deep Dive) indicator, Cost per Contact (Deep Dive) (CPCDD) quantifies how efficiently resources are converted into outputs. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Total Center Cost / Contacts Handled - reported in currency per unit. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Total Center Cost / Contacts Handled
```
