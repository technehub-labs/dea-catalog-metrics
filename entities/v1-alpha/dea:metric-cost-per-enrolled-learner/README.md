## 2. Definition

Cost per Enrolled Learner (CPEL) addresses how efficiently resources are converted into outputs and is a fixture of education & training (deep dive) reporting. It is defined as Total Delivery Cost / Enrolments; the result is stated in currency value. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Education, it is a recognized element of the standard performance toolkit.

## Formula

```
CPEL = Total Delivery Cost / Enrolments
```
