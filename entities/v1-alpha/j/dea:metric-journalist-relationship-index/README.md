## 2. Definition

Journalist Relationship Index (JRI) addresses capability maturity or development and is a fixture of corporate communications & pr (deep dive) reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Composite Journalist Engagement Score - reported in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.
