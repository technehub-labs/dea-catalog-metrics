## 2. Definition

A Textile & Apparel indicator, Trims and Accessories Stockout Rate (TAS) quantifies exposure to adverse outcomes. It is defined as Trims Stockouts / Trims Required Events; the result is stated in percent (%). In Textile & apparel, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Trims Stockouts / Trims Required Events
```
