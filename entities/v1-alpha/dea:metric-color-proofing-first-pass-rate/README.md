## 2. Definition

Color Proofing First-Pass Rate (CPF) measures the quality of outputs and outcomes in the Printing & Publishing domain. Its calculation is Jobs Passing Color Proof First Time / Jobs Proofed, measured in percent (%). It originates from and is most used in Printing & publishing practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Jobs Passing Color Proof First Time / Jobs Proofed
```
