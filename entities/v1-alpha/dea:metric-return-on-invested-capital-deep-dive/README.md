## 2. Definition

Return on Invested Capital (Deep Dive) (ROICDD) measures the economic value created or preserved in the Financial Statement Analysis Ratios (Deep Dive) domain. It is computed as NOPAT / Invested Capital, expressed in percent (%). It is applied across virtually every sector. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures return on the capital actively deployed in operations. ROIC is the quality test of growth: growth above cost of capital creates value, below it destroys. Invested-capital definitions vary and drive the number. Read with ROIC-WACC spread and return on capital employed (Deep Dive).

## Formula

```
NOPAT / Invested Capital
```
