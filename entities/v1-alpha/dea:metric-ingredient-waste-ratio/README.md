## 2. Definition

Ingredient Waste Ratio (IWR) addresses how efficiently resources are converted into outputs and is a fixture of food & beverage manufacturing reporting. It is computed as Ingredient Waste / Ingredient Input, expressed in percent (%). Its use is concentrated in Food & Beverage. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Ingredient Waste / Ingredient Input
```
