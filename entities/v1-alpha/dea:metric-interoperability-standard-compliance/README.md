## 2. Definition

Interoperability Standard Compliance (ISC-SA) captures conformance to standards, plans, or obligations for organizations tracking software architecture & technical design. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Integrations Using Approved Standards / Integrations, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Integrations Using Approved Standards / Integrations
```
