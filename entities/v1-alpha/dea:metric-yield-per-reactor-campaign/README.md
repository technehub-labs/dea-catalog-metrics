## 2. Definition

Yield per Reactor Campaign (YPRC) addresses how efficiently resources are converted into outputs and is a fixture of chemicals & specialty materials reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Output Mass / Theoretical Maximum Mass; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Chemicals, it is a recognized element of the standard performance toolkit.

## Formula

```
Output Mass / Theoretical Maximum Mass
```
