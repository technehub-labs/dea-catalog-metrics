## 2. Definition

Cross-Device User Stitching Accuracy (CDUSA) measures the quality of outputs and outcomes in the Web & Digital Analytics Standard Measures domain. It is defined as Identity Graph Matches Confirmed Correct / Matches Sampled; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Digital product, it is a recognized element of the standard performance toolkit.

## Formula

```
CDUSA = Identity Graph Matches Confirmed Correct / Matches Sampled
```
