## 2. Definition

Fraud Detection Latency (FDL-EF) captures exposure to adverse outcomes for organizations tracking enterprise fraud & financial crime management. The formula is Days between Fraud Occurrence and Detection - reported in days. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days between Fraud Occurrence and Detection
```
