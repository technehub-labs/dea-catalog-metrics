## 2. Definition

Average Premium per Policy (New Business) (APPNB) captures the economic value created or preserved for organizations tracking insurance underwriting. It is defined as New Business Premium / New Policies; the result is stated in currency value. In Insurance, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
New Business Premium / New Policies
```
