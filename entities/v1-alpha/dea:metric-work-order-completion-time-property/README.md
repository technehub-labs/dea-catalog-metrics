## 2. Definition

Work Order Completion Time (Property) (WOCT) measures how efficiently resources are converted into outputs in the Real Estate Portfolio & Property Management domain. It is defined as Days from Request to Completion; the result is stated in days. It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Real Estate, it is a recognized element of the standard performance toolkit.
