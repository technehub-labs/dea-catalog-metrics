## 2. Definition

Data Query Resolution Time (Clinical) (DQRT) measures how efficiently resources are converted into outputs in the Pharma R&D & Clinical Trials domain. The formula is Days to Resolve Data Queries - reported in days. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Pharmaceuticals sector.

## Formula

```
DQRT = Days to Resolve Data Queries
```
