## 2. Definition

A Software Development - Coding & Engineering Practices indicator, Developer Onboarding Time (DOT-SD) quantifies capability maturity or development. It is defined as Days from Join to First Production Merge; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
DOT-SD = Days from Join to First Production Merge
```
