## 2. Definition

Within Agile Delivery & Team Effectiveness, Definition of Done Compliance (DODC-AG) is used to gauge the quality of outputs and outcomes. Its calculation is Stories Meeting Full Definition of Done at Close / Stories, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
DODC-AG = Stories Meeting Full Definition of Done at Close / Stories
```
