## 2. Definition

A Software Architecture & Technical Design indicator, Design Pattern Standard Compliance (DPSC-SA) quantifies conformance to standards, plans, or obligations. It is defined as Components Following Approved Patterns / Components; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
DPSC-SA = Components Following Approved Patterns / Components
```
