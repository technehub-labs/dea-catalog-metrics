## 2. Definition

Discount Erosion Rate (DER-UE) captures the economic value created or preserved for organizations tracking unit economics & growth (deep dive). It is defined as Average Discount Depth on New Contracts; the result is stated in percent (%). In Software, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
DER-UE = Average Discount Depth on New Contracts
```
