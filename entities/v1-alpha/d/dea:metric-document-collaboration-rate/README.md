## 2. Definition

Document Collaboration Rate (DCR-DW) measures the engagement or satisfaction of the people involved in the Digital Workplace & Collaboration domain. It is defined as Documents Co-Authored / Documents Created; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
DCR-DW = Documents Co-Authored / Documents Created
```
