## 2. Definition

A Data Governance & Stewardship indicator, Data Standard Compliance Rate (DSCR-DG) quantifies conformance to standards, plans, or obligations. It is defined as Records Conforming to Defined Standards / Records Sampled; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
DSCR-DG = Records Conforming to Defined Standards / Records Sampled
```
