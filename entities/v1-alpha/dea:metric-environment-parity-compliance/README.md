## 2. Definition

A Continuous Delivery & Deployment indicator, Environment Parity Compliance (EPC-CD) quantifies the quality of outputs and outcomes. Its calculation is Non-Production Environments Matching Production Configuration / Environments, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Non-Production Environments Matching Production Configuration / Environments
```
