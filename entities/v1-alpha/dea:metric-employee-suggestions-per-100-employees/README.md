## 2. Definition

Employee Suggestions per 100 Employees (ESP100) measures capability maturity or development in the Balanced Scorecard - Learning & Growth Perspective domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Suggestions Submitted per 100 Employees; the result is stated in count (items per period). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.
