## 2. Definition

A Engineering & Design indicator, First-Pass Design Approval Rate (FPDAR) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Designs Approved without Rework / Reviews, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Designs Approved without Rework / Reviews
```
