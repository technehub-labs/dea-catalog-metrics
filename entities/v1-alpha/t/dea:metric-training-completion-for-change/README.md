## 2. Definition

Training Completion for Change (TCC-C) captures conformance to standards, plans, or obligations for organizations tracking change management. Its calculation is Target Users Completing Change Training / Target Users, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
TCC-C = Target Users Completing Change Training / Target Users
```
