## 2. Definition

Within Contract Lifecycle Management, Termination Notice Compliance (TNC-CL) is used to gauge the economic value created or preserved. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Terminations Exercised within Notice Windows / Intended Terminations - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
TNC-CL = Terminations Exercised within Notice Windows / Intended Terminations
```
