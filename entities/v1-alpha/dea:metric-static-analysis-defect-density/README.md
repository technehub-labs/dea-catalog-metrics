## 2. Definition

Static Analysis Defect Density (SADD) captures the quality of outputs and outcomes for organizations tracking software engineering. The formula is Static Analysis Defects per 1,000 Lines of Code - reported in ratio (x:1 or x). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula
