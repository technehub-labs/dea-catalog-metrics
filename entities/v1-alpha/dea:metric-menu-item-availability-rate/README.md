## 2. Definition

Menu Item Availability Rate (MIAR) captures the quality of outputs and outcomes for organizations tracking restaurant operations (deep dive). Its calculation is In-Stock Menu Items / Menu Items, measured in percent (%). It originates from and is most used in Restaurants practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
In-Stock Menu Items / Menu Items
```
