## 2. Definition

Within Construction & Engineering, Quality Inspection First-Time Pass (QIFP) is used to gauge the quality of outputs and outcomes. It is defined as Inspections Passed First Time / Inspections Performed; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Construction & engineering, it is a recognized element of the standard performance toolkit.

## Formula

```
Inspections Passed First Time / Inspections Performed
```
