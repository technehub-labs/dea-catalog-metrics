## 2. Definition

Records Classification Coverage (RCC) measures conformance to standards, plans, or obligations in the Records & Information Management domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Records Filed under Retention Class / Records Created; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Records Filed under Retention Class / Records Created
```
