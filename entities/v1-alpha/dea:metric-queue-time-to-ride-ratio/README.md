## 2. Definition

Queue Time to Ride Ratio (QTRR) addresses the quality of outputs and outcomes and is a fixture of entertainment venues & attractions reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Average Wait Time / Ride Duration; the result is stated in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
Average Wait Time / Ride Duration
```
