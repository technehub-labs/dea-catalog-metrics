## 2. Definition

Style Changeover Time (Apparel) (SCT-A) captures how efficiently resources are converted into outputs for organizations tracking textile & apparel. It is computed as Minutes to Change Production Line between Styles, expressed in minutes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is concentrated in Textile & apparel.
