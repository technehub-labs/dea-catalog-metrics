## 2. Definition

Refinance Capture Rate (RCR-RE) addresses growth over time and is a fixture of real estate & mortgage standard measures reporting. The formula is Eligible Borrowers Refinanced / Eligible Population - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Real estate sector.

## Formula

```
Eligible Borrowers Refinanced / Eligible Population
```
