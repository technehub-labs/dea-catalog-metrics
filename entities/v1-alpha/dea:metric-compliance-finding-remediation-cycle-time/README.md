## 2. Definition

Compliance Finding Remediation Cycle Time (CFRC) captures how efficiently resources are converted into outputs for organizations tracking compliance monitoring & testing. It is computed as Days from Finding to Verified Remediation, expressed in days. It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Finding to Verified Remediation
```
