## 2. Definition

Pre-Change Validation Coverage (PCVC) addresses exposure to adverse outcomes and is a fixture of network change & configuration management reporting. Its calculation is Changes with Validated Pre-Change State / Changes, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Changes with Validated Pre-Change State / Changes
```
