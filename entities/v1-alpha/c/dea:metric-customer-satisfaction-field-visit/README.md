## 2. Definition

Customer Satisfaction (Field Visit) (CSATFV) addresses the economic value created or preserved and is a fixture of field service & asset performance reporting. It is computed as Post-Visit Satisfaction Score, expressed in score (points). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

CSATFV = Post-Visit Satisfaction Score
