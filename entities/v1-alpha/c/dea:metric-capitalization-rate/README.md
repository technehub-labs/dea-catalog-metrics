## 2. Definition

A Real Estate & Mortgage Standard Measures indicator, Capitalization Rate (CAPRT) quantifies the economic value created or preserved. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Net Operating Income / Property Value; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. In Real estate, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures property net operating income relative to its value. Cap rate is the market's pricing of income property risk. Cap rate compression can mask deteriorating fundamentals with rising values. Read with cash-on-cash return and yield on cost (Development).

## Formula

```
CAPRT = Net Operating Income / Property Value
```
