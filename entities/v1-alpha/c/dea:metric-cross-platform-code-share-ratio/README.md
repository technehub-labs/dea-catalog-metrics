## 2. Definition

Cross-Platform Code Share Ratio (CPCSR) captures how efficiently resources are converted into outputs for organizations tracking mobile & client development. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Shared Code Lines / Total Code Lines - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Software sector.

## Formula

```
CPCSR = Shared Code Lines / Total Code Lines
```
