## 2. Definition

Crisis Escalation Threshold Accuracy (CETA) addresses the quality of outputs and outcomes and is a fixture of crisis management & emergency response reporting. It is defined as Events Correctly Classified on First Assessment / Events; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CETA = Events Correctly Classified on First Assessment / Events
```
