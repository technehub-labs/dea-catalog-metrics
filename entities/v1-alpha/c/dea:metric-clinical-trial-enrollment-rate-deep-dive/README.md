## 2. Definition

Within Pharma R&D & Clinical Trials, Clinical Trial Enrollment Rate (Deep Dive) (CTER) is used to gauge how effectively a process or entity achieves its intended outcome. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Enrolled Subjects / Planned Subjects, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Pharmaceuticals.

## Formula

```
CTER = Enrolled Subjects / Planned Subjects
```
