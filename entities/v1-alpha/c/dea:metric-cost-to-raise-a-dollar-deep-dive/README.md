## 2. Definition

A Nonprofit & Donor Operations (Deep Dive) indicator, Cost to Raise a Dollar (Deep Dive) (CRD-D) quantifies how efficiently resources are converted into outputs. It is computed as Fundraising Cost / Funds Raised, expressed in ratio (x:1 or x). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Lower values are better; each reduction is an improvement. Its use is concentrated in Nonprofit.

## 3. Context

Measures fundraising expense per dollar raised. It is the fundraising-efficiency verdict donors and watchdogs price, and it exposes when acquisition machinery (events, agencies, mail) has outgrown its yield. Event fundraising routinely shows attractive gross revenue with terrible cost-to-raise once fully loaded, so allocation honesty decides the number. Read with donor lifetime value (Deep Dive) - the denominator of sustainable acquisition cost.

## Formula

```
CRD-D = Fundraising Cost / Funds Raised
```
