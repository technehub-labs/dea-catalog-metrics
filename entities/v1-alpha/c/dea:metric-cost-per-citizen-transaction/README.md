## 2. Definition

Cost per Citizen Transaction (CPCT) measures how efficiently resources are converted into outputs in the Government & Public Administration domain. It is defined as Total Service Cost / Transactions; the result is stated in currency value. Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. In Public Sector, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures the fully loaded cost of processing a standard service transaction. It enables channel economics, digital business cases, and benchmarking across agencies, and it exposes the hidden subsidy of manual workarounds. Standardize transaction types before comparing, or the metric becomes an argument about definitions rather than performance. Read with digital channel adoption (Government) and volume-mix trends.

## Formula

```
CPCT = Total Service Cost / Transactions
```
