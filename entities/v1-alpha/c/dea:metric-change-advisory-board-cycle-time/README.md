## 2. Definition

Within Release Management & Environments, Change Advisory Board Cycle Time (CABCT) is used to gauge how efficiently resources are converted into outputs. It is defined as Days from CAB Submission to Decision; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
CABCT = Days from CAB Submission to Decision
```
