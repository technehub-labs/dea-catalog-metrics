## 2. Definition

A Internal Controls & Financial Reporting Integrity indicator, Control Environment Maturity Score (CEMS) quantifies capability maturity or development. The formula is COSO-Based Maturity Rating of Control Environment - reported in score (points). It is applied across virtually every sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the overall maturity of the control environment across culture, competence, and oversight. Environment is the soil controls grow in. Maturity self-assessed by control owners drifts optimistic. Read with control environment assessment and key control operating effectiveness rate.

## Formula

```
CEMS = COSO-Based Maturity Rating of Control Environment
```
