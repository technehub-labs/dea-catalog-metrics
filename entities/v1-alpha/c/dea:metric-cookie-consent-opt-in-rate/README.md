## 2. Definition

A Web & Digital Analytics Standard Measures indicator, Cookie Consent Opt-In Rate (CCOIR) quantifies the engagement or satisfaction of the people involved. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Consented Sessions / Sessions Prompted - reported in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. It is a standard measure in the Digital product sector.

## Formula

```
CCOIR = Consented Sessions / Sessions Prompted
```
