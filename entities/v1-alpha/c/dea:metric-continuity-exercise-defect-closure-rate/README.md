## 2. Definition

Continuity Exercise Defect Closure Rate (CEDCR) measures conformance to standards, plans, or obligations in the Business Continuity & Disaster Recovery domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Exercise Findings Remediated by Next Exercise / Findings; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
CEDCR = Exercise Findings Remediated by Next Exercise / Findings
```
