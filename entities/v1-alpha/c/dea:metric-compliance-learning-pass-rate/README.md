## 2. Definition

Compliance Learning Pass Rate (CLPR-LD) measures conformance to standards, plans, or obligations in the Learning & Development Effectiveness (Deep Dive) domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Mandatory Course Passes on First Attempt / Attempts, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
CLPR-LD = Mandatory Course Passes on First Attempt / Attempts
```
