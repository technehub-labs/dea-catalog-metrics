## 2. Definition

A Pharma R&D & Clinical Trials indicator, Clinical Trial Site Overhead Ratio (CTSO) quantifies how efficiently resources are converted into outputs. Its calculation is Site Overhead Costs / Direct Trial Costs, measured in percent (%). It originates from and is most used in Pharmaceuticals practice. Its value drives prioritization and resource reallocation among competing initiatives. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
CTSO = Site Overhead Costs / Direct Trial Costs
```
