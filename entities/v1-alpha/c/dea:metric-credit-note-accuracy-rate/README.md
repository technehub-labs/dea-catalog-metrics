## 2. Definition

A Accounts Payable & Receivable Operations (Deep Dive) indicator, Credit Note Accuracy Rate (CNAR) quantifies the quality of outputs and outcomes. It is defined as Credit Notes Issued Correctly First Time / Credit Notes; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
CNAR = Credit Notes Issued Correctly First Time / Credit Notes
```
