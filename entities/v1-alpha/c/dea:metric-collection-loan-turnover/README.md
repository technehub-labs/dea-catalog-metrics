## 2. Definition

Collection Loan Turnover (CLT-A) addresses the economic value created or preserved and is a fixture of arts & culture reporting. The formula is Works Loaned / Works in Collection per Period - reported in ratio (x:1 or x). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Arts & culture sector.

## 3. Context

Measures the rate at which collection items are loaned to other institutions. It matters because loans generate revenue and scholarly visibility while carrying conservation risk. Turnover can be chased with high-risk loans that damage long-term preservation. Read with Condition Reports on return and conservation cost to confirm lending is responsible.

## Formula

```
CLT-A = Works Loaned / Works in Collection per Period
```
