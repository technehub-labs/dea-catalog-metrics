## 2. Definition

Within Enterprise OKR & Performance Management, Continuous Feedback Adoption Rate (CFAR-OKR) is used to gauge the engagement or satisfaction of the people involved. It is computed as Employees Giving or Receiving Regular Feedback / Employees, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CFAR-OKR = Employees Giving or Receiving Regular Feedback / Employees
```
