## 2. Definition

A Marketing & Advertising Standard Measures (Deep Dive) indicator, Cost per Click (Deep Dive) (CPCDD) quantifies how efficiently resources are converted into outputs. The formula is Spend / Clicks - reported in currency per unit. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
CPCDD = Spend / Clicks
```
