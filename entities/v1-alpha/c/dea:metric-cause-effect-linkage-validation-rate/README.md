## 2. Definition

Within Balanced Scorecard Implementation & Review, Cause-Effect Linkage Validation Rate (CELV) is used to gauge the quality of outputs and outcomes. Its calculation is Hypothesized Linkages Supported by Correlation / Linkages, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures how many of the scorecard's assumed objective linkages are supported by data. Balanced scorecards are hypotheses; validation is what upgrades them to strategy maps. Linkages validated by anecdote rather than analysis are decoration. Read with leading indicator share and strategy map refresh currency.

## Formula

```
CELV = Hypothesized Linkages Supported by Correlation / Linkages
```
