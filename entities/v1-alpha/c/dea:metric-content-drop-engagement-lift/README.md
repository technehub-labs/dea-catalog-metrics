## 2. Definition

Content Drop Engagement Lift (CDEL) measures growth over time in the Gaming Development & Live Operations domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Post-Release Engagement - Baseline, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Gaming.

## Formula

```
CDEL = Post-Release Engagement - Baseline
```
