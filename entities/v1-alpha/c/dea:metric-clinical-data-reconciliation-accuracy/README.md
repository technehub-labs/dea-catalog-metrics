## 2. Definition

Within Pharma R&D & Clinical Trials, Clinical Data Reconciliation Accuracy (CDRA) is used to gauge the quality of outputs and outcomes. Its calculation is Reconciled Records without Discrepancy / Records, measured in percent (%). It originates from and is most used in Pharmaceuticals practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
CDRA = Reconciled Records without Discrepancy / Records
```
