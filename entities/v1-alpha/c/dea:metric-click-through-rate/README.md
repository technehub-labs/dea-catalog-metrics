## 2. Definition

Click-Through Rate (CTR) captures how effectively a process or entity achieves its intended outcome for organizations tracking marketing. It is defined as Clicks / Impressions; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
CTR = Clicks / Impressions
```
