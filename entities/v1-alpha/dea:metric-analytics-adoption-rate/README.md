## 2. Definition

Analytics Adoption Rate (AAR) addresses the economic value created or preserved and is a fixture of data management & analytics reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Active Analytics Users / Licensed Analytics Users, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of target users actively using analytics tools and outputs. It matters because unused analytics is expensive shelfware regardless of dashboard quality. Gaming risk includes counting logins or embedded glance views as adoption. Read with Decision-Making Cycle time evidence and Time to Data Insight to confirm adoption reflects use in real decisions.

## Formula

```
Active Analytics Users / Licensed Analytics Users
```
