## 2. Definition

Time to Onboard Gig Worker (TOGW) measures how efficiently resources are converted into outputs in the Gig & Contingent Workforce domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Days from Application to First Task Eligibility; the result is stated in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula
