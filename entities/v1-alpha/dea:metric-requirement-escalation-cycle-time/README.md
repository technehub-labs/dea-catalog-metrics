## 2. Definition

Within Requirements Engineering & Product Discovery, Requirement Escalation Cycle Time (RECT) is used to gauge how efficiently resources are converted into outputs. Its calculation is Days to Resolve Requirements Ambiguity or Conflict, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days to Resolve Requirements Ambiguity or Conflict
```
