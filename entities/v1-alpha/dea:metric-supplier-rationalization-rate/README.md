## 2. Definition

Supplier Rationalization Rate (SUPRR) measures how efficiently resources are converted into outputs in the Strategic Sourcing & Supplier Performance (Deep Dive) domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Redundant Suppliers Consolidated / Suppliers Identified, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
SUPRR = Redundant Suppliers Consolidated / Suppliers Identified
```
