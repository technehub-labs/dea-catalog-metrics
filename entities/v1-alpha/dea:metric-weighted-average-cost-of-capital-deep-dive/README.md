## 2. Definition

Weighted Average Cost of Capital (Deep Dive) (WACC) addresses the economic value created or preserved and is a fixture of valuation & corporate finance standard measures reporting. The formula is Weighted Cost of Equity and After-Tax Debt - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the blended required return on debt and equity capital. WACC is the hurdle against which every project and ROIC is judged. Estimation sensitivity (beta, risk premium) makes WACC an input with error bars. Read with ROIC-WACC spread and hurdle rate consistency.
