## 2. Definition

Return Logistics Cycle Time (RLCT) captures how efficiently resources are converted into outputs for organizations tracking parcel & last-mile logistics (deep dive). It is defined as Days from Return Initiation to Restock; the result is stated in days. In Logistics & Trade, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Days from Return Initiation to Restock
```
