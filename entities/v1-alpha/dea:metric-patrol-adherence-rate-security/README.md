## 2. Definition

A Security Services & Guarding indicator, Patrol Adherence Rate (Security) (PAR-S) quantifies conformance to standards, plans, or obligations. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Patrols Completed per Tour Plan / Planned, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Security.

## Formula

```
Patrols Completed per Tour Plan / Planned
```
