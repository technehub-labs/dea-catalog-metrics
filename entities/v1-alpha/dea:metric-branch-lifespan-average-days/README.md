## 2. Definition

Branch Lifespan - Average Days (BLD-SD) addresses how efficiently resources are converted into outputs and is a fixture of software development - coding & engineering practices reporting. Its calculation is Average Days from Branch Creation to Merge, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Average Days from Branch Creation to Merge
```
