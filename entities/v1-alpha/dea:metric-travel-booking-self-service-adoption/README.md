## 2. Definition

A Corporate Travel Management indicator, Travel Booking Self-Service Adoption (TBSS) quantifies how efficiently resources are converted into outputs. The formula is Bookings via Approved Self-Booking Tool / Total Bookings - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
TBSS = Bookings via Approved Self-Booking Tool / Total Bookings
```
