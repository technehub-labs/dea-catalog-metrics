## 2. Definition

Within Operating Model Monitoring & Design Effectiveness, Location Strategy Compliance Rate (LSCR-OM) is used to gauge conformance to standards, plans, or obligations. The formula is Roles Located per Location Policy / Roles - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Roles Located per Location Policy / Roles
```
