## 2. Definition

A Data Privacy & Protection indicator, Data Discovery Coverage (PII) (PDDC) quantifies exposure to adverse outcomes. The formula is Systems Scanned for Personal Data / Systems in Scope - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Systems Scanned for Personal Data / Systems in Scope
```
