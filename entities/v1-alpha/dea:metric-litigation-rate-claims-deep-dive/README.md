## 2. Definition

A Insurance Claims Deep Dive indicator, Litigation Rate (Claims) (Deep Dive) (LRC) quantifies exposure to adverse outcomes. The formula is Claims Reaching Litigation / Contested Claims - reported in percent (%). It is a standard measure in the Insurance sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Claims Reaching Litigation / Contested Claims
```
