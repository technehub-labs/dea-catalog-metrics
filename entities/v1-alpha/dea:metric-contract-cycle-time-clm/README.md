## 2. Definition

Contract Cycle Time (CLM) (CCT-CL) measures how efficiently resources are converted into outputs in the Contract Lifecycle Management domain. It is computed as Days from Request to Fully Executed Contract, expressed in days. It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

Days from Request to Fully Executed Contract
