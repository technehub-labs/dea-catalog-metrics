## 2. Definition

A Marketing Attribution & Analytics indicator, Tag Firing Compliance (TFC) quantifies the quality of outputs and outcomes. It is computed as Tags Firing Correctly / Tags Deployed, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Tags Firing Correctly / Tags Deployed
```
