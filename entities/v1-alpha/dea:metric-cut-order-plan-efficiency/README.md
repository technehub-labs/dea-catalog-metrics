## 2. Definition

Cut Order Plan Efficiency (COPE) addresses how efficiently resources are converted into outputs and is a fixture of textile & apparel (deep dive) reporting. It is defined as Fabric Utilized in Cut / Fabric Issued; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Textiles & Apparel, it is a recognized element of the standard performance toolkit.

## Formula

```
COPE = Fabric Utilized in Cut / Fabric Issued
```
