## 2. Definition

Within Contact Center Standard Measures (Deep Dive), First Contact Resolution Rate (Deep Dive) (FCRDD) is used to gauge the quality of outputs and outcomes. Its calculation is Contacts Resolved without Repeat / Contacts, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Contacts Resolved without Repeat / Contacts
```
