## 2. Definition

A Retail Standard Measures indicator, Markdown Rate (Deep Dive) (MKDD) quantifies the economic value created or preserved. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Markdown Value / Gross Sales, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Its use is concentrated in Retail & E-commerce.

## Formula

```
Markdown Value / Gross Sales
```
