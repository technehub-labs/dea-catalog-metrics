## 2. Definition

Color Consistency Delta-E Compliance (CCDC) measures the quality of outputs and outcomes in the Packaging & Plastics domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Measurements within Delta-E Tolerance / Measurements; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Manufacturing, it is a recognized element of the standard performance toolkit.

## Formula

```
Measurements within Delta-E Tolerance / Measurements
```
