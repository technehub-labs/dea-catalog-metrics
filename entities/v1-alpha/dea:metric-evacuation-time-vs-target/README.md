## 2. Definition

Evacuation Time vs Target (ETVT) measures exposure to adverse outcomes in the Crisis Management & Emergency Response domain. It is computed as Actual Evacuation Time / Target Evacuation Time, expressed in ratio (x:1 or x). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Actual Evacuation Time / Target Evacuation Time
```
