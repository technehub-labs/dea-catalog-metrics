## 2. Definition

Within Software Architecture & Technical Design, Cyclomatic Complexity Threshold Compliance (CCTC-SA) is used to gauge the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Functions within Complexity Threshold / Functions; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Functions within Complexity Threshold / Functions
```
