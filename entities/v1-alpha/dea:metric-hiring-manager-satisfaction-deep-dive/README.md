## 2. Definition

Hiring Manager Satisfaction (Deep Dive) (HMSATD) captures the quality of outputs and outcomes for organizations tracking talent acquisition deep dive. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Hiring Manager Survey Score with TA Process - reported in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.
