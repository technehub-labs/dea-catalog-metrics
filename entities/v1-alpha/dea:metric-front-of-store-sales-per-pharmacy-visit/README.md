## 2. Definition

Front-of-Store Sales per Pharmacy Visit (FSSPV) captures the economic value created or preserved for organizations tracking pharmacy retail. It is computed as Retail Sales / Pharmacy Visits, expressed in currency per unit. It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Healthcare.

## Formula

```
Retail Sales / Pharmacy Visits
```
