## 2. Definition

Client Retention per Stylist (CRPS) captures the retention of customers, users, or assets over time for organizations tracking beauty & personal care services. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Returning Clients / Client Base of Stylist; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Personal Services, it is a recognized element of the standard performance toolkit.

## Formula

```
Returning Clients / Client Base of Stylist
```
