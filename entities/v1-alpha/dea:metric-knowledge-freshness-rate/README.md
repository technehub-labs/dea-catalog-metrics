## 2. Definition

A Knowledge Management indicator, Knowledge Freshness Rate (KFR) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Articles within Review Cycle / Total Articles, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
KFR = Articles within Review Cycle / Total Articles
```
