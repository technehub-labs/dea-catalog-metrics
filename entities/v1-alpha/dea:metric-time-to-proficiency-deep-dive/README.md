## 2. Definition

Time to Proficiency (Deep Dive) (TTP-D) measures capability maturity or development in the Contact Center Operations (Deep Dive) domain. It is defined as Days from Hire to Target Proficiency; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

Days from Hire to Target Proficiency
