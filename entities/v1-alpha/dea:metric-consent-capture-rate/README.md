## 2. Definition

Within Data Privacy & Protection, Consent Capture Rate (CCR-DP) is used to gauge conformance to standards, plans, or obligations. It is defined as Data Subjects with Valid Consent Record / Subjects in Scope; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures how completely and verifiably consent is captured for consent-required processing. Unverifiable consent is unprovable compliance. Pre-ticked boxes and bundled consent fail most modern regimes. Read with consent withdrawal processing rate and privacy program maturity score.

## Formula

```
Data Subjects with Valid Consent Record / Subjects in Scope
```
