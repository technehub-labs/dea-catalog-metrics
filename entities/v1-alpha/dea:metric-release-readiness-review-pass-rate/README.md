## 2. Definition

Release Readiness Review Pass Rate (RRRPR) measures the quality of outputs and outcomes in the Release Management & Environments domain. It is computed as Releases Passing Readiness Review First Time / Reviews, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Releases Passing Readiness Review First Time / Reviews
```
