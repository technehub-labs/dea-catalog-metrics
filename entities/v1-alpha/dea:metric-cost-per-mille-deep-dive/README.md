## 2. Definition

Cost per Mille (Deep Dive) (CPM-D) addresses how efficiently resources are converted into outputs and is a fixture of advertising & media buying reporting. It is defined as Media Cost / Impressions x 1,000; the result is stated in currency per unit. In Media & Entertainment, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Media Cost / Impressions x 1,000
```
