## 2. Definition

Average Length of Stay (Deep Dive) (ALOS-D) addresses the utilization or availability of capacity and is a fixture of hotel & resort operations (deep dive) reporting. It is defined as Occupied Room Nights / Arrivals; the result is stated in days. In Hospitality, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Occupied Room Nights / Arrivals
```
