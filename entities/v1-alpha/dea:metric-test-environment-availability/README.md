## 2. Definition

Test Environment Availability (TEA-QA) measures the utilization or availability of capacity in the Software Testing & Quality Engineering domain. It is computed as Environment Available Time / Required Time, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Environment Available Time / Required Time
```
