## 2. Definition

A Entertainment Venues & Attractions indicator, Merchandise Attach Rate (Venues) (MAR-V) quantifies growth over time. The formula is Guests Purchasing Merchandise / Guests - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Media & Entertainment sector.

## Formula

```
Guests Purchasing Merchandise / Guests
```
