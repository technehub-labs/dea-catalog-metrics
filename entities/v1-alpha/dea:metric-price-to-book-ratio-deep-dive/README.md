## 2. Definition

Price-to-Book Ratio (Deep Dive) (PTBDD) measures the economic value created or preserved in the Valuation & Corporate Finance Standard Measures domain. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Market Price / Book Value per Share - reported in ratio (x:1 or x). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures market value relative to accounting book equity. It signals how much value the market sees beyond recorded assets. Book value excludes most internally built intangibles, distorting knowledge businesses. Read with tangible book value coverage and return on equity (Deep Dive).

## Formula

```
Market Price / Book Value per Share
```
