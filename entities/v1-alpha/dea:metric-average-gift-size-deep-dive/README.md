## 2. Definition

Average Gift Size (Deep Dive) (AGS-D) captures the economic value created or preserved for organizations tracking nonprofit & donor operations (deep dive). The formula is Total Donations / Number of Gifts - reported in currency value. It is a standard measure in the Nonprofit sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Total Donations / Number of Gifts
```
