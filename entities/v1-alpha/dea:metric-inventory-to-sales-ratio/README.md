## 2. Definition

Within Retail Standard Measures, Inventory-to-Sales Ratio (ITSR) is used to gauge how efficiently resources are converted into outputs. It is computed as Average Inventory Value / Monthly Sales Value, expressed in ratio (x:1 or x). Its use is concentrated in Retail & E-commerce. It is reviewed at cadence by planning owners to correct course before issues become strategic. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Average Inventory Value / Monthly Sales Value
```
