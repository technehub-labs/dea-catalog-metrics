## 2. Definition

Within Operating Model Monitoring & Design Effectiveness, Capability Maturity Assessment Currency (CMAC-OM) is used to gauge capability maturity or development. It is defined as Capabilities Assessed within Two Years / Capabilities; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures whether capability maturity assessments are recent enough to reflect current state. Stale assessments drive decisions against the organization that no longer exists. Currency without method consistency makes trend comparisons meaningless. Read with capability maturity level trend and target operating model realization rate.

## Formula

```
Capabilities Assessed within Two Years / Capabilities
```
