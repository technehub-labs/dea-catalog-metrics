## 2. Definition

Root Cause Resolution Rate (Data) (RCRRD) measures the quality of outputs and outcomes in the Data Quality Management domain. It is defined as Recurring Quality Failures Eliminated at Root Cause / Identified Root Causes; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
RCRRD = Recurring Quality Failures Eliminated at Root Cause / Identified Root Causes
```
