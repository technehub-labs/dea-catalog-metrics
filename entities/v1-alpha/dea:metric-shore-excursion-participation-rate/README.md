## 2. Definition

Shore Excursion Participation Rate (SEPR) captures growth over time for organizations tracking cruise & passenger shipping. It is defined as Passengers Booking Excursions / Port Calls; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Hospitality, it is a recognized element of the standard performance toolkit.

## Formula

```
Passengers Booking Excursions / Port Calls
```
