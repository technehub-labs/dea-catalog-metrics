## 2. Definition

Privacy Complaint Resolution Time (PCRT-DP) captures how efficiently resources are converted into outputs for organizations tracking data privacy & protection. It is defined as Days to Resolve Privacy Complaints; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

Days to Resolve Privacy Complaints
