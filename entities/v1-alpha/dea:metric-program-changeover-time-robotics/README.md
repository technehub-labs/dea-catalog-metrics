## 2. Definition

Program Changeover Time (Robotics) (PCTR) captures how efficiently resources are converted into outputs for organizations tracking industrial automation & robotics. It provides the day-to-day signal that a process is running as designed. Its calculation is Minutes to Reprogram and Reset Robotic Cell, measured in minutes. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Manufacturing practice.

## Formula

```
Minutes to Reprogram and Reset Robotic Cell
```
