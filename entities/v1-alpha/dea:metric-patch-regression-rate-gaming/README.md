## 2. Definition

A Gaming Development & Live Operations indicator, Patch Regression Rate (Gaming) (PRR-G) quantifies the quality of outputs and outcomes. The formula is Regressions per Patch Release - reported in count (items per period). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. It is a standard measure in the Gaming sector.

## Formula

```
Regressions per Patch Release
```
