## 2. Definition

Within Investment Research & Trading Operations, TCA Coverage of Orders (TCACO) is used to gauge capability maturity or development. It is defined as Orders with Transaction Cost Analysis / Orders; the result is stated in percent (%). In Financial Services, it is a recognized element of the standard performance toolkit. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of executed order flow subject to transaction cost analysis. Unanalyzed flow is unmanaged cost. Coverage concentrated in equity flow leaves the less transparent markets (fixed income, FX) unexamined. Read with implementation shortfall and best execution compliance rate.

## Formula

```
Orders with Transaction Cost Analysis / Orders
```
