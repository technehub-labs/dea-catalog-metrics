## 2. Definition

Headcount Plan Attainment (HPA-FP) captures the utilization or availability of capacity for organizations tracking financial planning & analysis. Its calculation is Actual Hires vs Plan Hires / Plan, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Actual Hires vs Plan Hires / Plan
```
