## 2. Definition

Within PMO & Portfolio Governance, Governance Meeting Action Closure Rate (GMACR) is used to gauge conformance to standards, plans, or obligations. It is defined as Governance Actions Closed by Due Date / Actions; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Governance Actions Closed by Due Date / Actions
```
