## 2. Definition

Escalation Communication Compliance (ECC-NOC) captures conformance to standards, plans, or obligations for organizations tracking network operations center (deep dive). It is a working-level control: thresholds trigger immediate operational response. It is defined as Escalations with Required Notifications / Escalations; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Escalations with Required Notifications / Escalations
```
