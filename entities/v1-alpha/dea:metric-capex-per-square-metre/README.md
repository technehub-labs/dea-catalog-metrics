## 2. Definition

CapEx per Square Metre (CPSM) captures how efficiently resources are converted into outputs for organizations tracking real estate portfolio & property management. It is computed as Capital Expenditure / Lettable Area, expressed in currency per unit. Its use is concentrated in Real Estate. It is reviewed at cadence by planning owners to correct course before issues become strategic. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Capital Expenditure / Lettable Area
```
