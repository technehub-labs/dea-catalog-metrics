## 2. Definition

eDiscovery Processing Cost per Gigabyte (EDPC) addresses how efficiently resources are converted into outputs and is a fixture of legal operations reporting. It is computed as eDiscovery Costs / Processed Data Volume, expressed in currency per unit. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
eDiscovery Costs / Processed Data Volume
```
