## 2. Definition

A Education & Training Outcome Standard Measures indicator, Course Completion Rate (Education Standard) (CCRES) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Completions / Enrollments in For-Credit Courses, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Education practice.

## Formula

```
Completions / Enrollments in For-Credit Courses
```
