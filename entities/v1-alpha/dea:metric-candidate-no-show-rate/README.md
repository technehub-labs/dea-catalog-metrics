## 2. Definition

Candidate No-Show Rate (CNSR) captures exposure to adverse outcomes for organizations tracking staffing & recruiting. It is defined as Candidate Interview No-Shows / Scheduled Interviews; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Staffing & recruiting, it is a recognized element of the standard performance toolkit.

## Formula

```
Candidate Interview No-Shows / Scheduled Interviews
```
