## 2. Definition

A Supply Chain Standard Measures (Deep Dive) indicator, Excess & Obsolete Inventory Ratio (Supply Chain) (EOIR) quantifies exposure to adverse outcomes. It is defined as E&O Inventory Value / Total Inventory Value; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of inventory that is excess or obsolete. E&O is written-down future cost sitting in today's balance sheet. Write-down timing management can defer the recognition, not the reality. Read with inventory turns (supply chain) and days inventory outstanding.

## Formula

```
E&O Inventory Value / Total Inventory Value
```
