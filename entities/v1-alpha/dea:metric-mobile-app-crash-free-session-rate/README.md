## 2. Definition

Mobile App Crash-Free Session Rate (MACFS) addresses the quality of outputs and outcomes and is a fixture of mobile & client development reporting. The formula is Sessions without Crash / Total Sessions - reported in percent (%). It is a standard measure in the Software sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Sessions without Crash / Total Sessions
```
