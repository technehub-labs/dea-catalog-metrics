## 2. Definition

A Enterprise OKR & Performance Management indicator, Cross-Functional OKR Alignment Ratio (XFOAR) quantifies capability maturity or development. It is defined as Shared OKRs across Functions / Cross-Cutting Initiatives; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures how many objectives are genuinely shared across function boundaries. Shared objectives are how silo-busting actually gets encoded. Ratios counted from naming conventions rather than shared accountability are decoration. Read with OKR coverage - cascading ratio and decision rights clarity score.

## Formula

```
Shared OKRs across Functions / Cross-Cutting Initiatives
```
