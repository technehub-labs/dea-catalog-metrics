## 2. Definition

A Logistics & Transportation indicator, Delivery Success on First Attempt (DSFA) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Successful First Attempts / Total Delivery Attempts, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Logistics practice.

## Formula

```
Successful First Attempts / Total Delivery Attempts
```
