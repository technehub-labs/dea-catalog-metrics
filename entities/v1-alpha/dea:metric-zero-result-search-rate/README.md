## 2. Definition

Zero Result Search Rate (ZRS) measures the quality of outputs and outcomes in the Digital Product & Web Operations domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Searches Returning No Results / Total Searches, measured in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Searches Returning No Results / Total Searches
```
