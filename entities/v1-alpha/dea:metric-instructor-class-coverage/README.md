## 2. Definition

Instructor Class Coverage (ICC) captures conformance to standards, plans, or obligations for organizations tracking fitness & wellness. The formula is Classes Taught as Scheduled / Classes Scheduled - reported in percent (%). It is a standard measure in the Fitness & wellness sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Classes Taught as Scheduled / Classes Scheduled
```
