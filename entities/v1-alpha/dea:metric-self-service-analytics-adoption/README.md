## 2. Definition

Within Financial Planning & Analysis, Self-Service Analytics Adoption (SSAA) is used to gauge how efficiently resources are converted into outputs. It is computed as Business Users with Direct Planning Access / Users in Scope, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Business Users with Direct Planning Access / Users in Scope
```
