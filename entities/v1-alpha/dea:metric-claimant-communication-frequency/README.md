## 2. Definition

Within Insurance Claims Deep Dive, Claimant Communication Frequency (CCF) is used to gauge the engagement or satisfaction of the people involved. Its calculation is Proactive Claimant Updates per Claim Cycle, measured in times per period. It originates from and is most used in Insurance practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Proactive Claimant Updates per Claim Cycle
```
