## 2. Definition

Provision Loading Accuracy (Cruise) (PLAC) captures the quality of outputs and outcomes for organizations tracking cruise & passenger shipping. It is defined as Provision Items Delivered per Manifest / Items; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. In Hospitality, it is a recognized element of the standard performance toolkit.

## Formula

```
Provision Items Delivered per Manifest / Items
```
