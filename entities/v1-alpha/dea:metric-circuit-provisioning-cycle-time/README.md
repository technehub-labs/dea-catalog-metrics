## 2. Definition

Within Network Performance & Capacity, Circuit Provisioning Cycle Time (CPCT) is used to gauge how efficiently resources are converted into outputs. The formula is Days from Order to Circuit Acceptance - reported in days. It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.
