## 2. Definition

Within Accounts Payable & Receivable Operations (Deep Dive), Early Payment Discount Capture Rate (EPDCR) is used to gauge the economic value created or preserved. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Discounts Captured / Discounts Offered, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Discounts Captured / Discounts Offered
```
