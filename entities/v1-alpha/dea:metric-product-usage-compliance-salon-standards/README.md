## 2. Definition

A Beauty & Personal Care Services indicator, Product Usage Compliance (Salon Standards) (PUCS) quantifies conformance to standards, plans, or obligations. Its calculation is Services Using Approved Products / Services, measured in percent (%). It originates from and is most used in Personal Services practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Services Using Approved Products / Services
```
