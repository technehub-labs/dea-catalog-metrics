## 2. Definition

Chemical Spill Containment Rate (CSCR2) measures exposure to adverse outcomes in the Chemicals & Specialty Materials domain. It is defined as Spills Contained to Bunded Area / Spills; the result is stated in percent (%). In Chemicals, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Spills Contained to Bunded Area / Spills
```
