## 2. Definition

Vendor Remediation Closure Rate (VRCR-TP) measures conformance to standards, plans, or obligations in the Third-Party Risk Management domain. It is defined as Findings Closed by Vendor by Due Date / Findings; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Findings Closed by Vendor by Due Date / Findings
```
