## 2. Definition

A Cloud Security Posture Management indicator, Critical Cloud Finding Resolution Time (CCFRT) quantifies exposure to adverse outcomes. It is computed as Hours to Remediate Critical CSPM Findings, expressed in hours. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Hours to Remediate Critical CSPM Findings
```
