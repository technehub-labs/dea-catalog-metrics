## 2. Definition

Background Check Clear Cycle Time (BCCCT) measures how efficiently resources are converted into outputs in the Talent Acquisition Deep Dive domain. It is defined as Days from Check Initiated to Cleared; the result is stated in days. It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
BCCCT = Days from Check Initiated to Cleared
```
