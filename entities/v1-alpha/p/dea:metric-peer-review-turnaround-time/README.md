## 2. Definition

Peer Review Turnaround Time (PRTT-SD) captures how efficiently resources are converted into outputs for organizations tracking software development - coding & engineering practices. Its calculation is Hours from Review Request to Approval, measured in hours. It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
PRTT-SD = Hours from Review Request to Approval
```
