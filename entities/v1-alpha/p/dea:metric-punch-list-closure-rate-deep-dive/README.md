## 2. Definition

Punch List Closure Rate (Deep Dive) (PLCR-D) captures how efficiently resources are converted into outputs for organizations tracking construction contracting (deep dive). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Punch Items Closed by Date / Punch Items, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Construction.

## Formula

```
PLCR-D = Punch Items Closed by Date / Punch Items
```
