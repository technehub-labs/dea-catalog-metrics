## 2. Definition

Progress Billing Dispute Ratio (PBDR) measures the quality of outputs and outcomes in the Construction Contracting (Deep Dive) domain. The formula is Billing Disputes / Progress Claims - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Construction sector.

## Formula

```
PBDR = Billing Disputes / Progress Claims
```
