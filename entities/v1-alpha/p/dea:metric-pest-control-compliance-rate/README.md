## 2. Definition

A Food & Beverage Manufacturing indicator, Pest Control Compliance Rate (PCCR) quantifies conformance to standards, plans, or obligations. It is defined as Pest Control Visits and Actions Complete / Required; the result is stated in percent (%). In Food & Beverage, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PCCR = Pest Control Visits and Actions Complete / Required
```
