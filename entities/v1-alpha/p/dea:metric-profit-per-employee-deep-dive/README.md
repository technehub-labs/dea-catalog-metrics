## 2. Definition

A Standard Workforce & Pay Metrics indicator, Profit per Employee (Deep Dive) (PPE-WF) quantifies the economic value created or preserved. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Operating Profit / Average Headcount, expressed in currency per unit. Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures net profit generated per employee. It is the sharpest single measure of workforce productivity after all costs. Profit spikes from one-off items distort the trend. Read with revenue per employee (Standard) and human capital ROI.

## Formula

```
PPE-WF = Operating Profit / Average Headcount
```
