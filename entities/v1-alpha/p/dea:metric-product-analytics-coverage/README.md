## 2. Definition

Product Analytics Coverage (PAC-S) addresses capability maturity or development and is a fixture of software product operations (deep dive) reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Features Instrumented with Events / Features - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Technology sector.

## Formula

```
PAC-S = Features Instrumented with Events / Features
```
