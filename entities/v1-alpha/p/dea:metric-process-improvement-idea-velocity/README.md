## 2. Definition

Process Improvement Idea Velocity (PIIV) captures capability maturity or development for organizations tracking operating model & process health deep dive. The formula is Improvement Ideas Implemented per 100 FTE per Quarter - reported in events per thousand or million (scaled). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PIIV = Improvement Ideas Implemented per 100 FTE per Quarter
```
