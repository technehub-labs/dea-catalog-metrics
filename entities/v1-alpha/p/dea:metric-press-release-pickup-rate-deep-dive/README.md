## 2. Definition

Press Release Pickup Rate (Deep Dive) (PRPR-D) measures how effectively a process or entity achieves its intended outcome in the Corporate Communications & PR (Deep Dive) domain. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Outlets Publishing Release / Outlets Targeted - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
PRPR-D = Outlets Publishing Release / Outlets Targeted
```
