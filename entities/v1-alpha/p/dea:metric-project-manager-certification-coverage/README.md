## 2. Definition

A PMO & Portfolio Governance indicator, Project Manager Certification Coverage (PMCC) quantifies capability maturity or development. It is defined as Certified PMs / PM Population; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PMCC = Certified PMs / PM Population
```
