## 2. Definition

Push Notification Opt-In Rate (PNOR) measures the engagement or satisfaction of the people involved in the Mobile & Client Development domain. It is computed as Users Enabling Push / App Users, expressed in percent (%). Its use is concentrated in Software. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PNOR = Users Enabling Push / App Users
```
