## 2. Definition

Within Data Privacy & Protection, Personal Data Minimization Compliance (PDMS) is used to gauge conformance to standards, plans, or obligations. The formula is Data Collections Justified as Necessary / Collections Sampled - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
PDMS = Data Collections Justified as Necessary / Collections Sampled
```
