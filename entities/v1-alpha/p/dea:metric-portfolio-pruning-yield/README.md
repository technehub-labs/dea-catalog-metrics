## 2. Definition

A Intellectual Property & Licensing indicator, Portfolio Pruning Yield (PPY) quantifies how efficiently resources are converted into outputs. It is defined as Low-Value Assets Divested or Abandoned / Flagged Assets; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
PPY = Low-Value Assets Divested or Abandoned / Flagged Assets
```
