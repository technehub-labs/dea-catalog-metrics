## 2. Definition

A Operating Model & Process Health Deep Dive indicator, Process Data Capture Rate (PDCA-OM) quantifies capability maturity or development. The formula is Process Steps with Digital Data Capture / Steps - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PDCA-OM = Process Steps with Digital Data Capture / Steps
```
