## 2. Definition

A Packaging & Plastics indicator, Packaging Drop Test Pass Rate (PDTP) quantifies the quality of outputs and outcomes. Its calculation is Packages Passing Drop Test / Packages Tested, measured in percent (%). It originates from and is most used in Manufacturing practice. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
PDTP = Packages Passing Drop Test / Packages Tested
```
