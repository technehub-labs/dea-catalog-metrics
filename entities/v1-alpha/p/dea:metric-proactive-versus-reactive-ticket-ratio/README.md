## 2. Definition

Proactive versus Reactive Ticket Ratio (PVRTR) captures capability maturity or development for organizations tracking network operations center (deep dive). It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Proactive Tickets / Total Tickets, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the balance of tickets generated by monitoring alerts and maintenance versus user-reported failures. A proactive NOC fixes issues before customers notice; a reactive one is an expensive messenger. The ratio is gameable by generating trivial proactive tickets. Read with auto-remediation execution rate and incident detection via monitoring ratio.

## Formula

```
PVRTR = Proactive Tickets / Total Tickets
```
