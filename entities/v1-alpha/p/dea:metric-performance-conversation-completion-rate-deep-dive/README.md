## 2. Definition

Within Enterprise OKR & Performance Management, Performance Conversation Completion Rate (Deep Dive) (PCCR-D) is used to gauge conformance to standards, plans, or obligations. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Required Conversations Held per Cycle / Required; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
PCCR-D = Required Conversations Held per Cycle / Required
```
