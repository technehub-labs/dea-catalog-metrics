## 2. Definition

A Channel & Distribution Management indicator, Partner Tier Reclassification Rate (PTRR) quantifies the quality of outputs and outcomes. Its calculation is Partners Moving Tier per Review Cycle / Partners, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula

```
PTRR = Partners Moving Tier per Review Cycle / Partners
```
