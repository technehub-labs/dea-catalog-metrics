## 2. Definition

Within R&D and Innovation, Prototype Iterations per Project (PIP) is used to gauge how efficiently resources are converted into outputs. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Prototype Build Cycles / Project, expressed in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
PIP = Prototype Build Cycles / Project
```
