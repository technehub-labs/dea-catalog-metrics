## 2. Definition

Print Registration Accuracy (PRA-P) addresses the quality of outputs and outcomes and is a fixture of packaging & plastics reporting. Its calculation is Prints within Registration Tolerance / Prints, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Manufacturing practice.

## Formula

```
PRA-P = Prints within Registration Tolerance / Prints
```
