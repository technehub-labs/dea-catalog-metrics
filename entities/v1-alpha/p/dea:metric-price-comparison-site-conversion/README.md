## 2. Definition

A Insurance Distribution - Direct & Digital indicator, Price Comparison Site Conversion (PCSC) quantifies growth over time. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Purchases from Comparison Traffic / Comparison Sessions - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Insurance sector.

## Formula

```
PCSC = Purchases from Comparison Traffic / Comparison Sessions
```
