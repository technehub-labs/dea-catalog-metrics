## 2. Definition

A Third-Party Risk Management indicator, Residual Risk Acceptance Cycle Time (RRACT) quantifies how efficiently resources are converted into outputs. It is computed as Days from Exception Raised to Formal Acceptance, expressed in days. It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Exception Raised to Formal Acceptance
```
