## 2. Definition

Security Clearance Processing Time (Deep Dive) (SCPT) addresses how efficiently resources are converted into outputs and is a fixture of aerospace & defense program management reporting. The formula is Days to Process Clearance Application - reported in days. It is a standard measure in the Aerospace & Defense sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula
