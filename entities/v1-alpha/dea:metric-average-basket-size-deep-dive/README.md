## 2. Definition

A Retail Standard Measures indicator, Average Basket Size (Deep Dive) (ABSDD) quantifies the economic value created or preserved. Its calculation is Total Transaction Value / Transactions, measured in currency per unit. It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Retail & E-commerce practice.

## Formula

```
Total Transaction Value / Transactions
```
