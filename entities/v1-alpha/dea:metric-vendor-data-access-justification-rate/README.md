## 2. Definition

A Third-Party Risk Management indicator, Vendor Data Access Justification Rate (VDAJR) quantifies exposure to adverse outcomes. It is defined as Vendor Access Grants with Valid Need / Grants Sampled; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Vendor Access Grants with Valid Need / Grants Sampled
```
