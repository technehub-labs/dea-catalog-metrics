## 2. Definition

Refinery Purity Yield (RPY) measures the quality of outputs and outcomes in the Metals & Mining Operations (Deep Dive) domain. It is computed as Refined Metal at Purity Spec / Input Metal, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Metals & Mining.

## Formula

```
Refined Metal at Purity Spec / Input Metal
```
