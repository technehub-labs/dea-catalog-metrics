## 2. Definition

Within Investment Management - Portfolio Operations, Money-Weighted Rate of Return (Deep Dive) (MWRR-D) is used to gauge how effectively a process or entity achieves its intended outcome. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Internal Rate of Return on Investor Cash Flows, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Financial Services.

## 3. Context

Measures the internal rate of return incorporating the size and timing of client cash flows. MWR answers the only question clients ultimately ask: what did my money earn? Because timing luck dominates, it is a poor tool for judging manager skill. Read with time-weighted rate of return and client reporting accuracy rate.
