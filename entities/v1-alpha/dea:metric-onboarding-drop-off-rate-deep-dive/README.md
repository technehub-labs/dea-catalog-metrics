## 2. Definition

Onboarding Drop-off Rate (Deep Dive) (ODOR-D) measures exposure to adverse outcomes in the Balanced Scorecard - Customer Perspective domain. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Customers Abandoning Onboarding / Starts - reported in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
ODOR-D = Customers Abandoning Onboarding / Starts
```
