## 2. Definition

Data Quality Certification Rate (DQCRT) captures conformance to standards, plans, or obligations for organizations tracking data quality management. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Datasets Certified for Business Use / In-Scope Datasets, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Datasets Certified for Business Use / In-Scope Datasets
```
