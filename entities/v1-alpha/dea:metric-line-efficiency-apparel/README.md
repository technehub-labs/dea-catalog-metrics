## 2. Definition

Within Textile & Apparel, Line Efficiency (Apparel) (LEA) is used to gauge how efficiently resources are converted into outputs. Its calculation is Actual Output / Standard Output at Given Hours, measured in percent (%). It originates from and is most used in Textile & apparel practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Actual Output / Standard Output at Given Hours
```
