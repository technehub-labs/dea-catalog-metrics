## 2. Definition

Customer Segment Coverage per Branch (CSCB) addresses capability maturity or development and is a fixture of retail banking branch network (deep dive) reporting. It is computed as Segments Served with Dedicated Offers / Segments, expressed in percent (%). Its use is concentrated in Banking. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Segments Served with Dedicated Offers / Segments
```
