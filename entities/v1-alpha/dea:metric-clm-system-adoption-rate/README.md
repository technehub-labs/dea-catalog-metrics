## 2. Definition

CLM System Adoption Rate (CLMSAR) addresses how efficiently resources are converted into outputs and is a fixture of contract lifecycle management reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Users Creating Contracts in CLM Platform / Contract Creators - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Users Creating Contracts in CLM Platform / Contract Creators
```
