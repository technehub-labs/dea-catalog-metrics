## 2. Definition

Within Legal Operations, Outside Counsel Rate Variance (OCRV) is used to gauge how efficiently resources are converted into outputs. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Average Blended Rate vs Standard Rate Benchmark - reported in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

Average Blended Rate vs Standard Rate Benchmark
