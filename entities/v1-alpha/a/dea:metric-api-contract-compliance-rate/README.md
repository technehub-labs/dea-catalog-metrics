## 2. Definition

Within Software Architecture & Technical Design, API Contract Compliance Rate (APICCR) is used to gauge conformance to standards, plans, or obligations. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Services Compliant with Published Contract / Services, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
APICCR = Services Compliant with Published Contract / Services
```
