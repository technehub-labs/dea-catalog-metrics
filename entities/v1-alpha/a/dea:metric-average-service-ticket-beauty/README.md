## 2. Definition

Average Service Ticket (Beauty) (AST-B) measures the economic value created or preserved in the Beauty & Personal Care Services domain. The formula is Service Revenue / Client Visits - reported in currency per unit. It is a standard measure in the Personal Services sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.
