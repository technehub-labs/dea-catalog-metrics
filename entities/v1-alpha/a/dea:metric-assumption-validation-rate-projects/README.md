## 2. Definition

Assumption Validation Rate (Projects) (AVR-P) measures the quality of outputs and outcomes in the Project Risk & Issue Management domain. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Assumptions Validated by Checkpoint / Assumptions, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
AVR-P = Assumptions Validated by Checkpoint / Assumptions
```
