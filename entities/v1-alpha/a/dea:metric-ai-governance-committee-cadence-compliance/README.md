## 2. Definition

Within AI Governance & Model Risk Management, AI Governance Committee Cadence Compliance (AIGCC) is used to gauge conformance to standards, plans, or obligations. The formula is Governance Meetings Held per Charter / Scheduled - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
AIGCC = Governance Meetings Held per Charter / Scheduled
```
