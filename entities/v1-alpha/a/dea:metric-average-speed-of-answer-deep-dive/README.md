## 2. Definition

Average Speed of Answer (Deep Dive) (ASA-D) measures how efficiently resources are converted into outputs in the Contact Center Operations (Deep Dive) domain. It is defined as Seconds to Answer Offered Calls; the result is stated in seconds. It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.
