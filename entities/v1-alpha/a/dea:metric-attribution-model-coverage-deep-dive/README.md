## 2. Definition

Within Marketing & Advertising Standard Measures (Deep Dive), Attribution Model Coverage (Deep Dive) (AMCDD) is used to gauge the quality of outputs and outcomes. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Conversions Scored by Multi-Touch Model / Conversions, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how completely conversions are attributed across channels and journeys. Coverage determines whether channel ROI is measurable at all. Last-click coverage is high and honest-looking while systemically wrong. Read with marketing mix model validation accuracy and multi-touch attribution coverage.

## Formula

```
AMCDD = Conversions Scored by Multi-Touch Model / Conversions
```
