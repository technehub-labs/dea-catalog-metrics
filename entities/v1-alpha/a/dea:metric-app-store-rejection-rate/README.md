## 2. Definition

App Store Rejection Rate (ASRR) addresses the quality of outputs and outcomes and is a fixture of mobile & client development reporting. Its calculation is Submissions Rejected / Submissions, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Software practice.

## Formula

```
ASRR = Submissions Rejected / Submissions
```
