## 2. Definition

Access to Personal Data Justification Rate (APDJR) measures exposure to adverse outcomes in the Data Privacy & Protection domain. Its calculation is Access Grants with Valid Justification / Grants Sampled, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
APDJR = Access Grants with Valid Justification / Grants Sampled
```
