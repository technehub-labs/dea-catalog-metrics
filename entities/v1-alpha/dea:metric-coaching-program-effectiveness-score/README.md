## 2. Definition

Coaching Program Effectiveness Score (CPES) measures the economic value created or preserved in the Learning & Development Effectiveness (Deep Dive) domain. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Measured Goal Attainment of Coached Cohort vs Baseline; the result is stated in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures whether coaching investment changes the coachee's behavior and outcomes. Coaching is expensive and notoriously unmeasured. Effectiveness scored by the coach grades its own homework. Read with manager effectiveness index (Deep Dive) and 360 feedback participation rate.

## Formula

```
Measured Goal Attainment of Coached Cohort vs Baseline
```
