## 2. Definition

App Update Adoption Lag (AUAL) captures how efficiently resources are converted into outputs for organizations tracking mobile & client development. It is computed as Days for 80% of Users to Adopt Latest Release, expressed in days. Its use is concentrated in Software. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Days for 80% of Users to Adopt Latest Release
```
