## 2. Definition

LTV-to-CAC Ratio (Deep Dive) (LTVCRD) addresses the economic value created or preserved and is a fixture of unit economics & growth (deep dive) reporting. It is computed as Lifetime Value / Acquisition Cost, expressed in ratio (x:1 or x). Its use is concentrated in Software. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures customer lifetime value relative to acquisition cost. The ratio is the go/no-go of growth spending: below 3 growth is bought, not earned. Ratio targets invite LTV model inflation. Read with CAC payback period (Unit Economics) and marginal CAC efficiency.

## Formula

```
Lifetime Value / Acquisition Cost
```
