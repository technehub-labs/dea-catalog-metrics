## 2. Definition

Onboarding Completion Rate (Fitness) (OCR-F) captures the retention of customers, users, or assets over time for organizations tracking fitness & wellness (deep dive). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as New Members Completing Induction / Joiners; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Health & Fitness, it is a recognized element of the standard performance toolkit.

## Formula

```
OCR-F = New Members Completing Induction / Joiners
```
