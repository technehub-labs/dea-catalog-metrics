## 2. Definition

A Mobile & Client Development indicator, Offline Mode Success Rate (OMSR) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Offline Transactions Completed Correctly / Offline Attempts, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Software practice.

## Formula

```
OMSR = Offline Transactions Completed Correctly / Offline Attempts
```
