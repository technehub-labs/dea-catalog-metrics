## 2. Definition

Within Records & Information Management, Off-Topic Records Ratio (OTRR) is used to gauge the quality of outputs and outcomes. It is computed as Records Misfiled / Records Sampled, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
OTRR = Records Misfiled / Records Sampled
```
