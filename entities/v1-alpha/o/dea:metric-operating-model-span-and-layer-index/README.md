## 2. Definition

Within Operating Model Monitoring & Design Effectiveness, Operating Model Span and Layer Index (OSLI) is used to gauge how efficiently resources are converted into outputs. It is computed as Reporting Layers and Span Balance Score, expressed in index (0-100 or normalized). It is applied across virtually every sector. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Values outside the intended band, on either side, warrant investigation.

## 3. Context

Measures organizational spans of control and management layers against healthy design norms. Excess layers slow decisions and dilute accountability. Index norms vary by work type; one-size targets misjudge specialist functions. Read with decision cycle time - strategic decisions and governance layer efficiency ratio.

## Formula

```
OSLI = Reporting Layers and Span Balance Score
```
