## 2. Definition

Resource Allocation Accuracy (RAA-PM) addresses how efficiently resources are converted into outputs and is a fixture of project management (deep dive) reporting. The formula is Actual Resource Use vs Plan / Plan - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Actual Resource Use vs Plan / Plan
```
