## 2. Definition

Within Regulatory Affairs & Compliance Operations, Compliance Escalation Cycle Time (CECT) is used to gauge how efficiently resources are converted into outputs. Its calculation is Days from Detection to Resolution of Compliance Escalation, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

Days from Detection to Resolution of Compliance Escalation
