## 2. Definition

Within Marketing Attribution & Analytics, View-Through Attribution Rate (VTAR) is used to gauge the quality of outputs and outcomes. It is defined as Conversions from Viewed Ads without Click / Attributed Conversions; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Conversions from Viewed Ads without Click / Attributed Conversions
```
