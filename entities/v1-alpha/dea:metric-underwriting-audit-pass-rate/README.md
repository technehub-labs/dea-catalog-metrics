## 2. Definition

Underwriting Audit Pass Rate (UAPR) captures conformance to standards, plans, or obligations for organizations tracking insurance underwriting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Files Passing Underwriting Audit / Files Audited, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Insurance.

## Formula

```
Files Passing Underwriting Audit / Files Audited
```
