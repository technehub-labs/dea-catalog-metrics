## 2. Definition

Within Generative AI & LLM Operations, Content Safety Filter Precision (CSFP) is used to gauge the quality of outputs and outcomes. Its calculation is Correctly Flagged Content / Flagged Content, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Correctly Flagged Content / Flagged Content
```
