## 2. Definition

Balanced Perspective Weight Compliance (BPWC) measures conformance to standards, plans, or obligations in the Balanced Scorecard Implementation & Review domain. The formula is Units Applying Approved Perspective Weighting / Units - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
BPWC = Units Applying Approved Perspective Weighting / Units
```
