## 2. Definition

Intranet Engagement Rate (IER-C) measures the engagement or satisfaction of the people involved in the Corporate Communications & PR domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Employees Interacting with Content / Employees Reached; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Employees Interacting with Content / Employees Reached
```
