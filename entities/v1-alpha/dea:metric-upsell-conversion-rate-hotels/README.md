## 2. Definition

Upsell Conversion Rate (Hotels) (UCR-H) addresses growth over time and is a fixture of hotel & resort operations (deep dive) reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Upsells Accepted / Upsell Offers - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Hospitality sector.

## Formula

```
Upsells Accepted / Upsell Offers
```
