## 2. Definition

Within Warehousing, Order Picking Accuracy (OPA) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Correctly Picked Lines / Lines Picked, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Correctly Picked Lines / Lines Picked
```
