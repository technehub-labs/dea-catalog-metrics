## 2. Definition

Cross-Browser or Cross-Device Test Coverage (CBTC-QA) measures the quality of outputs and outcomes in the Software Testing & Quality Engineering domain. Its calculation is Supported Configurations Tested / Configurations, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Supported Configurations Tested / Configurations
```
