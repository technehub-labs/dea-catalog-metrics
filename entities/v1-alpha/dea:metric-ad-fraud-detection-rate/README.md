## 2. Definition

Within Advertising & Media Buying, Ad Fraud Detection Rate (AFDR) is used to gauge exposure to adverse outcomes. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Invalid Traffic Identified / Traffic Analyzed; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
Invalid Traffic Identified / Traffic Analyzed
```
