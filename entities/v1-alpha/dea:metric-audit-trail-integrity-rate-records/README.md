## 2. Definition

Audit Trail Integrity Rate (Records) (ATIRR) addresses exposure to adverse outcomes and is a fixture of records & information management reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Access Logs Complete and Tamper-Evident / Logs Sampled, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Access Logs Complete and Tamper-Evident / Logs Sampled
```
