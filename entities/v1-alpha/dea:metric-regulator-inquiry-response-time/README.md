## 2. Definition

Regulator Inquiry Response Time (RIRT) captures how efficiently resources are converted into outputs for organizations tracking compliance monitoring & testing. It is defined as Days to Respond to Regulatory Inquiries; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
