## 2. Definition

A Process Excellence (Lean Six Sigma) indicator, Improvement Project Cycle Time (IPCT) quantifies how efficiently resources are converted into outputs. It is defined as Days from Project Start to Control Phase Handover; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## 3. Context

Measures average duration of improvement projects from charter to closure. It matters because slow projects burn scarce belt time and volunteer energy. Projects can be closed early with unverified benefits to shorten the average. Read with Kaizen Implementation Rate and Benefit Realization tracking to confirm speed coexists with verified impact.
