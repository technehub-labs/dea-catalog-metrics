## 2. Definition

Lease Administration Audit Pass Rate (LAAP) captures the quality of outputs and outcomes for organizations tracking real estate portfolio & property management. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Lease Abstracts Verified Correct / Audited, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Real Estate.

## Formula

```
LAAP = Lease Abstracts Verified Correct / Audited
```
