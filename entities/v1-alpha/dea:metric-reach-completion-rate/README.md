## 2. Definition

A Marketing & Advertising Standard Measures (Deep Dive) indicator, Reach Completion Rate (RCR-MK) quantifies growth over time. The formula is Target Audience Reached / Planned Audience - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Target Audience Reached / Planned Audience
```
