## 2. Definition

Within Education, Course Completion Rate (CCR-E) is used to gauge the quality of outputs and outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Completed Course Enrollments / Enrollments - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Education sector.

## 3. Context

Measures the share of enrolled learners finishing a course. It matters because completion is the gateway outcome for credential value and revenue recognition in education. Completion can be inflated by lowering rigor or grading generously to keep learners on the roster. Read with Learner Outcomes and Assessment Integrity findings to confirm completions reflect real learning.

## Formula

```
CCR-E = Completed Course Enrollments / Enrollments
```
