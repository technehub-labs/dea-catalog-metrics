## 2. Definition

Compa-Ratio (COMPA) captures conformance to standards, plans, or obligations for organizations tracking standard workforce & pay metrics. It is defined as Actual Salary / Salary Range Midpoint; the result is stated in ratio (x:1 or x). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Actual Salary / Salary Range Midpoint
```
