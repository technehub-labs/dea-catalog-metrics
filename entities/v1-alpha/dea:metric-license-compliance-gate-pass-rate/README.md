## 2. Definition

License Compliance Gate Pass Rate (LCGPR) captures conformance to standards, plans, or obligations for organizations tracking devsecops & application security engineering. It is defined as Releases Passing Open Source License Policy / Releases; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Releases Passing Open Source License Policy / Releases
```
