## 2. Definition

A Emerging Risk & Horizon Scanning indicator, External Intelligence Source Coverage (EISC) quantifies capability maturity or development. Its calculation is Monitored Sources per Risk Taxonomy / Planned Sources, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Monitored Sources per Risk Taxonomy / Planned Sources
```
