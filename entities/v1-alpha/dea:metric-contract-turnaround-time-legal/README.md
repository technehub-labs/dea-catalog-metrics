## 2. Definition

Contract Turnaround Time (Legal) (CTTL) measures how efficiently resources are converted into outputs in the Legal Operations domain. Its calculation is Days from Request to Executed Contract, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

Days from Request to Executed Contract
