## 2. Definition

Reference Master Governance Coverage (RMGC) captures conformance to standards, plans, or obligations for organizations tracking master data management. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Code Sets Governed Centrally / Code Sets in Use, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Code Sets Governed Centrally / Code Sets in Use
```
