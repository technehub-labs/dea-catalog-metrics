## 2. Definition

Within Semiconductor & Electronics, Photolithography Overlay Accuracy (PLOA) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Layer Alignment Errors within Tolerance / Layers Measured, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Electronics & semiconductors.

## Formula

```
Layer Alignment Errors within Tolerance / Layers Measured
```
