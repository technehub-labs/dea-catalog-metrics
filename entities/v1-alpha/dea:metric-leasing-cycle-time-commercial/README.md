## 2. Definition

Leasing Cycle Time (Commercial) (LCT-C) captures how efficiently resources are converted into outputs for organizations tracking real estate portfolio & property management. The formula is Days from Inquiry to Lease Execution - reported in days. It is a standard measure in the Real Estate sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
LCT-C = Days from Inquiry to Lease Execution
```
