## 2. Definition

Message Pull-Through Rate (Deep Dive) (MPTR) addresses how effectively a process or entity achieves its intended outcome and is a fixture of corporate communications & pr (deep dive) reporting. The formula is Articles Containing Key Messages / Articles - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Articles Containing Key Messages / Articles
```
