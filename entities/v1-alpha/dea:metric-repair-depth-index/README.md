## 2. Definition

Repair Depth Index (RDI-RM) measures the quality of outputs and outcomes in the Reliability & Maintainability Engineering (Deep Dive) domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Mean Repairs to Restore Function per Failure, expressed in times per period. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Mean Repairs to Restore Function per Failure
```
