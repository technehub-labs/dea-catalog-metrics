## 2. Definition

Grant Administration Overhead Ratio (GAOR) captures how efficiently resources are converted into outputs for organizations tracking public sector & citizen service standard measures (deep dive). Its calculation is Administration Cost / Grant Funds Disbursed, measured in percent (%). It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Lower values are better; each reduction is an improvement. It originates from and is most used in Public sector practice.

## 3. Context

Measures administrative cost relative to grant value distributed. Overhead is the efficiency question in public and philanthropic money. Ratios cut below sustainable levels convert into grant error and fraud exposure. Read with improper payment rate and audit finding closure rate (grants).

## Formula

```
Administration Cost / Grant Funds Disbursed
```
