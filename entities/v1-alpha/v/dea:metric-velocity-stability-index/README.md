## 2. Definition

Within Agile Delivery & Team Effectiveness, Velocity Stability Index (VSI-AG) is used to gauge the quality of outputs and outcomes. It is defined as Variance of Sprint Velocity around Mean; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
VSI-AG = Variance of Sprint Velocity around Mean
```
