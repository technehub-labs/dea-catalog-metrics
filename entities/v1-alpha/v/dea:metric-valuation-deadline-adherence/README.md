## 2. Definition

Valuation Deadline Adherence (VDA) addresses conformance to standards, plans, or obligations and is a fixture of actuarial & reserving reporting. It is defined as Valuations Completed by Deadline / Valuations Due; the result is stated in percent (%). In Insurance, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
VDA = Valuations Completed by Deadline / Valuations Due
```
