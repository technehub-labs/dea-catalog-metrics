## 2. Definition

A Data Science & Analytics Operations indicator, Analyst Utilization Rate (AUR-DS) quantifies the utilization or availability of capacity. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Billable or Project Hours / Total Hours; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Billable or Project Hours / Total Hours
```
