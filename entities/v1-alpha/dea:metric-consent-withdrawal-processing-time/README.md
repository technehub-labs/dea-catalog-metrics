## 2. Definition

A Data Privacy & Protection indicator, Consent Withdrawal Processing Time (CWPT) quantifies conformance to standards, plans, or obligations. Its calculation is Days to Effect Withdrawal across Systems, measured in days. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days to Effect Withdrawal across Systems
```
