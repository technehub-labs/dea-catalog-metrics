## 2. Definition

Rent Collection Timeliness (Portfolio) (RCT-P) measures conformance to standards, plans, or obligations in the Real Estate Portfolio & Property Management domain. Its calculation is Rent Received by Due Date / Billed Rent, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Real Estate practice.

## Formula

```
Rent Received by Due Date / Billed Rent
```
