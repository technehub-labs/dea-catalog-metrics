## 2. Definition

Risk Response Effectiveness (RRE) addresses exposure to adverse outcomes and is a fixture of project risk & issue management reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Risks Mitigated before Impact / Responded Risks; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Risks Mitigated before Impact / Responded Risks
```
