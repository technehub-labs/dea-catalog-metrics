## 2. Definition

Within Financial Statement Analysis Ratios (Deep Dive), Receivables Turnover Ratio (Deep Dive) (RTRDD) is used to gauge how efficiently resources are converted into outputs. It is computed as Net Credit Sales / Average Receivables, expressed in ratio (x:1 or x). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Net Credit Sales / Average Receivables
```
