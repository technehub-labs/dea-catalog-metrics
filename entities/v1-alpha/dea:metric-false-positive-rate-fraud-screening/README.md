## 2. Definition

Within Enterprise Fraud & Financial Crime Management, False Positive Rate (Fraud Screening) (FPRFS) is used to gauge how efficiently resources are converted into outputs. Its calculation is Alerts Dismissed as Legitimate / Alerts Generated, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Alerts Dismissed as Legitimate / Alerts Generated
```
