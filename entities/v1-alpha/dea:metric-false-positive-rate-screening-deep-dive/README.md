## 2. Definition

A Insurance Fraud & Financial Crime indicator, False Positive Rate - Screening (Deep Dive) (FPR-S) quantifies how efficiently resources are converted into outputs. It is computed as False Alerts / Total Alerts, expressed in percent (%). Its use is concentrated in Financial Services. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
False Alerts / Total Alerts
```
