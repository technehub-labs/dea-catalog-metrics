## 2. Definition

Within Continuous Delivery & Deployment, Version Compatibility Pass Rate (VCPR-CD) is used to gauge the quality of outputs and outcomes. The formula is Compatibility Tests Passed before Promotion / Tests - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Compatibility Tests Passed before Promotion / Tests
```
