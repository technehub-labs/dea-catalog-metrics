## 2. Definition

First-Time Fix Rate (Field) (FTFR-F) captures the quality of outputs and outcomes for organizations tracking field service & asset performance. It is a working-level control: thresholds trigger immediate operational response. It is defined as Jobs Resolved on First Visit / Jobs; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Jobs Resolved on First Visit / Jobs
```
