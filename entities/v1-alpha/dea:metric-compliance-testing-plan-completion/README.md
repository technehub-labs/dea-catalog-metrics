## 2. Definition

Within Compliance Monitoring & Testing, Compliance Testing Plan Completion (CTPC) is used to gauge conformance to standards, plans, or obligations. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Tests Executed per Annual Plan / Tests Planned, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Tests Executed per Annual Plan / Tests Planned
```
