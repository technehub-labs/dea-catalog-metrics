## 2. Definition

Within Data Privacy & Protection, Privacy-by-Design Review Coverage (PBDRC) is used to gauge exposure to adverse outcomes. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Features Passing Privacy Design Review / In-Scope Features - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Features Passing Privacy Design Review / In-Scope Features
```
