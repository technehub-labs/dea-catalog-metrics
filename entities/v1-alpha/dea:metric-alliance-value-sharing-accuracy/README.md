## 2. Definition

Within Alliances & Partnerships Management, Alliance Value Sharing Accuracy (AVSA) is used to gauge the quality of outputs and outcomes. Its calculation is Revenue Splits Calculated Correctly / Splits, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
AVSA = Revenue Splits Calculated Correctly / Splits
```
