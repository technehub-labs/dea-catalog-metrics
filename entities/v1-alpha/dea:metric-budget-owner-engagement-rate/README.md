## 2. Definition

Budget Owner Engagement Rate (BOER) addresses the engagement or satisfaction of the people involved and is a fixture of financial planning & analysis reporting. Its calculation is Owners Submitting on First Request / Owners, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Owners Submitting on First Request / Owners
```
