## 2. Definition

Frequency Overexposure Rate (FOR-A) addresses the quality of outputs and outcomes and is a fixture of advertising & media buying reporting. Its calculation is Users Exceeding Frequency Cap / Reached Users, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Media & Entertainment practice.

## Formula

```
FOR-A = Users Exceeding Frequency Cap / Reached Users
```
