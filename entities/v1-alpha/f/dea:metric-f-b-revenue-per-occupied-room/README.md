## 2. Definition

Within Hotel & Resort Operations (Deep Dive), F&B Revenue per Occupied Room (FBRPOR) is used to gauge the economic value created or preserved. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as F&B Revenue / Occupied Rooms; the result is stated in currency per unit. Improvement means raising this figure toward best-in-class levels. In Hospitality, it is a recognized element of the standard performance toolkit.

## Formula

```
FBRPOR = F&B Revenue / Occupied Rooms
```
