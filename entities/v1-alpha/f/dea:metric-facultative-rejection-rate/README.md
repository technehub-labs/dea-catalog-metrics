## 2. Definition

A Insurance Underwriting indicator, Facultative Rejection Rate (FRR) quantifies exposure to adverse outcomes. The formula is Facultative Offers Rejected / Offers Made - reported in percent (%). It is a standard measure in the Insurance sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
FRR = Facultative Offers Rejected / Offers Made
```
