## 2. Definition

Financial Aid Processing Cycle Time (FAPCT) measures how efficiently resources are converted into outputs in the Education & Training Outcome Standard Measures domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Days from Aid Application to Disbursement Decision, measured in days. It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Education practice.

## Formula

```
FAPCT = Days from Aid Application to Disbursement Decision
```
