## 2. Definition

Within International Trade & Customs, First-Time Customs Pass Rate (FTCP) is used to gauge the quality of outputs and outcomes. The formula is Entries Cleared without Query / Entries Filed - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Logistics & Trade sector.

## Formula

```
FTCP = Entries Cleared without Query / Entries Filed
```
