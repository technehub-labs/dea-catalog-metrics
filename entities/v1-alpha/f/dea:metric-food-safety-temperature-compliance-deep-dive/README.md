## 2. Definition

Food Safety Temperature Compliance (Deep Dive) (FSTC-D) captures conformance to standards, plans, or obligations for organizations tracking restaurant operations (deep dive). It is a working-level control: thresholds trigger immediate operational response. It is defined as Temperature Logs within Range / Logs; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Restaurants, it is a recognized element of the standard performance toolkit.

## Formula

```
FSTC-D = Temperature Logs within Range / Logs
```
