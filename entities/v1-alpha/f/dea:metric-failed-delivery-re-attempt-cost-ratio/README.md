## 2. Definition

Within Parcel & Last-Mile Logistics (Deep Dive), Failed Delivery Re-attempt Cost Ratio (FDRC) is used to gauge how efficiently resources are converted into outputs. It is defined as Re-attempt Costs / Total Delivery Costs; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Logistics & Trade, it is a recognized element of the standard performance toolkit.

## Formula

```
FDRC = Re-attempt Costs / Total Delivery Costs
```
