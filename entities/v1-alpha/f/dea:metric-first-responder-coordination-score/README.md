## 2. Definition

First Responder Coordination Score (FRCS) measures capability maturity or development in the Crisis Management & Emergency Response domain. The formula is Rubric for External Agency Coordination in Exercises - reported in score (points). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.
