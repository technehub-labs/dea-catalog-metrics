## 2. Definition

Within Strategic Sourcing & Supplier Performance (Deep Dive), Supplier On-time Delivery Rate (Deep Dive) (SOTDR) is used to gauge the quality of outputs and outcomes. It is defined as Lines Delivered on Time / Order Lines; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Lines Delivered on Time / Order Lines
```
