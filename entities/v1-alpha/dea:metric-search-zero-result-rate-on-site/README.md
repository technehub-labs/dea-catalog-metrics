## 2. Definition

A Web & Digital Analytics Standard Measures indicator, Search Zero-Result Rate (On-Site) (SZRR) quantifies the quality of outputs and outcomes. It is computed as Searches Returning No Results / Searches, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is concentrated in Digital product.

## Formula

```
SZRR = Searches Returning No Results / Searches
```
