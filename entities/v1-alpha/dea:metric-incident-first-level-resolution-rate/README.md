## 2. Definition

Incident First-Level Resolution Rate (IFLRR) measures how efficiently resources are converted into outputs in the IT Incident & Major Problem Management domain. Its calculation is Incidents Resolved at First Line / Incidents, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Incidents Resolved at First Line / Incidents
```
