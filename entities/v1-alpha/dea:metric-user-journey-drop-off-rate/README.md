## 2. Definition

User Journey Drop-off Rate (UJDR) measures the retention of customers, users, or assets over time in the UX & Design Systems domain. It is computed as Users Abandoning at Step / Users Reaching Step, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Users Abandoning at Step / Users Reaching Step
```
