## 2. Definition

JavaScript Error Rate (Sessions) (JSERR) measures the quality of outputs and outcomes in the Web & Digital Analytics Standard Measures domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Sessions with Console Error / Sessions, measured in percent (%). It should be driven down, since lower readings signal healthier performance. It originates from and is most used in Digital product practice.

## Formula

```
Sessions with Console Error / Sessions
```
