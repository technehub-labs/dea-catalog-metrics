## 2. Definition

A Balanced Scorecard Implementation & Review indicator, Measure Owner Assignment Coverage (MOAC-BSC) quantifies governance. It is defined as BSC Measures with Named Owner / Measures; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
BSC Measures with Named Owner / Measures
```
