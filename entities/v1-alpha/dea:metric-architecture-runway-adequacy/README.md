## 2. Definition

A Software Architecture & Technical Design indicator, Architecture Runway Adequacy (ARA-SA) quantifies capability maturity or development. It is defined as Features with Architecture Runway Ready / Planned Features; the result is stated in percent (%). It is applied across virtually every sector. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures whether the architectural foundation (platform capabilities, patterns, infrastructure) is sufficient for the next several increments of planned product delivery. Runway is the leading indicator of the velocity collapse pattern: product ambition outpacing architectural investment produces the hallway where every feature is a detour. Adequacy assessment must be jointly owned by product and engineering, or it becomes an excuse ledger. Read with delivery predictability trends and deferred-enabler backlog aging.

## Formula

```
Features with Architecture Runway Ready / Planned Features
```
