## 2. Definition

A Enterprise OKR & Performance Management indicator, Calibration Cycle Completion Time (BCCT-OKR) quantifies how efficiently resources are converted into outputs. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Days to Complete Performance Calibration Cycle, measured in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
