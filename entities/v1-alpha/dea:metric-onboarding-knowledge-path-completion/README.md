## 2. Definition

Within Knowledge Management (Deep Dive), Onboarding Knowledge Path Completion (OKPC) is used to gauge capability maturity or development. It is defined as New Hires Completing Curated Learning Paths / New Hires; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
New Hires Completing Curated Learning Paths / New Hires
```
