## 2. Definition

Data Retention Rule Execution Rate (DRRER) captures conformance to standards, plans, or obligations for organizations tracking data governance & stewardship. It is defined as Retention Rules Applied Automatically / Applicable Rules; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Retention Rules Applied Automatically / Applicable Rules
```
