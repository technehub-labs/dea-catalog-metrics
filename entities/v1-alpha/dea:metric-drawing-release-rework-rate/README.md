## 2. Definition

A Engineering & Design indicator, Drawing Release Rework Rate (DRRR) quantifies the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Drawings Revised after Release / Drawings, measured in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Drawings Revised after Release / Drawings
```
