## 2. Definition

Model Version Control Compliance (MVCC-M) addresses conformance to standards, plans, or obligations and is a fixture of mlops & model lifecycle operations reporting. Its calculation is Models with Versioned Artifacts / Models, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Models with Versioned Artifacts / Models
```
