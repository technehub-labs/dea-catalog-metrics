## 2. Definition

A Pharma R&D & Clinical Trials indicator, Clinical Trial Enrollment Cycle Time (CTEC) quantifies how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Days from Site Activation to First Subject; the result is stated in days. It should be driven down, since lower readings signal healthier performance. In Pharmaceuticals, it is a recognized element of the standard performance toolkit.
