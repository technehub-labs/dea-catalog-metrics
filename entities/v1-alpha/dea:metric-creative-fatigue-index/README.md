## 2. Definition

Within Marketing Attribution & Analytics, Creative Fatigue Index (CFI-M) is used to gauge the quality of outputs and outcomes. It is defined as Decline in Response Rate per Creative Exposure Cohort; the result is stated in index (0-100 or normalized). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```

```
