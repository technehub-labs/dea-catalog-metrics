## 2. Definition

Boarding Occupancy Rate (Vet Clinics) (BOR-V) captures the utilization or availability of capacity for organizations tracking veterinary & animal health. It is defined as Boarding Days Sold / Capacity Days; the result is stated in percent (%). In Healthcare, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Boarding Days Sold / Capacity Days
```
