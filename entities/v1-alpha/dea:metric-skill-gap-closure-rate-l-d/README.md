## 2. Definition

A Learning & Development Effectiveness (Deep Dive) indicator, Skill Gap Closure Rate (L&D) (SGCR-LD) quantifies capability maturity or development. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Critical Skill Gaps Closed within Plan / Gaps, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how quickly identified skill gaps are actually closed. Closure converts capability planning from map to management. Gaps closed by reclassifying requirements rather than building skill are cosmetic. Read with skills gap analysis coverage and strategic competency coverage.

## Formula

```
Critical Skill Gaps Closed within Plan / Gaps
```
