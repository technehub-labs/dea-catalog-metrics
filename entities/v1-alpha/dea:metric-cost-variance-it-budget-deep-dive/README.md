## 2. Definition

Cost Variance - IT Budget (Deep Dive) (CVITB-D) measures conformance to standards, plans, or obligations in the IT Financial Management & Technology Budgeting domain. It is defined as Actual Spend - Budget / Budget; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures deviation of actual IT spend from the approved budget. IT variance is a leading indicator of project and portfolio overruns. Variance hidden through capitalization policy shifts surfaces later. Read with cost variance percent and budget forecast accuracy - financial planning.

## Formula

```
Actual Spend - Budget / Budget
```
