## 2. Definition

A Crisis Management & Emergency Response indicator, Employee Safety Check Completion Rate (ESCCR) quantifies exposure to adverse outcomes. It is defined as Staff Accounted for within Threshold in Event / Staff; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Staff Accounted for within Threshold in Event / Staff
```
