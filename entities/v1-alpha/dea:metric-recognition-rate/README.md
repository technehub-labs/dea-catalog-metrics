## 2. Definition

Recognition Rate (RGR-E) measures the engagement or satisfaction of the people involved in the Culture & Employee Experience domain. Its calculation is Employees Recognized per Period / Employees, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Employees Recognized per Period / Employees
```
