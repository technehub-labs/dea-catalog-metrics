## 2. Definition

Alert-to-Dashboard Link Compliance (ADLC) addresses the quality of outputs and outcomes and is a fixture of observability & site reliability engineering reporting. It is defined as Alerts Linking to Runbook and Dashboard / Alerts; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```

```
