## 2. Definition

Within Master Data Management, Source System Registration Compliance (SSRC-MD) is used to gauge conformance to standards, plans, or obligations. It is computed as Registered Sources of Master Data / Actual Sources, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Registered Sources of Master Data / Actual Sources
```
