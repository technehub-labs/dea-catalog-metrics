## 2. Definition

Within Knowledge Management, Expertise Location Coverage (ELC) is used to gauge capability maturity or development. It is defined as Critical Topics with Identified Experts / Critical Topics; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of critical expertise domains with findable, current expert directories. It matters because lost time searching for expertise is invisible productivity drag. Directories can be current in structure but stale in accuracy. Read with Time-to-Expert search metrics and Knowledge Capture Rate to confirm location translates into access.

## Formula

```
Critical Topics with Identified Experts / Critical Topics
```
