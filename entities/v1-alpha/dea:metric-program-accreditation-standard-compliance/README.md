## 2. Definition

Program Accreditation Standard Compliance (PASC) addresses conformance to standards, plans, or obligations and is a fixture of education & training outcome standard measures reporting. It is defined as Standards Met at Last Review / Standards; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. In Education, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures adherence to accreditation bodies' standards across programs. Accreditation is the license to operate and the transferability of credentials. Compliance maintained through documentation rather than practice divergence invites findings. Read with regulatory finding closure rate and learning outcome attainment rate.

## Formula

```
Standards Met at Last Review / Standards
```
