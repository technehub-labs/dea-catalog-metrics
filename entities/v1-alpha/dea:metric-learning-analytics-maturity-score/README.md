## 2. Definition

A Learning & Development Effectiveness (Deep Dive) indicator, Learning Analytics Maturity Score (LAMS) quantifies capability maturity or development. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Rubric of Measurement Sophistication of L&D Function - reported in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.
