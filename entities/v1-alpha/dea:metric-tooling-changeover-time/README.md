## 2. Definition

A Automotive indicator, Tooling Changeover Time (TCT-A) quantifies how efficiently resources are converted into outputs. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Time to Change Stamping or Assembly Tooling - reported in minutes. It should be driven down, since lower readings signal healthier performance. It is a standard measure in the Automotive sector.

## Formula

```
Time to Change Stamping or Assembly Tooling
```
