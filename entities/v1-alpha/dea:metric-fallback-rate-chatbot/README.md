## 2. Definition

Fallback Rate (Chatbot) (FBR) measures the quality of outputs and outcomes in the Conversational AI & Chatbots domain. It is defined as Turns Handled by Fallback Response / Total Turns; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Turns Handled by Fallback Response / Total Turns
```
