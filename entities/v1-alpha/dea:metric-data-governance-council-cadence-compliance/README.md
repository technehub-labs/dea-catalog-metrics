## 2. Definition

Within Data Governance & Stewardship, Data Governance Council Cadence Compliance (DGCC) is used to gauge conformance to standards, plans, or obligations. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Council Meetings Held per Charter / Scheduled, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

