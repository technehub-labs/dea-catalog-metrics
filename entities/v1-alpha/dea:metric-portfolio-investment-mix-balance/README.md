## 2. Definition

Portfolio Investment Mix Balance (PIMB) captures strategy for organizations tracking program & portfolio management. The formula is Distribution across Run, Grow, Transform Categories - reported in percent (%). It is applied across virtually every sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Values outside the intended band, on either side, warrant investigation.

## 3. Context

Measures the distribution of portfolio investment across run, grow, and transform categories. Balance prevents the two classic failure modes: eating the seed corn (all run) and ignoring the core (all transformation). Optimal mix is strategy-dependent; balance itself is not a virtue. Read with strategic alignment score - initiatives and funding release versus milestone attainment.

## Formula

```
Distribution across Run, Grow, Transform Categories
```
