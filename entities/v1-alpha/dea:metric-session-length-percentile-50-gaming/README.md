## 2. Definition

Within Gaming Development & Live Operations, Session Length Percentile 50 (Gaming) (SL50) is used to gauge the engagement or satisfaction of the people involved. It is defined as Median Play Session Duration; the result is stated in minutes. In Gaming, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.
