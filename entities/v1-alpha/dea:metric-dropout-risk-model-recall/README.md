## 2. Definition

Dropout Risk Model Recall (DRMR) addresses exposure to adverse outcomes and is a fixture of education & training outcome standard measures reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as At-Risk Students Flagged before Withdrawal / Actual Withdrawals; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Education, it is a recognized element of the standard performance toolkit.

## Formula

```
At-Risk Students Flagged before Withdrawal / Actual Withdrawals
```
