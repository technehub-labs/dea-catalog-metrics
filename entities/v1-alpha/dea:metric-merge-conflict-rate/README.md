## 2. Definition

Merge Conflict Rate (MCR-SD) captures how efficiently resources are converted into outputs for organizations tracking software development - coding & engineering practices. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Merges Requiring Conflict Resolution / Merges, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Merges Requiring Conflict Resolution / Merges
```
