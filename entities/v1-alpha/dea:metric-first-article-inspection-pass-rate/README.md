## 2. Definition

A Quality Management indicator, First Article Inspection Pass Rate (FAI) quantifies the quality of outputs and outcomes. Its calculation is First Articles Passed / First Articles Inspected, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
First Articles Passed / First Articles Inspected
```
