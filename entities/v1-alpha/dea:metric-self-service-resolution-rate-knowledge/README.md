## 2. Definition

Self-Service Resolution Rate (Knowledge) (SSRR-KM) captures how efficiently resources are converted into outputs for organizations tracking knowledge management (deep dive). The formula is Issues Resolved via Self-Service / Issues - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Issues Resolved via Self-Service / Issues
```
