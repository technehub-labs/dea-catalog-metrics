## 2. Definition

A Agile Delivery & Team Effectiveness indicator, Retrospective Action Completion Rate (RACR-AG) quantifies conformance to standards, plans, or obligations. It provides the day-to-day signal that a process is running as designed. Its calculation is Retro Actions Closed by Next Retrospective / Actions, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Retro Actions Closed by Next Retrospective / Actions
```
