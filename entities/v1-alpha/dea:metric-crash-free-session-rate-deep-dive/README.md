## 2. Definition

Within Gaming Development & Live Operations, Crash-Free Session Rate (Deep Dive) (CFSR-D) is used to gauge the quality of outputs and outcomes. Its calculation is Sessions without Crash / Sessions, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Gaming practice.

## Formula

```
Sessions without Crash / Sessions
```
