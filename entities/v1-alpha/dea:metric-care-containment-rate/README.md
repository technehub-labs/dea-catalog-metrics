## 2. Definition

Within Telecom Customer Experience & Billing, Care Containment Rate (CCR-T2) is used to gauge how efficiently resources are converted into outputs. Its calculation is Issues Resolved in Care without Dispatch or Escalation / Issues, measured in percent (%). It originates from and is most used in Telecommunications practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Issues Resolved in Care without Dispatch or Escalation / Issues
```
