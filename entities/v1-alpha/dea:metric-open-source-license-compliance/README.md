## 2. Definition

A Intellectual Property & Licensing indicator, Open Source License Compliance (OSLC) quantifies exposure to adverse outcomes. Its calculation is Open Source Components with Compliant Use / Components, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Open Source Components with Compliant Use / Components
```
