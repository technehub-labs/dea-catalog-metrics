## 2. Definition

Mobile Feature Flag Hygiene Rate (MFFH) measures the quality of outputs and outcomes in the Mobile & Client Development domain. The formula is Stale Flags Removed / Stale Flags Identified - reported in percent (%). It is a standard measure in the Software sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Stale Flags Removed / Stale Flags Identified
```
