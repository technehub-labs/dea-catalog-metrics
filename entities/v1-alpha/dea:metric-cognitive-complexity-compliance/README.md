## 2. Definition

Cognitive Complexity Compliance (CCC-SD) captures the quality of outputs and outcomes for organizations tracking software development - coding & engineering practices. The formula is Functions within Cognitive Complexity Limit / Functions - reported in percent (%). It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Functions within Cognitive Complexity Limit / Functions
```
