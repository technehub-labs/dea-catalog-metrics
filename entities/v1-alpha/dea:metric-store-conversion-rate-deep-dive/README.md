## 2. Definition

Within Retail Standard Measures, Store Conversion Rate (Deep Dive) (SCRDD) is used to gauge growth over time. It is defined as Transactions / Store Traffic; the result is stated in percent (%). In Retail & E-commerce, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Transactions / Store Traffic
```
