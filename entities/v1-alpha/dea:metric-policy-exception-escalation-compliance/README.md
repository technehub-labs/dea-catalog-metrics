## 2. Definition

Within Compliance Monitoring & Testing, Policy Exception Escalation Compliance (PEEC) is used to gauge conformance to standards, plans, or obligations. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Exceptions Escalated per Framework / Exceptions Meeting Criteria - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Exceptions Escalated per Framework / Exceptions Meeting Criteria
```
