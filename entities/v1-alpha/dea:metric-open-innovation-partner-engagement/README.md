## 2. Definition

A R&D and Innovation indicator, Open Innovation Partner Engagement (OIP) quantifies capability maturity or development. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Active External Collaboration Projects / Total Innovation Projects; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures activity or value generated with external innovation partners. It matters because external collaboration extends R&D capacity and de-risks exploration. Metrics can count signed agreements rather than working collaborations, inflating engagement. Read with Idea Conversion from external sources and Time to Pilot to confirm partnerships produce outcomes, not press releases.

## Formula

```
Active External Collaboration Projects / Total Innovation Projects
```
