## 2. Definition

Environmental Cost per Model Training Run (ECMTR) captures environmental and social sustainability performance for organizations tracking ai ethics, fairness & responsible ai. It is defined as Energy Consumed per Training Run; the result is stated in megawatt-hours (MWh). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
