## 2. Definition

A Balanced Scorecard - Customer Perspective indicator, First Contact Resolution Trend (Deep Dive) (FCRT-D) quantifies how efficiently resources are converted into outputs. It is computed as Change in FCR between Periods, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.
