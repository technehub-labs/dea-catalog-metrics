## 2. Definition

Within Balanced Scorecard Implementation & Review, BSC Review Cadence Compliance (BRCC) is used to gauge conformance to standards, plans, or obligations. It is defined as Reviews Held per Calendar / Reviews Scheduled; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
BRCC = Reviews Held per Calendar / Reviews Scheduled
```
