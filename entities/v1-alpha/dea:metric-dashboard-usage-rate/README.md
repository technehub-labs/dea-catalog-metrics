## 2. Definition

A Data Science & Analytics Operations indicator, Dashboard Usage Rate (DUR-DS) quantifies the economic value created or preserved. The formula is Dashboards Accessed Monthly / Dashboards Published - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Dashboards Accessed Monthly / Dashboards Published
```
