## 2. Definition

Sprint Goal Success Rate (SGSR) captures conformance to standards, plans, or obligations for organizations tracking software engineering. It is defined as Sprints Achieving Goal / Total Sprints; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Sprints Achieving Goal / Total Sprints
```
