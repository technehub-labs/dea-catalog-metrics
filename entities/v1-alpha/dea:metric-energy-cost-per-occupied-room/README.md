## 2. Definition

Within Hotel & Resort Operations (Deep Dive), Energy Cost per Occupied Room (ECOR) is used to gauge how efficiently resources are converted into outputs. The formula is Energy Cost / Occupied Rooms - reported in currency per unit. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. It is a standard measure in the Hospitality sector.

## Formula

```
Energy Cost / Occupied Rooms
```
