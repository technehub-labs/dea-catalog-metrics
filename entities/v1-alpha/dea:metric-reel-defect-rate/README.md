## 2. Definition

Reel Defect Rate (RDR-P) addresses the quality of outputs and outcomes and is a fixture of pulp, paper & forest products reporting. Its calculation is Reels with Defects / Reels Produced, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Manufacturing practice.

## Formula

```
Reels with Defects / Reels Produced
```
