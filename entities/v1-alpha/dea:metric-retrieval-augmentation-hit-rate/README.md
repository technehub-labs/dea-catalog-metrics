## 2. Definition

Within Generative AI & LLM Operations, Retrieval Augmentation Hit Rate (RAHR-LLM) is used to gauge the quality of outputs and outcomes. Its calculation is Queries Returning Relevant Chunks / Queries, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Queries Returning Relevant Chunks / Queries
```
