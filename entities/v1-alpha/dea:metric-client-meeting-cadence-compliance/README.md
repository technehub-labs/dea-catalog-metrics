## 2. Definition

A Asset & Wealth Management (Deep Dive) indicator, Client Meeting Cadence Compliance (CMCC) quantifies conformance to standards, plans, or obligations. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Clients Reviewed per Service Schedule / Due; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Financial Services, it is a recognized element of the standard performance toolkit.

## Formula

```
Clients Reviewed per Service Schedule / Due
```
