## 2. Definition

A Observability & Site Reliability Engineering indicator, Dashboard-to-Service Coverage (DTSC) quantifies capability maturity or development. It is defined as Services with Operational Dashboards / Services; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
DTSC = Services with Operational Dashboards / Services
```
