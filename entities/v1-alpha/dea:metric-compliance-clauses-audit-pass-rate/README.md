## 2. Definition

Within Legal Operations, Compliance Clauses Audit Pass Rate (CCAP) is used to gauge conformance to standards, plans, or obligations. Its calculation is Audited Contracts with Required Clauses / Audited, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Audited Contracts with Required Clauses / Audited
```
