## 2. Definition

Flat-Pack Assembly Time (Standard) (FPAT) measures the quality of outputs and outcomes in the Furniture & Wood Products domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Minutes for Standard Assembly Sequence; the result is stated in minutes. It should be driven down, since lower readings signal healthier performance. In Manufacturing, it is a recognized element of the standard performance toolkit.
