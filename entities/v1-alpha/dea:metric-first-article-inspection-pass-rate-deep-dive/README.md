## 2. Definition

First Article Inspection Pass Rate (Deep Dive) (FAIPR) addresses the quality of outputs and outcomes and is a fixture of aerospace & defense program management reporting. It is computed as FAIs Accepted / FAIs Performed, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Aerospace & Defense.

## Formula

```
FAIs Accepted / FAIs Performed
```
