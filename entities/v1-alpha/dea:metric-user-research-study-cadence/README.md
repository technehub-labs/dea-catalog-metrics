## 2. Definition

User Research Study Cadence (URSC) addresses capability maturity or development and is a fixture of ux & design systems reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Studies Executed per Quarter, expressed in count (items per period). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.
