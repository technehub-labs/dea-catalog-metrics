## 2. Definition

Commission and Spread Cost Ratio (CSCR-IM) measures how efficiently resources are converted into outputs in the Investment Management - Portfolio Operations domain. The formula is Trading Costs / Traded Value - reported in percent (%). It is a standard measure in the Financial Services sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Trading Costs / Traded Value
```
