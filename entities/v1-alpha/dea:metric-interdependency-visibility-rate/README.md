## 2. Definition

Interdependency Visibility Rate (IVR-P) captures exposure to adverse outcomes for organizations tracking pmo & portfolio governance. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Cross-Initiative Dependencies Mapped / Identified, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Cross-Initiative Dependencies Mapped / Identified
```
