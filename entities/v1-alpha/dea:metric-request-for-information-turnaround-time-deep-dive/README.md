## 2. Definition

Within Construction Contracting (Deep Dive), Request for Information Turnaround Time (Deep Dive) (RFIT-D) is used to gauge how efficiently resources are converted into outputs. It is defined as Days from RFI to Answer; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Construction, it is a recognized element of the standard performance toolkit.

## Formula

```
RFIT-D = Days from RFI to Answer
```
