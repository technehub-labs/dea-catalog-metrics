## 2. Definition

Unit Test Coverage - Branch (UTCB-QA) measures the quality of outputs and outcomes in the Software Testing & Quality Engineering domain. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Branches Covered / Total Branches - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Branches Covered / Total Branches
```
