## 2. Definition

Average Attendance per Performance (AAP) measures the utilization or availability of capacity in the Arts & Culture domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Total Attendance / Performances, measured in count (items per period). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Arts & culture practice.

## Formula

```
Total Attendance / Performances
```
