## 2. Definition

Release Calendar Adherence by Teams (RCAT) addresses conformance to standards, plans, or obligations and is a fixture of release management & environments reporting. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Teams Following Coordinated Release Calendar / Teams, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Teams Following Coordinated Release Calendar / Teams
```
