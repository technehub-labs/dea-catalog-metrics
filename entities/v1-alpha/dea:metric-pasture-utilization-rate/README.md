## 2. Definition

Within Agriculture & Agronomy (Deep Dive), Pasture Utilization Rate (PUR) is used to gauge how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Grazed Pasture / Grown Pasture; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Agriculture, it is a recognized element of the standard performance toolkit.

## Formula

```
Grazed Pasture / Grown Pasture
```
