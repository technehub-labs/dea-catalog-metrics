## 2. Definition

Design Cycle Time (Engineering) (DCT-E) addresses how efficiently resources are converted into outputs and is a fixture of engineering & design reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Days from Requirements to Design Release - reported in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
