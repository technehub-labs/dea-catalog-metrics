## 2. Definition

Event Budget Variance (EBV-E) addresses how efficiently resources are converted into outputs and is a fixture of events & exhibitions reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Actual Spend - Budget / Budget, expressed in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Its use is concentrated in Media & Entertainment.

## Formula

```
Actual Spend - Budget / Budget
```
