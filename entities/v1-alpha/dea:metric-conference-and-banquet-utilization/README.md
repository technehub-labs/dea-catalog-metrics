## 2. Definition

Within Hotel & Resort Operations (Deep Dive), Conference and Banquet Utilization (CBU) is used to gauge the utilization or availability of capacity. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Function Space Revenue / Available Function Space Time - reported in currency per unit. Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Hospitality sector.

## Formula

```
Function Space Revenue / Available Function Space Time
```
