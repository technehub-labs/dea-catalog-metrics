## 2. Definition

A Corporate Travel Management indicator, Traveler Satisfaction (Program) (TSP) quantifies the engagement or satisfaction of the people involved. It is computed as Satisfied Traveler Survey Responses / Responses, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures traveler satisfaction with the corporate travel program. It matters because a program travelers hate drives workarounds that destroy its economics. Satisfaction can be gamed by surveying only compliant frequent travelers. Read with Out-of-Policy Spend Rate and booking channel data to confirm satisfaction coexists with control.

## Formula

```
TSP = Satisfied Traveler Survey Responses / Responses
```
