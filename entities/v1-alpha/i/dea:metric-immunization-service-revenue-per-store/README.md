## 2. Definition

Within Pharmacy Retail, Immunization Service Revenue per Store (ISRS) is used to gauge growth over time. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Vaccination Revenue / Stores, measured in currency value. Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Healthcare practice.

## Formula

```
ISRS = Vaccination Revenue / Stores
```
