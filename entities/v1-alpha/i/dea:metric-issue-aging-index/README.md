## 2. Definition

Within Project Risk & Issue Management, Issue Aging Index (IAI-P) is used to gauge exposure to adverse outcomes. The formula is Average Age of Open Project Issues - reported in days. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
IAI-P = Average Age of Open Project Issues
```
