## 2. Definition

IP Enforcement Action Success Rate (IEASR) addresses exposure to adverse outcomes and is a fixture of intellectual property & licensing reporting. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Enforcement Actions with Favorable Outcome / Actions, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how often enforcement actions (cease-and-desist, litigation, licensing pressure) achieve their objective. Enforcement credibility is what makes the portfolio valuable. Settled-on-friendly terms cases can be scored as successes while setting bad precedent. Read with IP litigation cost exposure ratio and patent grant success rate.

## Formula

```
IEASR = Enforcement Actions with Favorable Outcome / Actions
```
