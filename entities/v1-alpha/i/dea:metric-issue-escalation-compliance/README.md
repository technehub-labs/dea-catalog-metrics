## 2. Definition

Issue Escalation Compliance (IEC-P) measures conformance to standards, plans, or obligations in the Project Risk & Issue Management domain. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Issues Escalated per Matrix / Issues Meeting Criteria - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
IEC-P = Issues Escalated per Matrix / Issues Meeting Criteria
```
