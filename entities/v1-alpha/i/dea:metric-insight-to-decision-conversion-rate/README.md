## 2. Definition

Within Financial Planning & Analysis, Insight-to-Decision Conversion Rate (IDCR-FP) is used to gauge the economic value created or preserved. The formula is Analyses Resulting in Documented Decisions / Analyses - reported in percent (%). It is applied across virtually every sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures how often FP&A analysis demonstrably changes a business decision. Conversion is the justification for the analysis function: unconsumed insight is expensive trivia. Attribution of influence is inherently soft and often self-claimed. Read with decision quality audit score and single source of truth metric adoption.

## Formula

```
IDCR-FP = Analyses Resulting in Documented Decisions / Analyses
```
