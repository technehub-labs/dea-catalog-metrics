## 2. Definition

IP Renewal Decision Compliance (IRDC) addresses the economic value created or preserved and is a fixture of intellectual property & licensing reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Renewals Decided by Review Date / Renewals Due, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
IRDC = Renewals Decided by Review Date / Renewals Due
```
