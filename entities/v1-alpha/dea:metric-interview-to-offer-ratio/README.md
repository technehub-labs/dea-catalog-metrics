## 2. Definition

Interview-to-Offer Ratio (ITOR) measures how efficiently resources are converted into outputs in the Talent Acquisition Deep Dive domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Candidates Interviewed per Offer Made, measured in ratio (x:1 or x). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

