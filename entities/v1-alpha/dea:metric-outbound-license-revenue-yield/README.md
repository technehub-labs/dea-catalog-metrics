## 2. Definition

Within Intellectual Property & Licensing, Outbound License Revenue Yield (OLRY) is used to gauge the economic value created or preserved. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Licensing Revenue vs Portfolio Potential, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures revenue generated from licensing IP to others. Yield converts the portfolio from cost center to asset. Revenue achieved through giving away core technology can undermine the primary business. Read with IP value realization rate and royalty collection rate.

## Formula

```
Licensing Revenue vs Portfolio Potential
```
