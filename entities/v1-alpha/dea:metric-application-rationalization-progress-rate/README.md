## 2. Definition

A IT Financial Management & Technology Budgeting indicator, Application Rationalization Progress Rate (ARRP-ITFM) quantifies how efficiently resources are converted into outputs. Its calculation is Applications Retired or Consolidated per Plan / Planned, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures how quickly the application portfolio is consolidated toward its target state. Most estates carry large duplication that rationalization retires. Progress measured by 'reviewed' rather than 'decommissioned' is preparation, not progress. Read with total cost of ownership per application and technical debt remediation progress.

## Formula

```
Applications Retired or Consolidated per Plan / Planned
```
