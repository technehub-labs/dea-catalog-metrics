## 2. Definition

A Agriculture & Agronomy (Deep Dive) indicator, Post-Harvest Quality Rejection Rate (Deep Dive) (PHQR-D) quantifies the quality of outputs and outcomes. Its calculation is Rejected Lots / Delivered Lots, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Agriculture practice.

## Formula

```
Rejected Lots / Delivered Lots
```
