## 2. Definition

A Generative AI & LLM Operations indicator, Fine-Tuning Cycle Time (FTCT-LLM) quantifies how efficiently resources are converted into outputs. The formula is Days from Data Curation to Fine-Tuned Model Evaluation - reported in days. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.
