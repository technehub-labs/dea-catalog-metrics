## 2. Definition

Within Events & Exhibitions, Sponsorship Revenue Fulfilment Rate (SRFR) is used to gauge conformance to standards, plans, or obligations. It is defined as Delivered Sponsor Benefits / Contracted Benefits; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Media & Entertainment, it is a recognized element of the standard performance toolkit.

## Formula

```
Delivered Sponsor Benefits / Contracted Benefits
```
