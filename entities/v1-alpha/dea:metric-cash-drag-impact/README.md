## 2. Definition

Cash Drag Impact (CDI-IP) addresses the economic value created or preserved and is a fixture of investment performance measurement reporting. Its calculation is Return Lost to Cash Position vs Benchmark, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Investment management practice.

## Formula

```
CDI-IP = Return Lost to Cash Position vs Benchmark
```
