## 2. Definition

Course Completion Rate (Deep Dive - L&D) (CCRDD) addresses conformance to standards, plans, or obligations and is a fixture of learning & development effectiveness (deep dive) reporting. Its calculation is Completions per Enrollments, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.
