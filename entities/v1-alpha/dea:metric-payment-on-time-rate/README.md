## 2. Definition

Within Accounts Payable & Receivable Operations (Deep Dive), Payment on Time Rate (POTR) is used to gauge conformance to standards, plans, or obligations. It is defined as Payments within Agreed Terms / Payments; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Payments within Agreed Terms / Payments
```
