## 2. Definition

Within Furniture & Wood Products, Finish Quality First Pass Rate (FQFP) is used to gauge the quality of outputs and outcomes. Its calculation is Items Passing Finish Inspection / Items, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Manufacturing practice.

## Formula

```
Items Passing Finish Inspection / Items
```
