## 2. Definition

Portfolio Outcome Review Cadence Compliance (PORCC) addresses conformance to standards, plans, or obligations and is a fixture of program & portfolio management reporting. It is defined as Reviews Held per Governance Calendar / Scheduled; the result is stated in percent (%). Its trend is watched by senior leadership as an early signal of structural performance shifts. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures whether the portfolio undergoes scheduled performance-versus-promise reviews. Reviews are the engine of portfolio learning and reallocation decisions. Cadence compliance without decision authority in the room is ceremony. Read with portfolio value delivery rate and initiative kill decision timeliness.

## Formula

```
Reviews Held per Governance Calendar / Scheduled
```
