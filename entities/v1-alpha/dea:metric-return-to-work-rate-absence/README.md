## 2. Definition

A Standard Workforce & Pay Metrics indicator, Return-to-Work Rate (Absence) (RTWR) quantifies the retention of customers, users, or assets over time. It is computed as Absences Ending in Successful Return / Absence Cases, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Absences Ending in Successful Return / Absence Cases
```
