## 2. Definition

Within Actuarial & Reserving, Peer Review Completion Rate (Actuarial) (PRCA) is used to gauge the quality of outputs and outcomes. The formula is Work Products Peer Reviewed / Work Products - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Insurance sector.

## Formula

```
Work Products Peer Reviewed / Work Products
```
