## 2. Definition

API Contract Test Coverage (APICC) measures the quality of outputs and outcomes in the API Lifecycle Management domain. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Endpoints Covered by Contract Tests / Endpoints, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Software.

## Formula

```
Endpoints Covered by Contract Tests / Endpoints
```
