## 2. Definition

Within Events & Exhibitions, Attendee Lead-to-Sale Conversion (Exhibitors) (ALSC) is used to gauge the economic value created or preserved. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Exhibitor Leads Converted to Sales / Leads, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Media & Entertainment.

## Formula

```
Exhibitor Leads Converted to Sales / Leads
```
