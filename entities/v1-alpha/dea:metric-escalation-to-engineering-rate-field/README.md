## 2. Definition

Escalation-to-Engineering Rate - Field (EEF) measures the quality of outputs and outcomes in the Field Maintenance & Technical Field Service (Deep Dive) domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Jobs Escalated to Engineering / Jobs, expressed in percent (%). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Jobs Escalated to Engineering / Jobs
```
