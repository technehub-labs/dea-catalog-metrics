## 2. Definition

Fiber Cut Restoration Time (FCRT) measures how efficiently resources are converted into outputs in the Telecom Network Operations (Deep Dive) domain. Its calculation is Hours to Restore Fiber Link, measured in hours. It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Telecommunications practice.

## Formula

```
Hours to Restore Fiber Link
```
