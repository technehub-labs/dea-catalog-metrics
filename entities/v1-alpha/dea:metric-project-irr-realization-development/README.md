## 2. Definition

Project IRR Realization (Development) (PIRR) measures the economic value created or preserved in the Real Estate & Mortgage Standard Measures domain. It is computed as Realized IRR vs Underwritten IRR / Underwritten IRR, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is concentrated in Real estate.

## 3. Context

Measures whether completed developments achieved their underwritten IRR. Realization is the accountability loop for development risk-taking. IRRs recomputed with later cost overruns excluded from the denominator flatter. Read with yield on cost (Development) and cost variance percent (Deep Dive).

## Formula

```
Realized IRR vs Underwritten IRR / Underwritten IRR
```
