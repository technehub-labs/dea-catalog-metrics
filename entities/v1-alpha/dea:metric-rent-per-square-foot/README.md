## 2. Definition

A Real Estate & Mortgage Standard Measures indicator, Rent per Square Foot (RPSF) quantifies the economic value created or preserved. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Annual Rent / Leasable Area - reported in currency per unit. Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Real estate sector.

## Formula

```
Annual Rent / Leasable Area
```
