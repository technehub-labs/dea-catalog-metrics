## 2. Definition

Patent Maintenance Coverage (PMC) addresses conformance to standards, plans, or obligations and is a fixture of intellectual property & licensing reporting. Its calculation is Patents with Current Maintenance Payments / Patents, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Patents with Current Maintenance Payments / Patents
```
