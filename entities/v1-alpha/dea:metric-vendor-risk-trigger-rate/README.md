## 2. Definition

A Project Risk & Issue Management indicator, Vendor Risk Trigger Rate (VRTR) quantifies exposure to adverse outcomes. Its calculation is Third-Party Risks Materializing / Third-Party Risks Tracked, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Third-Party Risks Materializing / Third-Party Risks Tracked
```
