## 2. Definition

Within Agile Delivery & Team Effectiveness, Cycle Time Percentile 85 - Delivery (CTP85-AG) is used to gauge the quality of outputs and outcomes. It is defined as 85th Percentile Item Cycle Time; the result is stated in days. It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
