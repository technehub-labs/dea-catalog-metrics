## 2. Definition

Compliance Adherence for Broadcast Content (CABC) measures conformance to standards, plans, or obligations in the Broadcasting & Streaming Media domain. The formula is Items Meeting Regulatory Code / Items Aired - reported in percent (%). It is a standard measure in the Media & Entertainment sector. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures conformance of broadcast content with regulatory obligations - advertising codes, watershed rules, captions, editorial standards. Fines and license conditions ride on this adherence, and standards failures are brand events in a trust business. Sampling methodology determines credibility, since live content cannot be fully reviewed. Read with complaint volumes to the regulator and caption/accessibility service levels.

## Formula

```
Items Meeting Regulatory Code / Items Aired
```
