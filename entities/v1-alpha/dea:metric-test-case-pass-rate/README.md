## 2. Definition

Test Case Pass Rate (TCPR-QA) measures the quality of outputs and outcomes in the Software Testing & Quality Engineering domain. Its calculation is Passed Tests / Executed Tests, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Passed Tests / Executed Tests
```
