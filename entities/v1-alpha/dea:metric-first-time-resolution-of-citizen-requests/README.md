## 2. Definition

A Public Sector & Government indicator, First-Time Resolution of Citizen Requests (FTCR) quantifies the quality of outputs and outcomes. The formula is Requests Resolved without Follow-up / Requests Received - reported in percent (%). It is a standard measure in the Public sector sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of citizen requests resolved without follow-up contact. It matters because first-time resolution is the citizen-felt definition of competence in public service. It can be gamed by marking requests resolved upon a first reply that did not address the issue. Read with Case Processing Time and complaint/escalation volumes to confirm resolution claims survive citizen experience.

## Formula

```
Requests Resolved without Follow-up / Requests Received
```
