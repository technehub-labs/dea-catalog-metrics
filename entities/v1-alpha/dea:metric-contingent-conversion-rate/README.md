## 2. Definition

Within Gig & Contingent Workforce, Contingent Conversion Rate (CVC) is used to gauge capability maturity or development. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Contingent Workers Converted to Permanent / Eligible Contingent, measured in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of contingent workers converted to permanent roles. It matters because conversion is a proven low-risk talent pipeline. Rate can be inflated by converting only the roles nobody wants. Read with Post-Conversion Retention and Manager Satisfaction with conversions to confirm quality of pipeline.

## Formula

```
Contingent Workers Converted to Permanent / Eligible Contingent
```
