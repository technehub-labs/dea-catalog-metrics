## 2. Definition

Bug Triage Cycle Time (BTCT-QA) captures how efficiently resources are converted into outputs for organizations tracking software testing & quality engineering. The formula is Hours from Report to Triage Decision - reported in hours. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Hours from Report to Triage Decision
```
