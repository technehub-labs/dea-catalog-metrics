## 2. Definition

Shrinkage of Dye Batch (SDB) captures the quality of outputs and outcomes for organizations tracking textile & apparel. The formula is Fabric Weight Loss in Dyeing / Fabric Input Weight - reported in percent (%). It is a standard measure in the Textile & apparel sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Fabric Weight Loss in Dyeing / Fabric Input Weight
```
