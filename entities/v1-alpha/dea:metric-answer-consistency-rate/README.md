## 2. Definition

A Generative AI & LLM Operations indicator, Answer Consistency Rate (ACR-LLM) quantifies the quality of outputs and outcomes. It is computed as Identical Prompts Yielding Semantically Consistent Answers / Sampled, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Identical Prompts Yielding Semantically Consistent Answers / Sampled
```
