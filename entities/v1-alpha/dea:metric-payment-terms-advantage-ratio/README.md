## 2. Definition

Payment Terms Advantage Ratio (PTAR-SS) addresses the economic value created or preserved and is a fixture of strategic sourcing & supplier performance (deep dive) reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Awards with Favourable Payment Terms / Awards - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Awards with Favourable Payment Terms / Awards
```
