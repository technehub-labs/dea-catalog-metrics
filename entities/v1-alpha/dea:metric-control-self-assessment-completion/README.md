## 2. Definition

Control Self-Assessment Completion (CSAC) captures conformance to standards, plans, or obligations for organizations tracking compliance monitoring & testing. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Business Units Submitting CSAs by Due Date / Units; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Business Units Submitting CSAs by Due Date / Units
```
