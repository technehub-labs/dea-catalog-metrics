## 2. Definition

A Contract Lifecycle Management indicator, Standard Template Adoption Rate (STAR-CL) quantifies how efficiently resources are converted into outputs. Its calculation is Contracts on Approved Templates / Contracts Drafted, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Contracts on Approved Templates / Contracts Drafted
```
