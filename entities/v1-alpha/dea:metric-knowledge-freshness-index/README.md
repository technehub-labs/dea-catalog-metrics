## 2. Definition

A Knowledge Management (Deep Dive) indicator, Knowledge Freshness Index (KFI) quantifies the quality of outputs and outcomes. Its calculation is Articles Reviewed within Currency Standard / Articles, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Articles Reviewed within Currency Standard / Articles
```
