## 2. Definition

A Master Data Management indicator, Unmanaged Master Creation Rate (UMMCR) quantifies conformance to standards, plans, or obligations. Its calculation is Records Bypassing MDM Workflow / New Records, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Records Bypassing MDM Workflow / New Records
```
