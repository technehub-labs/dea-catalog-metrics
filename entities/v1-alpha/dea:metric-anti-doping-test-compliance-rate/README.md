## 2. Definition

Within Sports Clubs & Leagues (Deep Dive), Anti-Doping Test Compliance Rate (ADTC) is used to gauge conformance to standards, plans, or obligations. The formula is Tests Completed per Testing Plan / Planned - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Sports sector.

## 3. Context

Measures completion of required testing - no-notice availability, whereabouts accuracy, testing participation. Anti-doping failures are existential for athletes and reputational for clubs, and missed tests count toward violations even without any positive sample. Whereabouts-filing discipline is the operational weak point, and travel schedules are the usual failure mode. Read with test-availability statistics and education program completion.

## Formula

```
Tests Completed per Testing Plan / Planned
```
