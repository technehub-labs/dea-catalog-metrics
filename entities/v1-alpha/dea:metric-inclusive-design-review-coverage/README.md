## 2. Definition

Inclusive Design Review Coverage (IDRC) addresses conformance to standards, plans, or obligations and is a fixture of ux & design systems reporting. It is computed as Features Passing Inclusive Design Review / Features, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Features Passing Inclusive Design Review / Features
```
