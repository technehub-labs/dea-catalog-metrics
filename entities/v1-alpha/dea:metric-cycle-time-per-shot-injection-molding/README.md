## 2. Definition

Cycle Time per Shot (Injection Molding) (CTPS) measures how efficiently resources are converted into outputs in the Packaging & Plastics domain. It is a working-level control: thresholds trigger immediate operational response. It is defined as Seconds per Molding Cycle; the result is stated in seconds. It should be driven down, since lower readings signal healthier performance. In Manufacturing, it is a recognized element of the standard performance toolkit.
