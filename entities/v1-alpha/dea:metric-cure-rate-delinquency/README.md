## 2. Definition

Cure Rate (Delinquency) (CRD-CC) measures the quality of outputs and outcomes in the Credit & Collections Risk (Enterprise) domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Delinquent Accounts Returning to Current / Delinquent Accounts, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Delinquent Accounts Returning to Current / Delinquent Accounts
```
