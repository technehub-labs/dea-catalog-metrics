## 2. Definition

Within Diversity, Equity & Inclusion (Deep Dive), Flexibility Program Utilization (FPU-DEI) is used to gauge the retention of customers, users, or assets over time. The formula is Employees Using Flexible Arrangements / Employees - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Employees Using Flexible Arrangements / Employees
```
