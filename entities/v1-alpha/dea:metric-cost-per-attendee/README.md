## 2. Definition

Cost per Attendee (CPA-E) measures how efficiently resources are converted into outputs in the Events & Exhibitions domain. It is defined as Total Event Cost / Attendees; the result is stated in currency value. In Media & Entertainment, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Total Event Cost / Attendees
```
