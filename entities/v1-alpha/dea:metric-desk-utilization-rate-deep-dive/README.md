## 2. Definition

A Facility Management & Workplace (Deep Dive) indicator, Desk Utilization Rate (Deep Dive) (DUR-D) quantifies the utilization or availability of capacity. It is computed as Days Desks Used / Days Desks Available, expressed in percent (%). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures share of desks in active use during occupied hours. Desk-level utilization exposes the mismatch between allocated real estate and hybrid work behavior - most portfolios run below half - and it is the direct input to consolidation economics. Peak versus average utilization determines how much space can safely be removed, so read peak-day distributions. Read with space utilization rate (Deep Dive) and collaboration-space availability ratios.

## Formula

```
Days Desks Used / Days Desks Available
```
