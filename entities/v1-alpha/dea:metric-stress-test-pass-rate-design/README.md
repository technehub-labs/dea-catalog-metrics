## 2. Definition

A Engineering & Design indicator, Stress Test Pass Rate (Design) (STPR) quantifies exposure to adverse outcomes. It is computed as Components Passing Stress Analysis / Components Assessed, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Components Passing Stress Analysis / Components Assessed
```
