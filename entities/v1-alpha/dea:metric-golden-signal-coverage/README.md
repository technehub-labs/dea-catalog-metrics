## 2. Definition

Golden Signal Coverage (GSC) measures capability maturity or development in the Observability & Site Reliability Engineering domain. Its calculation is Services with Latency, Traffic, Errors, Saturation Signals / Services, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Services with Latency, Traffic, Errors, Saturation Signals / Services
```
