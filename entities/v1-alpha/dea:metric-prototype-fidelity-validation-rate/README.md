## 2. Definition

Prototype Fidelity Validation Rate (PFVR) measures the quality of outputs and outcomes in the UX & Design Systems domain. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. The formula is Prototypes Validated with Users before Build / Prototypes - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Prototypes Validated with Users before Build / Prototypes
```
