## 2. Definition

A Balanced Scorecard - Financial Perspective indicator, Fixed Asset Turnover (Deep Dive) (FAT-D) quantifies how efficiently resources are converted into outputs. It is computed as Revenue / Net Fixed Assets, expressed in ratio (x:1 or x). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures revenue generated per unit of fixed assets. It exposes whether the asset base is sweating or bloating. Asset-light digital models make sector comparison essential. Read with return on capital employed and infrastructure utilization.

## Formula

```
Revenue / Net Fixed Assets
```
