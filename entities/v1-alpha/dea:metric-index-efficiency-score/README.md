## 2. Definition

A Database & Data Platform Operations indicator, Index Efficiency Score (IES-DB) quantifies how efficiently resources are converted into outputs. Its calculation is Queries Using Efficient Index Plans / Queries Sampled, measured in percent (%). It originates from and is most used in Software practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Queries Using Efficient Index Plans / Queries Sampled
```
