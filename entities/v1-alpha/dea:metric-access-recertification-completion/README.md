## 2. Definition

Access Recertification Completion (ARC-IC) measures conformance to standards, plans, or obligations in the Internal Controls & Financial Reporting Integrity domain. Its calculation is Access Reviews Completed by Due Date / Reviews, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
ARC-IC = Access Reviews Completed by Due Date / Reviews
```
