## 2. Definition

A Generative AI & LLM Operations indicator, Escalation Rate - LLM to Human (ERLH) quantifies how efficiently resources are converted into outputs. The formula is Conversations Escalated to Human / Conversations - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula
