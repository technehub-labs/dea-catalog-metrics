## 2. Definition

A Mobile & Client Development indicator, Device Compatibility Coverage (DCC-MOB) quantifies the quality of outputs and outcomes. It is computed as Tested Device-OS Combinations / Top Combinations in Use, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Software.

## Formula

```
Tested Device-OS Combinations / Top Combinations in Use
```
