## 2. Definition

Knowledge Base Coverage Ratio (KBCR-KM) measures capability maturity or development in the Knowledge Management (Deep Dive) domain. It is defined as Documented Answers for Recurring Questions / Recurring Questions; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Documented Answers for Recurring Questions / Recurring Questions
```
