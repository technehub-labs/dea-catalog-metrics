## 2. Definition

Secure Coding Standard Adoption (SCSA) measures capability maturity or development in the Application Security (AppSec) domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Teams Following Secure Coding Standard / Teams, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Software.

## Formula

```
Teams Following Secure Coding Standard / Teams
```
