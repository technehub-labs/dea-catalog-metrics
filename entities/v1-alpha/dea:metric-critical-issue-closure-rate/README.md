## 2. Definition

Critical Issue Closure Rate (CICR) addresses exposure to adverse outcomes and is a fixture of project risk & issue management reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Critical Issues Closed within SLA / Critical Issues, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
CICR = Critical Issues Closed within SLA / Critical Issues
```
