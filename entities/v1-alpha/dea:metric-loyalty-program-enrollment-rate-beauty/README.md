## 2. Definition

Loyalty Program Enrollment Rate (Beauty) (LPER-B) measures the retention of customers, users, or assets over time in the Beauty & Personal Care Services domain. The formula is Clients Enrolled / Eligible Clients - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Personal Services sector.

## Formula

```
Clients Enrolled / Eligible Clients
```
