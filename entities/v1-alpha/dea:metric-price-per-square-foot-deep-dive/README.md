## 2. Definition

Price per Square Foot (Deep Dive) (PPSFDD) addresses the economic value created or preserved and is a fixture of real estate & mortgage standard measures reporting. It is defined as Transaction Price / Leasable Area; the result is stated in currency per unit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. In Real estate, it is a recognized element of the standard performance toolkit.

## Formula

```
Transaction Price / Leasable Area
```
