## 2. Definition

Within Quality Management, Document Change Cycle Time (DCCT) is used to gauge how efficiently resources are converted into outputs. It is computed as Days from Change Request to Document Release, expressed in days. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Change Request to Document Release
```
