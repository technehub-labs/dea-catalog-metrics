## 2. Definition

A Contact Center Standard Measures (Deep Dive) indicator, Quality Monitoring Score (Contact Center) (QMDD) quantifies the quality of outputs and outcomes. Its calculation is Average Evaluation Score across Monitored Contacts, measured in score (points). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Average Evaluation Score across Monitored Contacts
```
