## 2. Definition

Horizon Scanning Coverage (HSC) measures capability maturity or development in the Regulatory Affairs & Compliance Operations domain. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Jurisdictions Monitored / Jurisdictions in Scope, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
HSC = Jurisdictions Monitored / Jurisdictions in Scope
```
