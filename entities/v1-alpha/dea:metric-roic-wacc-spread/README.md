## 2. Definition

Within Valuation & Corporate Finance Standard Measures, ROIC-WACC Spread (ROICWACCS) is used to gauge the economic value created or preserved. The formula is Return on Invested Capital minus WACC - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the gap between return on invested capital and its cost. The spread is the single cleanest value-creation measure: positive and growing is value creation, negative is destruction dressed as growth. Spread measured on unadjusted segment capital can mislead. Read with return on invested capital (Deep Dive) and economic value added (Standard Measure).

## Formula

```
Return on Invested Capital minus WACC
```
