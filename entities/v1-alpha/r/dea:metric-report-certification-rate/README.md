## 2. Definition

Report Certification Rate (RCR-DS) captures conformance to standards, plans, or obligations for organizations tracking data science & analytics operations. It is computed as Reports Certified by Governance / Reports Published, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
RCR-DS = Reports Certified by Governance / Reports Published
```
