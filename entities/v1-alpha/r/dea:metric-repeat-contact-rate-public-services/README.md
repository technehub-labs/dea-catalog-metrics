## 2. Definition

A Public Sector & Citizen Service Standard Measures (Deep Dive) indicator, Repeat Contact Rate (Public Services) (RCRPS) quantifies the quality of outputs and outcomes. Its calculation is Citizens Re-contacting within 30 Days / Contacts, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Lower values are better; each reduction is an improvement. It originates from and is most used in Public sector practice.

## Formula

```
RCRPS = Citizens Re-contacting within 30 Days / Contacts
```
