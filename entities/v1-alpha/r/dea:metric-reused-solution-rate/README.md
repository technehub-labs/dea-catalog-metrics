## 2. Definition

A Knowledge Management indicator, Reused Solution Rate (RSR-K) quantifies how efficiently resources are converted into outputs. The formula is Solutions Reused from Repository / Solutions Delivered - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of problems solved by reusing existing knowledge rather than reinventing. It matters because reuse is the compounding return of knowledge management. Reuse can be over-claimed by relabeling routine work as reuse. Read with Solution Development Cycle Time and Lessons Learned Capture Rate to confirm reuse delivers real acceleration.

## Formula

```
RSR-K = Solutions Reused from Repository / Solutions Delivered
```
