## 2. Definition

Rights Cost per Viewing Hour (RCPH) captures how efficiently resources are converted into outputs for organizations tracking media & entertainment. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Content Rights Cost / Total Viewing Hours; the result is stated in currency per unit. It should be driven down, since lower readings signal healthier performance. In Media & entertainment, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures content licensing cost per hour viewed. It matters because it is the fundamental efficiency ratio of streaming and broadcasting economics. Gaming risk includes front-loading views in launch windows while costs amortize over years, hiding long-tail economics. Read with Content Completion Rate and Subscriber Lifetime Value to confirm per-hour efficiency holds over the content lifecycle.

## Formula

```
RCPH = Content Rights Cost / Total Viewing Hours
```
