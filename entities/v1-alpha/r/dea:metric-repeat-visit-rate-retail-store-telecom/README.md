## 2. Definition

A Telecom Customer Experience & Billing indicator, Repeat Visit Rate (Retail Store Telecom) (RVR) quantifies the quality of outputs and outcomes. It is defined as Customers Returning to Store within Period for Same Issue / Store Visits; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. In Telecommunications, it is a recognized element of the standard performance toolkit.

## Formula

```
RVR = Customers Returning to Store within Period for Same Issue / Store Visits
```
