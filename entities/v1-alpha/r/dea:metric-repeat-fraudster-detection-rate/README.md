## 2. Definition

A Enterprise Fraud & Financial Crime Management indicator, Repeat Fraudster Detection Rate (RFDR) quantifies exposure to adverse outcomes. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Repeat Offenders Identified on Re-Attempt / Repeat Attempts, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
RFDR = Repeat Offenders Identified on Re-Attempt / Repeat Attempts
```
