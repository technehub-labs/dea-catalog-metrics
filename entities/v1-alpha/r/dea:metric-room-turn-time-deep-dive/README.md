## 2. Definition

Room Turn Time (Deep Dive) (RTT-D) captures how efficiently resources are converted into outputs for organizations tracking hotel & resort operations (deep dive). It is defined as Minutes to Clean and Inspect Departure Room; the result is stated in minutes. In Hospitality, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.
