## 2. Definition

Regrind Content Ratio (RCR-P) measures environmental and social sustainability performance in the Packaging & Plastics domain. Its calculation is Regrind Used / Total Resin Input, measured in percent (%). It originates from and is most used in Manufacturing practice. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula

```
RCR-P = Regrind Used / Total Resin Input
```
