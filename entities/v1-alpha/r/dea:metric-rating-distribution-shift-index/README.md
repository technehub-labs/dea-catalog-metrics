## 2. Definition

A Enterprise OKR & Performance Management indicator, Rating Distribution Shift Index (RDSI-OKR) quantifies the quality of outputs and outcomes. The formula is Change in Rating Distribution versus Prior Cycle - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Values outside the intended band, on either side, warrant investigation.

## Formula

```
RDSI-OKR = Change in Rating Distribution versus Prior Cycle
```
