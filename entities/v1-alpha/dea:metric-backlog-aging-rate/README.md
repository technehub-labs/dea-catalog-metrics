## 2. Definition

Backlog Aging Rate (BAG-AG) measures exposure to adverse outcomes in the Agile Delivery & Team Effectiveness domain. The formula is Backlog Items Older than Two Quarters / Backlog - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Backlog Items Older than Two Quarters / Backlog
```
