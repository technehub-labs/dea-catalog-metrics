## 2. Definition

BSC Target Attainment Rate (BTAR) addresses the economic value created or preserved and is a fixture of balanced scorecard implementation & review reporting. It is defined as Measures Meeting Target / Measures with Targets; the result is stated in percent (%). It is applied across virtually every sector. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of scorecard targets achieved in the period. Attainment is the execution scoreboard of the balanced scorecard system. Universally attained targets signal sandbagging; chronically missed ones signal disconnection from capability. Read with key result attainment average and strategy execution confidence index.

## Formula

```
BTAR = Measures Meeting Target / Measures with Targets
```
