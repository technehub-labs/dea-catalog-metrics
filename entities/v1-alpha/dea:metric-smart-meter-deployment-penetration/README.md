## 2. Definition

Smart Meter Deployment Penetration (SMDP) captures capability maturity or development for organizations tracking utilities field operations & grid. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is computed as Smart Meters Installed / Meter Points, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Utilities.

## 3. Context

Measures the share of endpoints with advanced metering infrastructure. Penetration unlocks the data foundation for loss reduction, demand response, outage detection, and dynamic pricing - most grid modernization benefits start here. Deployment pace matters less than enabled-use realization, so track benefits against meters installed. Read with grid losses ratio trends and demand response program delivery.

## Formula

```
Smart Meters Installed / Meter Points
```
