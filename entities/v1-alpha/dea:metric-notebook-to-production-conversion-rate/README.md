## 2. Definition

A Data Science & Analytics Operations indicator, Notebook-to-Production Conversion Rate (NTPCR) quantifies how efficiently resources are converted into outputs. The formula is Notebook Analyses Reaching Production / Analyses - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Notebook Analyses Reaching Production / Analyses
```
