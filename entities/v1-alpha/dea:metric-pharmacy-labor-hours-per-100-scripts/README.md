## 2. Definition

Pharmacy Labor Hours per 100 Scripts (PLH100) addresses how efficiently resources are converted into outputs and is a fixture of pharmacy retail reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Labor Hours / 100 Prescriptions; the result is stated in hours. It should be driven down, since lower readings signal healthier performance. In Healthcare, it is a recognized element of the standard performance toolkit.

## Formula

```
Labor Hours / 100 Prescriptions
```
