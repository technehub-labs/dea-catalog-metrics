## 2. Definition

A Insurance Underwriting indicator, Underwriting Leakage Rate (UWLR2) quantifies the quality of outputs and outcomes. It is defined as Premium Shortfalls from Rating Errors / Gross Premium; the result is stated in percent (%). In Insurance, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Premium Shortfalls from Rating Errors / Gross Premium
```
