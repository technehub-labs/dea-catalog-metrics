## 2. Definition

A Corporate Communications & PR (Deep Dive) indicator, Internal Communication Read Rate (ICRR-C) quantifies the engagement or satisfaction of the people involved. Its calculation is Employees Reading Announcements / Recipients, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Employees Reading Announcements / Recipients
```
