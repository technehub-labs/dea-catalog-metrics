## 2. Definition

Within Network Change & Configuration Management, Change Review Board Compliance (CRBC) is used to gauge conformance to standards, plans, or obligations. Its calculation is High-Risk Changes with CAB Approval / High-Risk Changes, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
High-Risk Changes with CAB Approval / High-Risk Changes
```
