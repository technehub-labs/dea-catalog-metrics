## 2. Definition

Net New ARR per Sales Rep (NNAR) addresses how efficiently resources are converted into outputs and is a fixture of unit economics & growth (deep dive) reporting. It is defined as Net New ARR / Quota-Carrying Reps; the result is stated in currency per unit. In Software, it is a recognized element of the standard performance toolkit. Its trend is watched by senior leadership as an early signal of structural performance shifts. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures new ARR added per quota-carrying rep. It is the productivity engine check on the go-to-market model. Reps counted including long ramp periods depress the average honestly; excluding them inflates. Read with quota attainment distribution and sales cycle length.

## Formula

```
Net New ARR / Quota-Carrying Reps
```
