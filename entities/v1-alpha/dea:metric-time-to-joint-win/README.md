## 2. Definition

A Alliances & Partnerships Management indicator, Time to Joint Win (TTJW) quantifies how efficiently resources are converted into outputs. It is defined as Days from Qualified Joint Opportunity to Closed Deal; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Qualified Joint Opportunity to Closed Deal
```
