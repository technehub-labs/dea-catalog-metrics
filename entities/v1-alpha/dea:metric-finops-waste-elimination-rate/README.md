## 2. Definition

FinOps Waste Elimination Rate (FWER) addresses how efficiently resources are converted into outputs and is a fixture of it financial management & technology budgeting reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Idle or Unused Resource Spend Eliminated / Identified, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Idle or Unused Resource Spend Eliminated / Identified
```
