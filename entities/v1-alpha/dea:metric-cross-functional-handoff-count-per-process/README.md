## 2. Definition

Cross-Functional Handoff Count per Process (CFHCP) addresses how efficiently resources are converted into outputs and is a fixture of operating model monitoring & design effectiveness reporting. The formula is Handoffs between Functions per Process - reported in count (items per period). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Handoffs between Functions per Process
```
