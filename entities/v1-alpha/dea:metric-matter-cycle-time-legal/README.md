## 2. Definition

Within Legal Operations, Matter Cycle Time (Legal) (MCT) is used to gauge how efficiently resources are converted into outputs. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Days from Matter Open to Close, expressed in days. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
MCT = Days from Matter Open to Close
```
