## 2. Definition

Velocity (VEL) measures the utilization or availability of capacity in the Software Engineering domain. Its calculation is Story Points Completed per Sprint, measured in count (items per period). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.
