## 2. Definition

Return to Work Rate after Long Absence (RTW) addresses the utilization or availability of capacity and is a fixture of employee wellbeing reporting. The formula is Employees Returned to Work / Long-Absence Cases Closed - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of employees on long absence successfully returning to work. It matters because sustainable returns are the true outcome of absence management. Returns can be rushed, with quick relapses counted as successes. Read with Sustained Retention 6-12 months post-return and Absence Rate trends to confirm returns stick.

## Formula

```
Employees Returned to Work / Long-Absence Cases Closed
```
