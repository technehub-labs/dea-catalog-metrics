## 2. Definition

Collaboration Tool Adoption Rate (CTAR) captures capability maturity or development for organizations tracking digital workplace & collaboration. It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. The formula is Active Users of Collaboration Platform / Licensed Users - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures active use of collaboration platforms relative to the entitled or target workforce. Adoption is the entry ticket for digital workplace value: collaboration value compounds with network effects, so partial adoption can yield near-zero benefit. Beware inflated metrics counting login-provisioned users as active; define active by meaningful contribution. Read with meeting hours per employee per week and channel-shift outcomes in project delivery.

## Formula

```
Active Users of Collaboration Platform / Licensed Users
```
