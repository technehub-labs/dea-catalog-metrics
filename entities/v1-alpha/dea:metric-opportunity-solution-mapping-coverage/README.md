## 2. Definition

Opportunity Solution Mapping Coverage (OSMC) captures capability maturity or development for organizations tracking requirements engineering & product discovery. It is defined as Key Outcomes with Mapped Opportunities / Key Outcomes; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Key Outcomes with Mapped Opportunities / Key Outcomes
```
