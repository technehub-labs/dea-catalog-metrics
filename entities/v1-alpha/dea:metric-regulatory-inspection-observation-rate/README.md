## 2. Definition

Within Pharma R&D & Clinical Trials, Regulatory Inspection Observation Rate (RIOR) is used to gauge exposure to adverse outcomes. It is defined as Inspection Observations per Inspection; the result is stated in count (items per period). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Pharmaceuticals, it is a recognized element of the standard performance toolkit.

## Formula

```
Inspection Observations per Inspection
```
