## 2. Definition

Defect Density per Release (DDPR-QA) addresses the quality of outputs and outcomes and is a fixture of software testing & quality engineering reporting. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Defects per Release, measured in count (items per period). It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.
