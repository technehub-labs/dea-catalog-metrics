## 2. Definition

Deliveries per Route Hour (Deep Dive) (DPH-D) captures how efficiently resources are converted into outputs for organizations tracking parcel & last-mile logistics (deep dive). It provides the day-to-day signal that a process is running as designed. Its calculation is Successful Deliveries / Route Hours, measured in count (items per period). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Logistics & Trade practice.

## Formula

```
Successful Deliveries / Route Hours
```
