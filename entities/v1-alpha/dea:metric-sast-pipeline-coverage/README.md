## 2. Definition

SAST Pipeline Coverage (SASTPC) measures conformance to standards, plans, or obligations in the Application Security (AppSec) domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Repositories with Static Analysis in Pipeline / Repositories, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Software practice.

## Formula

```
Repositories with Static Analysis in Pipeline / Repositories
```
