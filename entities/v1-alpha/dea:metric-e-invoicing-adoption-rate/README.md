## 2. Definition

e-Invoicing Adoption Rate (EIA) addresses how efficiently resources are converted into outputs and is a fixture of accounts payable & receivable operations (deep dive) reporting. It is computed as Invoices Received Electronically / Invoices, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Invoices Received Electronically / Invoices
```
