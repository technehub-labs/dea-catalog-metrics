## 2. Definition

E-Discovery Collection Cycle Time (EDCCT) measures how efficiently resources are converted into outputs in the Records & Information Management domain. Its calculation is Days from Legal Request to Data Collected, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Days from Legal Request to Data Collected
```
