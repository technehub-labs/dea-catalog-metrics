## 2. Definition

Within Beauty & Personal Care Services, Retail Attach Rate (Salon) (RAR-S) is used to gauge growth over time. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Clients Purchasing Products / Clients Served, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Its use is concentrated in Personal Services.

## Formula

```
Clients Purchasing Products / Clients Served
```
