## 2. Definition

Data Catalog Population Rate (DCPR-DG) addresses how efficiently resources are converted into outputs and is a fixture of data governance & stewardship reporting. It is computed as Curated Assets Documented in Catalog / In-Scope Assets, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Curated Assets Documented in Catalog / In-Scope Assets
```
