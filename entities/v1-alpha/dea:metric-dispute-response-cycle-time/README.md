## 2. Definition

Dispute Response Cycle Time (DRCT) measures how efficiently resources are converted into outputs in the Payments & Cards (Deep Dive) domain. It is computed as Days to Respond to Card Dispute, expressed in days. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is concentrated in Payments.

## Formula

```
Days to Respond to Card Dispute
```
