## 2. Definition

A Advertising & Media Buying indicator, Agency Fee-to-Media Ratio (AFMR) quantifies how efficiently resources are converted into outputs. The formula is Agency Fees / Gross Media Spend - reported in percent (%). It is a standard measure in the Media & Entertainment sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Values outside the intended band, on either side, warrant investigation.

## Formula

```
Agency Fees / Gross Media Spend
```
