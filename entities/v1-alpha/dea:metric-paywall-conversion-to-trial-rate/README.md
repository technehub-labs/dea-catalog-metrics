## 2. Definition

Paywall Conversion-to-Trial Rate (PCTR) measures growth over time in the Publishing & News Media domain. The formula is Trial Starts / Paywall Hits - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Media & Entertainment sector.

## Formula

```
Trial Starts / Paywall Hits
```
