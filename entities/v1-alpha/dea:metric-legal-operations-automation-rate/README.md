## 2. Definition

Legal Operations Automation Rate (LOAR) captures capability maturity or development for organizations tracking legal operations. It is defined as Workflows Automated / Total Workflows; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Workflows Automated / Total Workflows
```
