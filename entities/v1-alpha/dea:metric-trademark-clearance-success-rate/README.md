## 2. Definition

Trademark Clearance Success Rate (TCSR) measures the quality of outputs and outcomes in the Intellectual Property & Licensing domain. It is defined as Marks Cleared without Opposition / Marks Filed; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Marks Cleared without Opposition / Marks Filed
```
