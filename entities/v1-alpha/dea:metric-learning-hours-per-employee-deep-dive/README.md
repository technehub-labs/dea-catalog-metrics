## 2. Definition

Within Learning & Development Effectiveness (Deep Dive), Learning Hours per Employee (Deep Dive) (LHPEDD) is used to gauge capability maturity or development. Its calculation is Total Learning Hours / Employees, measured in hours. It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. Values outside the intended band, on either side, warrant investigation.

## Formula
