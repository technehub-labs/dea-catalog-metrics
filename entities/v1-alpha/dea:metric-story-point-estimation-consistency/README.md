## 2. Definition

Story Point Estimation Consistency (SPEC-AG) captures the quality of outputs and outcomes for organizations tracking agile delivery & team effectiveness. It is computed as Estimation Variance across Similar Stories, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Estimation Variance across Similar Stories
```
