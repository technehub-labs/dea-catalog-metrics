## 2. Definition

Within PMO & Portfolio Governance, Portfolio Dashboard Currency (PMO) (PDC) is used to gauge governance. It is defined as Initiatives with Status Updated in Last Period / Initiatives; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Initiatives with Status Updated in Last Period / Initiatives
```
