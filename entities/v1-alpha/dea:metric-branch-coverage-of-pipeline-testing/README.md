## 2. Definition

Branch Coverage of Pipeline Testing (BCPT) measures conformance to standards, plans, or obligations in the Continuous Integration domain. Its calculation is Branches with Automated Verification before Merge / Branches, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Branches with Automated Verification before Merge / Branches
```
