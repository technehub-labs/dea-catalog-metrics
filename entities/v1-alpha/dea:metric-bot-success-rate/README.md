## 2. Definition

Bot Success Rate (BSR-A) measures the quality of outputs and outcomes in the Automation & Robotic Process Automation domain. It is computed as Bot Executions without Exception / Bot Executions, expressed in percent (%). It is applied across virtually every sector. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Bot Executions without Exception / Bot Executions
```
