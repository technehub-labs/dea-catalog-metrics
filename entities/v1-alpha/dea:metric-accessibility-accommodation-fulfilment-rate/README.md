## 2. Definition

Accessibility Accommodation Fulfilment Rate (AAFR) captures conformance to standards, plans, or obligations for organizations tracking diversity, equity & inclusion (deep dive). It is computed as Workplace Accommodations Delivered within SLA / Requests, expressed in percent (%). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Workplace Accommodations Delivered within SLA / Requests
```
