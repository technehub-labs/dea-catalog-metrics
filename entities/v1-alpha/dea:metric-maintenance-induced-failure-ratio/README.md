## 2. Definition

Maintenance-Induced Failure Ratio (MIFR) measures the quality of outputs and outcomes in the Reliability & Maintainability Engineering (Deep Dive) domain. The formula is Failures Attributable to Maintenance Error / Failures - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Failures Attributable to Maintenance Error / Failures
```
