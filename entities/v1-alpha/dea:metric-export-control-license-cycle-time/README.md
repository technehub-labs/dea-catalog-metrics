## 2. Definition

Within International Trade & Customs, Export Control License Cycle Time (ECLC) is used to gauge how efficiently resources are converted into outputs. Its calculation is Days from License Application to Grant, measured in days. Its value drives prioritization and resource reallocation among competing initiatives. Lower values are better; each reduction is an improvement. It originates from and is most used in Logistics & Trade practice.
