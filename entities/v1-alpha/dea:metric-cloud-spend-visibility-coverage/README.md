## 2. Definition

Cloud Spend Visibility Coverage (CSVC-ITFM) captures the quality of outputs and outcomes for organizations tracking it financial management & technology budgeting. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Tagged and Allocated Cloud Spend / Total Cloud Spend, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Tagged and Allocated Cloud Spend / Total Cloud Spend
```
