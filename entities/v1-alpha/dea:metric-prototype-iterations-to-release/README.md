## 2. Definition

Prototype Iterations to Release (PITR) measures how efficiently resources are converted into outputs in the Engineering & Design domain. It is computed as Prototype Cycles before Design Freeze, expressed in count (items per period). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula
