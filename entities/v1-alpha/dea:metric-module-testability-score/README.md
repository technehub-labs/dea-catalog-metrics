## 2. Definition

Within Code Quality & Static Analysis, Module Testability Score (MTS-CQ) is used to gauge the quality of outputs and outcomes. It is computed as Rubric of Seam Quality and Dependency Injection Readiness, expressed in score (points). Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Software.
