## 2. Definition

Within Application Security (AppSec), Penetration Test Finding Closure Rate (PTFCR) is used to gauge conformance to standards, plans, or obligations. Its calculation is Pentest Findings Remediated / Findings, measured in percent (%). Its value drives prioritization and resource reallocation among competing initiatives. Higher values are better; gains are read as improvement and losses as deterioration. It originates from and is most used in Software practice.

## Formula

```
Pentest Findings Remediated / Findings
```
