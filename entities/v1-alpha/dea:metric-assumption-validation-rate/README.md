## 2. Definition

Assumption Validation Rate (AVR-RE) measures exposure to adverse outcomes in the Requirements Engineering & Product Discovery domain. It is computed as Assumptions Tested in Discovery / Identified Assumptions, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Assumptions Tested in Discovery / Identified Assumptions
```
