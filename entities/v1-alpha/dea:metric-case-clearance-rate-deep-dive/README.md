## 2. Definition

A Public Sector & Citizen Service Standard Measures (Deep Dive) indicator, Case Clearance Rate (Deep Dive) (CCRD) quantifies how efficiently resources are converted into outputs. It provides the day-to-day signal that a process is running as designed. Its calculation is Cases Closed / Cases Received, measured in ratio (x:1 or x). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Public sector practice.

## Formula

```
Cases Closed / Cases Received
```
