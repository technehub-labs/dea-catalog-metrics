## 2. Definition

Change Impact Assessment Coverage (CIAC) measures conformance to standards, plans, or obligations in the Change Management domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Changes with Documented Impact Assessment / Changes Approved; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of changes with completed impact assessments. It matters because unassessed changes hit people and processes cold. Coverage can be met with templated assessments that name no real impacts. Read with Change-Driven Productivity Dip Duration and incident upticks post-change to confirm assessments were substantive.

## Formula

```
Changes with Documented Impact Assessment / Changes Approved
```
