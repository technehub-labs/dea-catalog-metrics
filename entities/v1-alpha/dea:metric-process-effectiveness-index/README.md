## 2. Definition

Within Balanced Scorecard - Internal Process Perspective, Process Effectiveness Index (PEI-BSC) is used to gauge how effectively a process or entity achieves its intended outcome. The formula is Composite Process Performance Score - reported in index (0-100 or normalized). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures aggregate performance of core processes against defined performance standards. The index converts scattered process metrics into one strategic signal for scorecard review. Composite indexes can hide deteriorating processes behind improving ones. Read with process first-pass yield trend and process cycle time trend.

Composite Process Performance Score
