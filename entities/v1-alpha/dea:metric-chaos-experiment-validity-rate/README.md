## 2. Definition

Within SRE & Observability Standard Measures, Chaos Experiment Validity Rate (CEVR) is used to gauge the quality of outputs and outcomes. The formula is Experiments Producing Actionable Resilience Findings / Experiments - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. It is a standard measure in the Software sector.

## Formula

```
Experiments Producing Actionable Resilience Findings / Experiments
```
