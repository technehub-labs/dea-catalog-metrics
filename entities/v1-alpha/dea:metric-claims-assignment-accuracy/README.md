## 2. Definition

A Insurance Claims Deep Dive indicator, Claims Assignment Accuracy (CLA) quantifies the quality of outputs and outcomes. The formula is Claims Correctly Assigned on Intake / Claims Assigned - reported in percent (%). It is a standard measure in the Insurance sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Claims Correctly Assigned on Intake / Claims Assigned
```
