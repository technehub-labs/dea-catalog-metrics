## 2. Definition

Strategic Alignment Score - Initiatives (SASI-PPM) measures strategy in the Program & Portfolio Management domain. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Initiatives Mapped to Strategic Objectives / Initiatives, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how well each initiative demonstrably supports declared strategic objectives. Misalignment wastes spend and, worse, consumes the scarcest resources. Self-scored alignment without objective mapping tends to flatter. Read with portfolio investment mix balance and strategic initiative funding fulfilment.

## Formula

```
Initiatives Mapped to Strategic Objectives / Initiatives
```
