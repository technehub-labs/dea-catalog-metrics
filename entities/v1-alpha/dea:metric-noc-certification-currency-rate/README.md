## 2. Definition

NOC Certification Currency Rate (NCCR) captures capability maturity or development for organizations tracking network operations center (deep dive). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Engineers with Current Certifications / Engineers - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Engineers with Current Certifications / Engineers
```
