## 2. Definition

A Utilities Customer Operations indicator, First Contact Resolution (Utilities) (FCR-U) quantifies the quality of outputs and outcomes. The formula is Requests Resolved on First Contact / Requests - reported in percent (%). It is a standard measure in the Utilities sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Requests Resolved on First Contact / Requests
```
