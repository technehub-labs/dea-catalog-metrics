## 2. Definition

Right First Time - Sewing (Deep Dive) (RFT-S) captures the quality of outputs and outcomes for organizations tracking textile & apparel (deep dive). It is defined as Garments Passing without Repair / Garments; the result is stated in percent (%). In Textiles & Apparel, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Garments Passing without Repair / Garments
```
