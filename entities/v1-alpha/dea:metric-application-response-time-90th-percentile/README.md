## 2. Definition

Within ERP & Enterprise Application Operations, Application Response Time - 90th Percentile (ART90) is used to gauge the quality of outputs and outcomes. The formula is 90th Percentile Transaction Time - reported in seconds. It is applied across virtually every sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Reduction is the goal, and sustained decreases indicate successful intervention.
