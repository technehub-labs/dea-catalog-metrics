## 2. Definition

A Retail Standard Measures indicator, Sell-Through Rate (Retail) (STR-RT) quantifies how efficiently resources are converted into outputs. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Units Sold / (Units Sold + Ending Inventory); the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Retail & E-commerce, it is a recognized element of the standard performance toolkit.

## Formula

```
Units Sold / (Units Sold + Ending Inventory)
```
