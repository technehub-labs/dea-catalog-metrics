## 2. Definition

Material Waste Rate (Construction) (MWR) addresses how efficiently resources are converted into outputs and is a fixture of construction & engineering reporting. Its calculation is Wasted Material Value / Material Value Ordered, measured in percent (%). It originates from and is most used in Construction & engineering practice. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Wasted Material Value / Material Value Ordered
```
