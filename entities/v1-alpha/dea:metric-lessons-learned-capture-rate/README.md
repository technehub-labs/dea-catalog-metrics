## 2. Definition

Lessons Learned Capture Rate (LLCR) captures capability maturity or development for organizations tracking project management. It is defined as Projects Recording Lessons Learned / Projects Closed; the result is stated in percent (%). It is applied across virtually every sector. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of projects that formally capture and share lessons learned. It matters because organizations that skip this repeat every failure at full price. Gaming risk includes boilerplate lessons recorded but never distributed or applied. Read with Process Improvement implementation rates and repeat-issue frequency to confirm captured lessons change behavior.

## Formula

```
Projects Recording Lessons Learned / Projects Closed
```
