## 2. Definition

BSC Measure Currency (BSMC) addresses the quality of outputs and outcomes and is a fixture of balanced scorecard implementation & review reporting. Its calculation is Measures Refreshed in Period / Measures in Use, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Measures Refreshed in Period / Measures in Use
```
