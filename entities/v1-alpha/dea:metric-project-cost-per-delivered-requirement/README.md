## 2. Definition

Project Cost per Delivered Requirement (PCPDR) measures how efficiently resources are converted into outputs in the Project Management (Deep Dive) domain. It is defined as Project Cost / Delivered Requirements; the result is stated in currency value. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Project Cost / Delivered Requirements
```
