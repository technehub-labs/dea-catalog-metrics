## 2. Definition

Look-to-Book Ratio (L2B) addresses how effectively a process or entity achieves its intended outcome and is a fixture of travel & tourism reporting. It is defined as Bookings / Search or Quote Requests; the result is stated in ratio (x:1 or x). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Travel & tourism, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures bookings relative to searches or lookups. It matters because it diagnoses whether the funnel fails at offer, price, or trust. It can be gamed by narrowing counted searches to high-intent ones. Read with Booking Conversion Rate (Travel) and Search Abandonment reasons to interpret the funnel honestly.

## Formula

```
Bookings / Search or Quote Requests
```
