## 2. Definition

A Customer indicator, Customer Support Cost per Contact (CSC) quantifies how efficiently resources are converted into outputs. Its calculation is Total Support Cost / Total Support Contacts, measured in currency per unit. It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Total Support Cost / Total Support Contacts
```
