## 2. Definition

Client Site Audit Score (Security) (CSAS-S) captures the quality of outputs and outcomes for organizations tracking security services & guarding. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Composite Client Audit Score; the result is stated in score (points). Improvement means raising this figure toward best-in-class levels. In Security, it is a recognized element of the standard performance toolkit.
