## 2. Definition

Sponsorship Activation Delivery Rate (SADR-S) measures conformance to standards, plans, or obligations in the Sports Clubs & Leagues (Deep Dive) domain. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Contracted Assets Delivered / Contracted; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Sports, it is a recognized element of the standard performance toolkit.

## Formula

```
SADR-S = Contracted Assets Delivered / Contracted
```
