## 2. Definition

A Construction Contracting (Deep Dive) indicator, Site Labor Productivity Index (Deep Dive) (SLPI-D) quantifies how efficiently resources are converted into outputs. It is computed as Earned Standard Hours / Actual Hours, expressed in ratio (x:1 or x). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Construction.

## Formula

```
SLPI-D = Earned Standard Hours / Actual Hours
```
