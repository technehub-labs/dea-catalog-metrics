## 2. Definition

Seed Germination Rate (Deep Dive) (SGR-D) addresses the quality of outputs and outcomes and is a fixture of agriculture & agronomy (deep dive) reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Established Plants / Seeds Sown, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Agriculture practice.

## Formula

```
SGR-D = Established Plants / Seeds Sown
```
