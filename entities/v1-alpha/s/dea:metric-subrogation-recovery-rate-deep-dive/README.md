## 2. Definition

Subrogation Recovery Rate (Deep Dive) (SRR-D) addresses the economic value created or preserved and is a fixture of insurance claims deep dive reporting. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Recovered via Subrogation / Recoverable Opportunities - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Insurance sector.

## Formula

```
SRR-D = Recovered via Subrogation / Recoverable Opportunities
```
