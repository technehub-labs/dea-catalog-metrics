## 2. Definition

A Pharmacy Retail indicator, Script Complement Rate - OTC Attach (SCR-O) quantifies growth over time. It provides the day-to-day signal that a process is running as designed. Its calculation is OTC Recommendations Accepted / Offered, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Healthcare practice.

## Formula

```
SCR-O = OTC Recommendations Accepted / Offered
```
