## 2. Definition

Session Check-in Accuracy (SCIA) addresses the quality of outputs and outcomes and is a fixture of events & exhibitions reporting. Its calculation is Checked-in Sessions Matching Registrations / Sessions, measured in percent (%). It originates from and is most used in Media & Entertainment practice. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
SCIA = Checked-in Sessions Matching Registrations / Sessions
```
