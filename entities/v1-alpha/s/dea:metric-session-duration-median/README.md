## 2. Definition

A Web & Digital Analytics Standard Measures indicator, Session Duration (Median) (SESDUR) quantifies the engagement or satisfaction of the people involved. Its calculation is Median Time on Site per Session, measured in minutes. It provides the day-to-day signal that a process is running as designed. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. It originates from and is most used in Digital product practice.

## Formula

```
SESDUR = Median Time on Site per Session
```
