## 2. Definition

A Agile Delivery & Team Effectiveness indicator, Sprint Predictability Ratio (SPR-AG) quantifies conformance to standards, plans, or obligations. It is computed as Committed versus Completed Story Points / Committed, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Values outside the intended band, on either side, warrant investigation.

## Formula

```
SPR-AG = Committed versus Completed Story Points / Committed
```
