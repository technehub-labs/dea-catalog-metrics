## 2. Definition

Shade Continuity Compliance (SCC-T) captures the quality of outputs and outcomes for organizations tracking textile & apparel (deep dive). It is a working-level control: thresholds trigger immediate operational response. It is defined as Rolls Matched for Shade within Tolerance / Rolls; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Textiles & Apparel, it is a recognized element of the standard performance toolkit.

## Formula

```
SCC-T = Rolls Matched for Shade within Tolerance / Rolls
```
