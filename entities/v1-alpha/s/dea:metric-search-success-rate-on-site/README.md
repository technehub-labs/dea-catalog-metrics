## 2. Definition

Search Success Rate (On-Site) (SSR-W) addresses how effectively a process or entity achieves its intended outcome and is a fixture of digital product & web operations reporting. Its calculation is Searches Leading to Result Click / Total Searches, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
SSR-W = Searches Leading to Result Click / Total Searches
```
