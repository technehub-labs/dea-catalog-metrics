## 2. Definition

A Network Change & Configuration Management indicator, Standard Change Pre-Approval Ratio (SCPR) quantifies how efficiently resources are converted into outputs. Its value drives prioritization and resource reallocation among competing initiatives. Its calculation is Change Types Pre-Approved as Standard / Change Types, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
SCPR = Change Types Pre-Approved as Standard / Change Types
```
