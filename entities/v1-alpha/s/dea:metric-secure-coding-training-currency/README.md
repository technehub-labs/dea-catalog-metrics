## 2. Definition

Secure Coding Training Currency (SCTC-DSO) addresses capability maturity or development and is a fixture of devsecops & application security engineering reporting. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Engineers with Current Security Training / Engineers, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
SCTC-DSO = Engineers with Current Security Training / Engineers
```
