## 2. Definition

A IT Financial Management & Technology Budgeting indicator, Software License True-up Variance (SLTV-ITFM) quantifies exposure to adverse outcomes. The formula is True-Up Payment vs Estimated Liability / Estimate - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
SLTV-ITFM = True-Up Payment vs Estimated Liability / Estimate
```
