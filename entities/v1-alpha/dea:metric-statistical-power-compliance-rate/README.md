## 2. Definition

A Data Science & Analytics Operations indicator, Statistical Power Compliance Rate (SPCR) quantifies the quality of outputs and outcomes. Its calculation is Tests Meeting Minimum Power Requirement / Tests, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Tests Meeting Minimum Power Requirement / Tests
```
