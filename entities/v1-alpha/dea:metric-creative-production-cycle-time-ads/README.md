## 2. Definition

Creative Production Cycle Time (Ads) (CPCT-A) measures how efficiently resources are converted into outputs in the Advertising & Media Buying domain. It is computed as Days from Brief to Finished Creative, expressed in days. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. Lower values are better; each reduction is an improvement. Its use is concentrated in Media & Entertainment.

## Formula

```
Days from Brief to Finished Creative
```
