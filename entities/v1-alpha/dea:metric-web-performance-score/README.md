## 2. Definition

Within Digital Product & Web Operations, Web Performance Score (WPS) is used to gauge the quality of outputs and outcomes. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Composite Score of Core Web Vitals Measurements, expressed in score (points). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures composite site speed and rendering quality (such as Core Web Vitals). It matters because performance directly drives conversion and search ranking. Scores can be gamed by optimizing only the URLs that crawlers test while real journeys lag. Read with Page Load Time on real-user monitoring and Conversion Rate (Retail) to confirm performance is customer-felt.

## Formula

```
Composite Score of Core Web Vitals Measurements
```
