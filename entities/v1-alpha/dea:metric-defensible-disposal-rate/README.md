## 2. Definition

Defensible Disposal Rate (DDR) captures conformance to standards, plans, or obligations for organizations tracking records & information management. It is reviewed at cadence by planning owners to correct course before issues become strategic. It is computed as Disposals with Documented Approval and Certificate / Disposals, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Disposals with Documented Approval and Certificate / Disposals
```
