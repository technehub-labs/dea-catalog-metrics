## 2. Definition

Within Insurance Distribution & Agency Management, New Agency Recruitment Ramp Time (NARR) is used to gauge how efficiently resources are converted into outputs. It is defined as Days from Appointment to First Bound Policy; the result is stated in days. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Lower values are better; each reduction is an improvement. In Insurance, it is a recognized element of the standard performance toolkit.

## Formula

```
NARR = Days from Appointment to First Bound Policy
```
