## 2. Definition

Net Effective Rent Ratio (NERR) addresses the economic value created or preserved and is a fixture of real estate & mortgage standard measures reporting. Its trend is watched by senior leadership as an early signal of structural performance shifts. It is defined as Net Effective Rent after Concessions / Face Rent; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Real estate, it is a recognized element of the standard performance toolkit.

## 3. Context

Measures achieved rent net of concessions relative to face rent. It is the honesty check on headline leasing performance. Long free-rent periods make face rent marketing, not economics. Read with cash-on-cash return and tenant retention rate (Real Estate).

## Formula

```
NERR = Net Effective Rent after Concessions / Face Rent
```
