## 2. Definition

A Construction Contracting (Deep Dive) indicator, Submittal Approval Cycle Time (Deep Dive) (SACT-C) quantifies how efficiently resources are converted into outputs. It is defined as Days from Submittal to Approval; the result is stated in days. In Construction, it is a recognized element of the standard performance toolkit. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Reduction is the goal, and sustained decreases indicate successful intervention.
