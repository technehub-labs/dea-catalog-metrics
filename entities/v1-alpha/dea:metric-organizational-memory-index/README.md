## 2. Definition

Within Knowledge Management (Deep Dive), Organizational Memory Index (OMI) is used to gauge capability maturity or development. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Rubric of Preserved Institutional Knowledge across Functions, measured in index (0-100 or normalized). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how well the organization retains and accesses what it has learned. Memory is what stops re-learning and re-failing. Indexes counting repository size rather than retrieval success measure storage, not memory. Read with knowledge base contribution rate and lessons learned reuse rate.
