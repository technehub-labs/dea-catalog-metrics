## 2. Definition

A Operating Model & Decision Effectiveness indicator, RACI Clarity Index (RACI) quantifies capability maturity or development. The formula is Decisions with Clear Accountability / Decisions Mapped - reported in percent (%). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the share of key decisions and processes with unambiguous, agreed ownership. It matters because unclear accountability is the root cause of slow, contested decisions. Clarity can be scored on documented RACIs that nobody follows in practice. Read with Decision Latency and Escalation Rate to Executive to confirm clarity is behavioral, not just documented.

## Formula

```
Decisions with Clear Accountability / Decisions Mapped
```
