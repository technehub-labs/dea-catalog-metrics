## 2. Definition

Within Talent Acquisition Deep Dive, Cost per Hire (Deep Dive) (CPHDD) is used to gauge how efficiently resources are converted into outputs. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Total Acquisition Cost / Hires - reported in currency per unit. It should be driven down, since lower readings signal healthier performance. Practitioners in nearly any industry can adopt it directly.

## Formula

```
CPHDD = Total Acquisition Cost / Hires
```
