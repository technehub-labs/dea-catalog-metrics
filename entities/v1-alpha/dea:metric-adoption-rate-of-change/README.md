## 2. Definition

Adoption Rate of Change (ARC) captures how effectively a process or entity achieves its intended outcome for organizations tracking change management. Its calculation is Target Users Adopting Changed Process or System / Target Users, measured in percent (%). It is applied across virtually every sector. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures the share of the affected population actually using the new process, system, or behavior as designed. It is the first real-world test of change management and the point where many programs quietly fail while reporting green. Define adoption operationally - usage frequency, quality of use, workarounds abandoned - not merely access provisioned. Read with sustained adoption at 90 Days and post-implementation benefit confirmation.

## Formula

```
Target Users Adopting Changed Process or System / Target Users
```
