## 2. Definition

Cement Strength Compliance Rate (CSCR-C) captures the quality of outputs and outcomes for organizations tracking cement & building materials. It is computed as Tests Meeting Strength Spec / Tests, expressed in percent (%). Its use is concentrated in Manufacturing. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Tests Meeting Strength Spec / Tests
```
