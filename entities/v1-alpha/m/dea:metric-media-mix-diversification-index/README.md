## 2. Definition

Media Mix Diversification Index (MMDI) addresses exposure to adverse outcomes and is a fixture of advertising & media buying reporting. The formula is Spend Concentration across Channels (Herfindahl-based) - reported in index (0-100 or normalized). It is a standard measure in the Media & Entertainment sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Values outside the intended band, on either side, warrant investigation.

## Formula

```
MMDI = Spend Concentration across Channels (Herfindahl-based)
```
