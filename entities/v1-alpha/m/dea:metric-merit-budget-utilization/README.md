## 2. Definition

Merit Budget Utilization (MBU-PAY) captures conformance to standards, plans, or obligations for organizations tracking standard workforce & pay metrics. It is computed as Merit Increases Awarded / Merit Budget, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. Values outside the intended band, on either side, warrant investigation.

## Formula

```
MBU-PAY = Merit Increases Awarded / Merit Budget
```
