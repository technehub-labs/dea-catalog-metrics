## 2. Definition

Within Reliability & Maintainability Engineering (Deep Dive), Maintainability M(t) (MTAIN) is used to gauge the quality of outputs and outcomes. It provides the day-to-day signal that a process is running as designed. Its calculation is Probability Repair Completed within Time t, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
MTAIN = Probability Repair Completed within Time t
```
