## 2. Definition

Measure Rationalization Rate (MRR-BSC) captures how efficiently resources are converted into outputs for organizations tracking balanced scorecard implementation & review. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Redundant Measures Retired / Measures Flagged; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
MRR-BSC = Redundant Measures Retired / Measures Flagged
```
