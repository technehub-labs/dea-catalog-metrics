## 2. Definition

Within Agriculture & Agronomy (Deep Dive), Milk Yield per Cow per Day (Deep Dive) (MYCD) is used to gauge how effectively a process or entity achieves its intended outcome. It is computed as Litres / Cow / Day, expressed in kilolitres (kl). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Agriculture.

## Formula
