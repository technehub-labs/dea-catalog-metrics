## 2. Definition

Wasted Spend Rate (Invalid Traffic) (WSRIVT) addresses how efficiently resources are converted into outputs and is a fixture of marketing & advertising standard measures (deep dive) reporting. Its calculation is Spend on Invalid Traffic / Total Spend, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. Reduction is the goal, and sustained decreases indicate successful intervention.

## Formula

```
Spend on Invalid Traffic / Total Spend
```
