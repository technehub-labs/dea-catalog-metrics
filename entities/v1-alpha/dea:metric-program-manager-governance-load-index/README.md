## 2. Definition

A Program & Portfolio Management indicator, Program Manager Governance Load Index (PMGLI) quantifies how efficiently resources are converted into outputs. The formula is Governance Hours per Program Manager per Week - reported in hours. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Governance Hours per Program Manager per Week
```
