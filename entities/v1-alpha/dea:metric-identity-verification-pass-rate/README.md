## 2. Definition

A Enterprise Fraud & Financial Crime Management indicator, Identity Verification Pass Rate (IVPR) quantifies the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Transactions Passing Step-Up Verification / Challenged Transactions; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
IVPR = Transactions Passing Step-Up Verification / Challenged Transactions
```
