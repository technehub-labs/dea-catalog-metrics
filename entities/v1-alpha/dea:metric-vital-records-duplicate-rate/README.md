## 2. Definition

Vital Records Duplicate Rate (VRDR) captures exposure to adverse outcomes for organizations tracking records & information management. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Vital Records with Verified Duplicate Copies / Vital Records - reported in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Vital Records with Verified Duplicate Copies / Vital Records
```
