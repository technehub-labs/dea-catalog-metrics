## 2. Definition

Reagent Consumption Ratio (RCR-M) addresses how efficiently resources are converted into outputs and is a fixture of metals & mining operations (deep dive) reporting. It is a working-level control: thresholds trigger immediate operational response. It is defined as Actual Reagent Use vs Plan / Plan; the result is stated in percent (%). The objective is neither maximization nor minimization but staying within an agreed operating band. In Metals & Mining, it is a recognized element of the standard performance toolkit.

## Formula

```
Actual Reagent Use vs Plan / Plan
```
