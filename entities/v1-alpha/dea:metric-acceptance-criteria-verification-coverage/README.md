## 2. Definition

Acceptance Criteria Verification Coverage (ACVC-QA) addresses conformance to standards, plans, or obligations and is a fixture of software testing & quality engineering reporting. It provides the day-to-day signal that a process is running as designed. Its calculation is Acceptance Criteria Verified by Tests / Criteria, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
ACVC-QA = Acceptance Criteria Verified by Tests / Criteria
```
