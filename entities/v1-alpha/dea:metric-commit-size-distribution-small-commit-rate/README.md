## 2. Definition

Commit Size Distribution - Small Commit Rate (CSD-SD) measures the quality of outputs and outcomes in the Software Development - Coding & Engineering Practices domain. The formula is Commits within Size Guideline / Commits - reported in percent (%). It is monitored close to the work: teams act on it within a shift, sprint, or daily review. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Commits within Size Guideline / Commits
```
