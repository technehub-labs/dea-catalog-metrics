## 2. Definition

A Data Governance & Stewardship indicator, Data Steward Coverage Ratio (DSCR) quantifies governance. Its calculation is Systems with Assigned Stewards / Systems, measured in percent (%). It is applied across virtually every sector. Its value drives prioritization and resource reallocation among competing initiatives. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
DSCR = Systems with Assigned Stewards / Systems
```
