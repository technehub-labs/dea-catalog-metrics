## 2. Definition

Within Field Maintenance & Technical Field Service (Deep Dive), Asset Data Capture Compliance - Field (ADCC-F) is used to gauge the quality of outputs and outcomes. Front-line and delivery teams watch it in real time, as small deviations demand immediate correction. It is computed as Visits with Complete Asset Condition Data / Visits, expressed in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Visits with Complete Asset Condition Data / Visits
```
