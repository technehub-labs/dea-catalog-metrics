## 2. Definition

Search Success Rate (Intranet) (SSR-I) measures the quality of outputs and outcomes in the Digital Workplace & Collaboration domain. Its calculation is Searches Resulting in Click / Searches, measured in percent (%). It provides the day-to-day signal that a process is running as designed. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Searches Resulting in Click / Searches
```
