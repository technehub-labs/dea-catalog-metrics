## 2. Definition

Chemical Recovery Efficiency (Kraft) (CREK) captures how efficiently resources are converted into outputs for organizations tracking pulp, paper & forest products. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Chemicals Recovered / Chemicals Used - reported in percent (%). Improvement means raising this figure toward best-in-class levels. It is a standard measure in the Manufacturing sector.

## Formula

```
Chemicals Recovered / Chemicals Used
```
