## 2. Definition

A Metals & Mining Operations (Deep Dive) indicator, Camp Turnover Rate (Remote Operations) (CTR-M) quantifies the engagement or satisfaction of the people involved. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Workers Exiting Early / Workers Deployed - reported in percent (%). It should be driven down, since lower readings signal healthier performance. It is a standard measure in the Metals & Mining sector.

## Formula

```
Workers Exiting Early / Workers Deployed
```
