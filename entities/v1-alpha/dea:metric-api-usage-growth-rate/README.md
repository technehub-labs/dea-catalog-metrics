## 2. Definition

API Usage Growth Rate (AUGR) captures growth over time for organizations tracking software product operations (deep dive). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Change in API Calls Period over Period; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Technology, it is a recognized element of the standard performance toolkit.

## Formula

```
Change in API Calls Period over Period
```
