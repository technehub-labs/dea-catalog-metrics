## 2. Definition

A Balanced Scorecard - Financial Perspective indicator, Debt to Equity (Deep Dive) (DTE-D) quantifies exposure to adverse outcomes. It is computed as Total Debt / Total Equity, expressed in ratio (x:1 or x). It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It is managed toward a defined target band rather than an extreme - both overshoot and undershoot can signal problems. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures the balance of borrowed funds to shareholder equity in the capital structure. Leverage amplifies both returns and fragility, so the right level is strategy- and sector-specific. Book equity distortions (buybacks, intangibles) make market-value versions more honest. Read with interest coverage ratio and credit rating trend.

## Formula

```
Total Debt / Total Equity
```
