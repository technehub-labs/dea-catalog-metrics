## 2. Definition

Labor Cost per Guest (Deep Dive) (LCPG-D) captures how efficiently resources are converted into outputs for organizations tracking restaurant operations (deep dive). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. The formula is Labor Cost / Guests - reported in currency per unit. It should be driven down, since lower readings signal healthier performance. It is a standard measure in the Restaurants sector.

## Formula

```
Labor Cost / Guests
```
