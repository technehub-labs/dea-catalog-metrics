## 2. Definition

Return on Capital Employed (Deep Dive) (ROCE-D) captures the economic value created or preserved for organizations tracking balanced scorecard - financial perspective. The formula is EBIT / Capital Employed - reported in percent (%). It carries weight in boardroom and executive reviews, where it anchors cross-organization trade-offs. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## 3. Context

Measures profit generated per unit of long-term capital deployed. ROCE is the cleanest test of whether growth is being bought with shareholder money or created with it. A rising ROCE driven by underinvestment (starved capex) is decay in disguise. Read with economic value added and cash flow return on investment.

## Formula

```
EBIT / Capital Employed
```
