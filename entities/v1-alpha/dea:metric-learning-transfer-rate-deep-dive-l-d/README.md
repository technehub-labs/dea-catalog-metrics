## 2. Definition

Learning Transfer Rate (Deep Dive - L&D) (LTRDDL) addresses the economic value created or preserved and is a fixture of learning & development effectiveness (deep dive) reporting. It informs long-horizon decisions and is typically tracked on enterprise dashboards rather than team boards. Its calculation is Behaviors Applied at Work after Training / Trained Cohort, measured in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures how much of what is trained shows up in changed on-the-job behavior. Transfer is where learning investment either pays or evaporates. Post-course surveys measure satisfaction, not transfer. Read with learning transfer rate (Deep Dive) and skill gap closure rate (L&D).

## Formula

```
LTRDDL = Behaviors Applied at Work after Training / Trained Cohort
```
