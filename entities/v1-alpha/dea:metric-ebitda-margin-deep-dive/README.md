## 2. Definition

EBITDA Margin (Deep Dive) (EBMDD) captures the economic value created or preserved for organizations tracking financial statement analysis ratios (deep dive). It is computed as EBITDA / Revenue, expressed in percent (%). It is applied across virtually every sector. It is a headline indicator: movement in it prompts leadership questions about strategy and resourcing. It should be maximized within the limits of cost and quality trade-offs.

## 3. Context

Measures operating profitability before depreciation and amortization. EBITDA approximates cash generation capacity and enables capital-structure comparison. Treating EBITDA as cash ignores working capital and capex, sometimes fatally. Read with operating margin (Deep Dive) and free cash flow yield.

## Formula

```
EBITDA / Revenue
```
