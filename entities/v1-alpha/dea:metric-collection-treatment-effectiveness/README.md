## 2. Definition

Collection Treatment Effectiveness (CTE-CC) addresses how efficiently resources are converted into outputs and is a fixture of credit & collections risk (enterprise) reporting. It is defined as Cured Accounts per Treatment Strategy / Treated Accounts; the result is stated in percent (%). It is applied across virtually every sector. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Cured Accounts per Treatment Strategy / Treated Accounts
```
