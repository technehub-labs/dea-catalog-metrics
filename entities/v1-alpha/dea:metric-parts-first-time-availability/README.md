## 2. Definition

A Field Service & Asset Performance indicator, Parts First-Time Availability (PFTA) quantifies how efficiently resources are converted into outputs. Its calculation is Jobs with All Parts on Vehicle / Parts-Dependent Jobs, measured in percent (%). It is applied across virtually every sector. It provides the day-to-day signal that a process is running as designed. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Jobs with All Parts on Vehicle / Parts-Dependent Jobs
```
