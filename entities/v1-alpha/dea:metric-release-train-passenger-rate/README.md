## 2. Definition

A Release Management & Environments indicator, Release Train Passenger Rate (RTPR) quantifies how efficiently resources are converted into outputs. The formula is Changes Shipping in Train / Changes Committed to Train - reported in percent (%). It is applied across virtually every sector. It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Changes Shipping in Train / Changes Committed to Train
```
