## 2. Definition

Backlog Refinement Cadence Compliance (BRCC-S) captures conformance to standards, plans, or obligations for organizations tracking requirements engineering & product discovery. It is a working-level control: thresholds trigger immediate operational response. It is defined as Refinement Sessions Held per Cadence / Scheduled; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## Formula

```
Refinement Sessions Held per Cadence / Scheduled
```
