## 2. Definition

Fraud Ring Detection Yield (FRDY) measures exposure to adverse outcomes in the Enterprise Fraud & Financial Crime Management domain. It is computed as Confirmed Rings Disrupted / Network Investigations, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
FRDY = Confirmed Rings Disrupted / Network Investigations
```
