## 2. Definition

Cleaning Compliance Score (Rooms) (CCS-R) measures the quality of outputs and outcomes in the Hotel & Resort Operations (Deep Dive) domain. It provides the day-to-day signal that a process is running as designed. Its calculation is Inspected Rooms Meeting Standard / Inspected, measured in percent (%). Improvement means raising this figure toward best-in-class levels. It originates from and is most used in Hospitality practice.

## Formula

```
CCS-R = Inspected Rooms Meeting Standard / Inspected
```
