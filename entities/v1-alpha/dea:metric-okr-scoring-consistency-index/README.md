## 2. Definition

Within Enterprise OKR & Performance Management, OKR Scoring Consistency Index (OSCI) is used to gauge the quality of outputs and outcomes. The formula is Variance of Attainment Distributions across Teams - reported in index (0-100 or normalized). It guides mid-horizon planning: portfolio, program, and function owners act on it between review cycles. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

Variance of Attainment Distributions across Teams
