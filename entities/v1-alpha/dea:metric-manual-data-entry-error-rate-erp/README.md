## 2. Definition

Manual Data Entry Error Rate (ERP) (MDEE) addresses the quality of outputs and outcomes and is a fixture of erp & enterprise application operations reporting. It is defined as Manual Entries with Errors / Entries Sampled; the result is stated in percent (%). It is a working-level control: thresholds trigger immediate operational response. Lower values are better; each reduction is an improvement. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Manual Entries with Errors / Entries Sampled
```
