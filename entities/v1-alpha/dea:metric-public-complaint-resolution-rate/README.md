## 2. Definition

Within Government & Public Administration, Public Complaint Resolution Rate (PCRR) is used to gauge the quality of outputs and outcomes. It is defined as Complaints Resolved within Standard / Complaints; the result is stated in percent (%). It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. Higher values are better; gains are read as improvement and losses as deterioration. In Public Sector, it is a recognized element of the standard performance toolkit.

## Formula

```
Complaints Resolved within Standard / Complaints
```
