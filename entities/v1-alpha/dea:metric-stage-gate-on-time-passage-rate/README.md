## 2. Definition

A PMO & Portfolio Governance indicator, Stage Gate On-Time Passage Rate (SGOTP) quantifies conformance to standards, plans, or obligations. It is computed as Initiatives Passing Gates on Schedule / Gate Reviews, expressed in percent (%). It is applied across virtually every sector. It is reviewed at cadence by planning owners to correct course before issues become strategic. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Initiatives Passing Gates on Schedule / Gate Reviews
```
