## 2. Definition

Regulatory Inspection Completion Rate (RICR) addresses conformance to standards, plans, or obligations and is a fixture of government & public administration reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Inspections Completed per Plan / Planned Inspections; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Public Sector, it is a recognized element of the standard performance toolkit.

## Formula

```
RICR = Inspections Completed per Plan / Planned Inspections
```
