## 2. Definition

Within Internal Controls & Financial Reporting Integrity, Control Test Sampling Sufficiency Rate (CTSSR) is used to gauge the quality of outputs and outcomes. It is computed as Tests Meeting Sample Sufficiency Standard / Tests, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is not sector-specific; it appears in cross-industry performance frameworks.

## Formula

```
Tests Meeting Sample Sufficiency Standard / Tests
```
