## 2. Definition

A Healthcare Quality & Patient Safety Standard Measures indicator, Sepsis Bundle Compliance Rate (SBCHR) quantifies the quality of outputs and outcomes. It is a working-level control: thresholds trigger immediate operational response. It is defined as Sepsis Cases Receiving Full 3-Hour Bundle / Cases; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. In Healthcare, it is a recognized element of the standard performance toolkit.

## Formula

```
Sepsis Cases Receiving Full 3-Hour Bundle / Cases
```
