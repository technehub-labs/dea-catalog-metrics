## 2. Definition

A Cleaning & Environmental Services indicator, Chemical Dilution Compliance (CDC-C) quantifies conformance to standards, plans, or obligations. The formula is Dilution Checks within Spec / Checks - reported in percent (%). It is a standard measure in the Facility Services sector. It is monitored close to the work: teams act on it within a shift, sprint, or daily review. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Dilution Checks within Spec / Checks
```
