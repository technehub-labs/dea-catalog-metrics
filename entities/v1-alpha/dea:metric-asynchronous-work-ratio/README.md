## 2. Definition

Asynchronous Work Ratio (ASWR) addresses how efficiently resources are converted into outputs and is a fixture of digital workplace & collaboration reporting. It bridges daily operations and executive reporting, giving managers a lever to pull within a quarter. It is defined as Async Communications / Total Team Communications; the result is stated in percent (%). Improvement means raising this figure toward best-in-class levels. Practitioners in nearly any industry can adopt it directly.

## 3. Context

Measures the share of collaboration done asynchronously rather than in meetings. It matters because async work enables deep work and global teams. Async can be counted while meetings simply reproduce the same content. Read with Focus Time Share and Meeting Hours per employee to confirm async adoption is genuine.

## Formula

```
Async Communications / Total Team Communications
```
