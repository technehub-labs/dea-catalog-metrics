## 2. Definition

Within Packaging & Plastics, Leak Test Pass Rate (Packaging) (LTPR-P) is used to gauge the quality of outputs and outcomes. It is defined as Packages Passing Leak Test / Packages Tested; the result is stated in percent (%). In Manufacturing, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
LTPR-P = Packages Passing Leak Test / Packages Tested
```
