## 2. Definition

Wood Utilization Efficiency (WUE) addresses how efficiently resources are converted into outputs and is a fixture of furniture & wood products reporting. It is computed as Finished Product Volume / Timber Input Volume, expressed in percent (%). It is reviewed at cadence by planning owners to correct course before issues become strategic. Higher values are better; gains are read as improvement and losses as deterioration. Its use is concentrated in Manufacturing.

## Formula

```
Finished Product Volume / Timber Input Volume
```
