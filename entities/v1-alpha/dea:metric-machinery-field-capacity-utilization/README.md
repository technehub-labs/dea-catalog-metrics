## 2. Definition

Within Agriculture & Agronomy (Deep Dive), Machinery Field Capacity Utilization (MFCU) is used to gauge how efficiently resources are converted into outputs. It is defined as Actual Work Rate / Theoretical Work Rate; the result is stated in percent (%). In Agriculture, it is a recognized element of the standard performance toolkit. It is a working-level control: thresholds trigger immediate operational response. It should be maximized within the limits of cost and quality trade-offs.

## Formula

```
Actual Work Rate / Theoretical Work Rate
```
